# 研究代码样式与修改协议

## 1. 适用范围

本规范适用于站内充电单元交互图与事件残差修正项目的全部数据处理、模型、
训练、评价和实验编排代码。目标不是追求形式上的复杂，而是保证每一次修改
都可理解、可测试、可复现，并且不会悄然改变论文中的数据和评价口径。

## 2. 不可变研究边界

1. 研究对象是由充电会话记录重构的**节点代理负荷**，单位为
   `kWh/15 min`；不得称为在线电表实测功率。
2. 节点由站内充电接口或车位级空间标识确定；图边表示统计交互关系，不表示
   配电网物理拓扑。
3. 数据按时间顺序划分训练集、验证集和测试集。标准化参数、固定图关系、
   事件阈值及路径规则只能由训练集或验证集确定。
4. 测试集只用于一次性评价，不得用于选模型、调阈值、选图边或提前停止训练。
5. 正式结论必须来自三随机种子 `2024、2025、2026` 的完整数据实验。
6. `implementation_smoke_only` 仅验证程序可运行，不得进入论文性能表格。

## 3. 目录职责

- `src/evcs_station_graph/data/`：时间片重构、张量、预测键和数据集。
- `src/evcs_station_graph/graphs/`：只使用允许数据构造统计关系。
- `src/evcs_station_graph/models/`：纯模型结构，不在此读取文件或划分数据。
- `src/evcs_station_graph/training/`：训练循环、检查点和统一模型工厂。
- `src/evcs_station_graph/evaluation/`：指标、分层和四格还原。
- `src/evcs_station_graph/experiments/`：实验编排、跨实验汇总和证据检查。
- `configs/experiments/`：实验差异的唯一声明位置。
- `tests/`：对数据边界、张量形状、预测键和实验工件进行回归检查。

禁止在临时脚本中复制一套新的切分、指标或事件定义。新实验必须通过统一入口
调用现有模块。

## 4. Python 编码规范

1. 使用类型标注；公共函数必须写中文文档字符串，说明输入、输出和边界。
2. 中文注释用于解释“为什么这样设计”，不逐行翻译代码。
3. 函数保持单一职责；数据读取、模型前向、评价和文件写出不得混在同一函数。
4. 配置、路径和阈值不得以散落常量硬编码在模型中。
5. 使用含义明确的英文标识符，例如 `prediction_origin`、`event_mask`、
   `adjacency`，避免 `data1`、`tmp2` 等名称。
6. 对空数据、重复预测键、维度不一致、检查点种子错配等情况立即抛出明确异常，
   不静默补齐或跳过。
7. 工件采用 UTF-8、稳定字段名和确定性排序；浮点数不在中间计算阶段提前取整。

## 5. 模型接口约定

所有预测模型接收统一批次结构并输出形状
`[batch, horizon, node]`。模型不得自行读取未来标签。

- SG-EXP-002：只使用节点自身历史与预测时点可见特征。
- SG-EXP-003：使用训练期固定的站内统计交互图。
- SG-EXP-004：学习自适应节点关系，同时保留固定关系约束。
- SG-EXP-005：加载同一随机种子的 SG-EXP-002 检查点，仅在冻结事件门控开启时
  增加有界局部残差。
- SG-EXP-006：复用统一训练与评价代码，不另写指标公式。

## 6. 评价与预测键规范

预测长表的主键固定为：

```text
split + origin_index + horizon + node_id
```

每个键只能出现一次。跨方法比较前必须验证行数、键集合和顺序无关指纹一致。
全局、目标事件和规则触发采用互斥四格划分：

1. 目标事件且规则触发；
2. 目标事件但规则未触发；
3. 非目标事件但规则触发；
4. 非目标事件且规则未触发。

四格绝对误差按样本量加权后必须精确还原全局 MAE。不能还原时，不得解释
事件收益来源。

## 7. 配置与实验变更流程

每次修改依次执行：

1. 说明研究问题和不变口径；
2. 新增或修改配置，不覆盖既有正式配置；
3. 先写能够暴露旧问题的测试；
4. 实施最小范围代码修改；
5. 运行全部自动化测试和小样本冒烟实验；
6. 审核预测键、三种子、四格还原和结果权威标记；
7. 再运行完整正式实验；
8. 将配置、代码版本、指标、预测长表和检查点共同归档。

涉及数据切分、标签、事件阈值、图构造、损失函数或评价指标的变更，必须新建
实验编号或版本，禁止原地覆盖旧结果。

## 8. 注释与文档示例

推荐：

```python

    """仅由训练期特征构造固定站内关系图。

    """
```

```python

def graph(x, k):
    ...
```
