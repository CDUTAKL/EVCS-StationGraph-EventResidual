## 一、项目一句话

**基于站内充电单元行为交互图的短期负荷预测**（15 min 粒度，96 步历史 → 4 步预测），
核心贡献 = 场景驱动的三类统计关系图（LRE）+ 双层门控多关系图卷积（MRG-GCN）
+ 三层机制诊断协议（MDP）+ 事件窗口的机制刻画与预测支持探索（第 5 章）。

## 二、正式方法与最终结论（已定稿，不可改）

| 项 | 定稿结论 |
|---|---|
| **正式主模型** | StaticGraph（MRG-GCN）：TCN 编码 → 双图卷积（**三类固定关系** LRE，关系级 β 门控 softmax 融合 + 节点级 G 门控）→ Skip Fusion。全局 MAE **0.01376**（三种子均值，SD 0.00023），本文所有贡献以此为基准。**注意：自适应第四关系仅存在于 AdaptiveGraph 对照模型（SG-EXP-004）**，正式主模型不含自适应邻接 |
| **主要结果** | StaticGraph 相对 TCN 基线提升 53.4%（0.02952→0.01376）；相对最强传统基线 ARIMA 提升 39.1%；MLP 参数量 6.9 倍于 StaticGraph 反而落后 34.8% |
| **显著性口径** | n=3 种子不做 t 检验；头部三模型（StaticGraph/AdaptiveGraph/EventResidual）差距与种子噪声同级（0.6~1.2 倍 SD），正文表述"统计上不可区分"；与其他模型差距为 7~68 倍种子 SD，属量级差异 |
| **消融** | 无图 → +113%；仅固定图 +2.5%、仅自适应图 +2.3%（两类关系边际贡献接近）；门控关闭（全样本修正）→ +90.5%（门控选择性必要）；关系子集消融：单关系 ≈ 三关系（多关系边际增益≈0）；top_k 5→7 劣化 +4.1% |
| **事件窗口** | 事件窗口 MAE ≈0.276 为稳定窗口 ≈0.010 的 **28 倍**，是数据结构性属性（所有模型共同），非模型缺陷 |
