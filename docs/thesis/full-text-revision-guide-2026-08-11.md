# 全文审校与修改方向指南（2026-08-11）

## 1. 审校范围与原则

本轮以 `docs/thesis/thesis-manuscript.md` 为正文唯一内容源，同时核对实验登记、正式结果、图表索引、图形脚本、证据清单和正式 DOCX。审校分为两条独立线路：一条检查论证链、数字、公式、实验口径与结论边界；另一条检查措辞、重复、句法、段落功能和人工写作质感。修改遵循“先纠正事实与逻辑，再压缩语言，最后处理格式”的顺序。

## 2. 逻辑与准确性修改规则

1. **对象边界**：全文只讨论由会话记录重构的节点代理负荷，不写成电表实测功率、瞬时功率或配电网物理负荷。
2. **比较边界**：三种子只能支持重复性描述；头部模型差异与跨种子波动同级时，不使用“显著优于”。点级 Bootstrap 也不替代跨站、跨时期或跨种子统计推断。
3. **事件双口径**：`target_event` 占测试预测键 1.43%，是依据未来4个预测步的目标侧观测构造的事后评价标签，并非人工核验的现实事件真值；`rule_trigger` 占 0.43%，是预测时可见的冻结规则，用于四格诊断和区间路由。两者不得混称。
4. **区间结论**：规则路由只能称“预测时可执行”，但经验覆盖未达目标，不能称为可靠或已经可部署；使用 `target_event` 分层的 oracle 统一称“标签事件事后参照”，不称理论上界或部署结果。
5. **结构结论**：关系权重观察、参数替换、蒸馏和四格诊断分别回答不同问题，不把任一项升级为物理因果。关系子集结果不支持“三类关系均有独立正增量”。
6. **图构建口径**：主预测模型使用 top-k=5；TE 与 LRE 的探索性覆盖比较为控制边数使用 top-k=3，正文必须显式区分。
7. **PCMCI+样本量**：输入是训练段 83,198 个原始时间观测，不是窗口化后的 83,103 个预测起点。
8. **公式与矩阵方向**：节点门控的线性映射采用行向量记法，写为 $[H\Vert M]W_g+b$，与代码中的特征拼接后线性层一致。
9. **离散度**：跨三个随机种子的误差棒统一采用样本标准差（`ddof=1`）；确定性基线不绘制伪误差棒。
10. **传统基线证据**：正文表 3-1 使用修正目标对齐后的结果。旧 `traditional_baselines_summary.json` 早于修复，仅作历史文件；权威锁定记录为 `formal_baselines_locked.json`。
11. **标识字段边界**：`siteID=2` 表示数据子集所属站点；`stationID`、`EVSEID` 和 `spaceID` 用于区分站内设备与充电位。不得把单一 `siteID` 与55个候选节点混为同一层级。
12. **第二层传播输入**：第一层以 $H^{(0)}$ 为输入，第二层以 MLP 精炼后的 $H^{(1,\mathrm{ref})}$ 为输入；跨层拼接仍使用原始 $H^{(0)}$、$H^{(1)}$ 和 $H^{(2)}$，不拼接精炼状态。

## 3. 语言与人工写作质感规则

1. 每段只承担一个主要功能，避免在同一句内堆叠“方法—结果—解释—边界”。
2. 删除重复的章节回顾；摘要、章首、章末和结论分别保留“概述、承接、归纳、最终判断”功能，不机械复述同一数字串。
3. 减少“本文进一步、由此可见、充分说明、显著、不可替代”等模板化词语。没有统计检验时用“明显、较高、较低、在所检配置中”。
4. 将 `checkpoint`、实验编号和流水线术语移出面向评审的正文，改为“模型权重文件”“正式运行”“实验记录”；实验编号只保留在登记表和附录追溯材料。
5. 对工程术语首次给出中文含义，后文保持同一写法；`oracle` 保留英文时必须同时标注“事后参照”。
6. 长句优先按“事实—解释—边界”拆分，主语保持明确，避免多个分号连续组织四层以上逻辑。
7. 具体化限定范围：把“结构有效”“规则失效”等泛化判断改写为“在该消融套件内退化最大”“覆盖不足主要表现为可见信号与标签错位”。
