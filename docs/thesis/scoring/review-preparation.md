# 评分准备、证据缓存与变更影响索引

## 用途与边界

`scripts/prepare_thesis_review.py`用于正式内容评阅前核验冻结材料、复用完全相同输入闭包的确定性检查，并按正文章节、证据和来源状态生成主张重读索引。它不评分、不修订总分，也不代替人工判断。

本项目的评审前检查范围是`review-preparation.json`登记的19份2026-10-17配对校准证据快照，以及当前稿、同一校准基线稿、量表、评分锚点、评阅指引和计分验证依赖。`evidence_inventory_confirmed`仅确认该明确清单；新训练结果、原始数据、图像实体或项目外材料必须先加入清单和主张映射。

## 执行

每次输出使用新目录，避免覆盖旧快照：

```bash
python3 scripts/prepare_thesis_review.py \
  --project . \
  --config docs/thesis/scoring/review-preparation.json \
  --out docs/thesis/review-preparation-日期/run序号 \
  --cache-dir .cache/thesis-review \
  --run-checks --freeze
```

脚本以SHA-256读取文件内容；相同大小和修改时间不能掩盖字节变化。缓存键绑定检查脚本、显式声明的全部依赖、参数、输入文件、rubric/anchors/protocol/reviewer instructions、Python运行环境和选定环境变量。失败、超时、输入漂移或输出被改写时不会复用成功记录。所有间接导入和外部配置必须写入检查的`inputs`；工具无法自动推断任意脚本的运行时依赖。

缓存记录另用本机用户私有状态目录中的密钥做HMAC认证；项目内缓存被复制或手工篡改后会作为缓存未命中处理。若密钥不可安全读取，脚本禁用缓存复用并重新运行检查。`--run-checks`会以当前用户权限执行配置登记的本地Python脚本；启用前应检查配置、脚本和依赖闭包。不要对来源不明的项目配置启用该选项。

冻结包只含基线稿、当前稿、列明且标记可供隔离评阅者阅读的科学证据、评分量表、锚点和评阅指引。评分卡、历史分数、评阅者原始报告和评分治理材料不得传给隔离评阅者。`manifest.json`记录每个文件哈希。图像范围仅到图注；Word/WPS分页、图像清晰度和全页视觉验收必须另行完成。

## 当前一次性核验

run07/08记录了修订前的评阅准备状态：配对评分发布合同检查成功，来源哈希匹配；当时登记的[76]近邻比较缺口仍需处理。2026-10-17后续修订已将[76]与表1-1、§1.2.3和§1.3逐项对应，并在`review-preparation.json`中将其状态改为`compared`。修订稿的当前变更影响需由新一轮评阅前检查重新生成；不能把run07/08的旧索引当作本稿通过记录。影响索引也不为未复读主张生成科学通过标记。缓存记录以本机私有密钥认证；评分卡不能通过证据、量表附件或评阅指引角色进入冻结包。

在同一机器对同一配置进行的冷/热缓存对照中，完整准备由0.124秒降至0.031秒（约75%）；配对评分发布合同检查由0.097秒降至0.017秒（约83%）。此为单次本机测量，只反映文件哈希、JSON/文本结构检查和评分记录校验，不包括三位评阅者阅读和审理、法证复核、Word/PDF生成或全页视觉验收。缓存减少重复机械计算，不代表总体论文评审用时按同一比例缩短。

此工具不改变`EVCS-THESIS-REVIEW-2.0`的三视角隔离、同量表配对、法证复核和发布门槛。日常迭代可以只处理已变更主张；正式总分仍须按完整协议完成。
