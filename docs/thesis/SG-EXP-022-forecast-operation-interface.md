# SG-EXP-022：节点预测到站内运行核查的固定原点算例

## 目的与结论

本分析将一个已归档的MRG-GCN四步预测转换为区间平均代理功率，说明此类输出可如何进入站内容量余量核查。它不是调度优化实验，也不估计经济收益。固定算例在代理需求跃升时低估了末步值，说明模型输出不能单独承担容量保护或自动控制。

## 来源与复算

- 输入：`outputs/analysis/SG-EXP-021-demand-warning/final/first_example_seed_mean_display_only.csv`。
- 来源SHA-256：`4e112e14febfef4b707edd5cd79bd9e5cededf42e477bcbcfb070e541c3f6162`。
- 固定对象：`mrg_full`，种子2024/2025/2026的展示均值，原点101411，洛杉矶当地发布时刻2021-03-16 13:00，目标需求过程于13:45开始。
- 选择规则：使用既有记录中按时间顺序确定的首个合格过程；不按模型预测是否命中选例。
- 计算：每15 min代理能量除以0.25 h，得到区间平均代理功率换算值。种子均值只作曲线展示，不表示部署集成；种子标准差不表示预测区间。
- 代码：`scripts/build_forecast_operation_case.py`。
- 输出：`outputs/analysis/SG-EXP-022-forecast-operation-interface/`，包含四步派生CSV、输入与计算审计JSON、输出manifest。

重算命令：

```sh

```

脚本默认拒绝覆盖已有结果目录。审计检查发布原点、4个目标步、0/15/30/45 min目标起点前视、三个种子范围和代理能量到平均速率的换算关系。

## 运行解释边界

在真实充电站中，经过电表数据标定的站级功率预测可以与设备限额、其他负荷和备用裕度共同用于容量余量核查；余量偏低时，再检查能否移动会话启动或调整功率，并遵守车辆服务要求、设备限制及储能状态。SG-DATA-006与SG-EXP-019没有站级实测功率、完整容量边界或发布时可用的预约需求/充电控制约束，因此本算例不计算真实余量、可行排程、削峰量或成本变化。数据也不足以研究发电侧经济调度。

SG-EXP-021完整阈值预警比较与时间块核验继续保留在其原始报告和计算工件中，不在本算例中删除。其可靠性限制仍应在正文说明：主模型开始前过程发现率约10.30%±0.80%，测试期代理需求越限比例高于校准期（18.96%对4.96%）。经验阈值不是设备容量；这些数字不是工程安全率。
