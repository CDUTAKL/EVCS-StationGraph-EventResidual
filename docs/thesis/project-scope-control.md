# 项目范围与硬门槛

## 允许的研究表述

- 单站内多个充电单元的时空代理负荷预测。
- 站内充电单元之间的统计行为交互图。
- 验证集冻结的事件分流与有界残差修正。

## 禁止提前使用的表述

- 真实在线电表功率预测。
- 配电网物理拓扑学习。
- 可学习事件触发器、动态专家或测试阶段自适应重训。
- 未完成现代基线和多种子检验前的“整体最优”。

## 数据硬门槛

1. 节点标识必须能稳定映射到站内充电接口、EVSE 或车位级单元。
2. 同一物理单元的别名不得重复计为多个节点。
3. 训练、验证和测试采用时间顺序划分；测试信息不得参与图、阈值或规则构建。
4. 节点必须具有足够的非零覆盖和跨划分可用性。
5. 若不能证明站点—节点层级，则研究名称降级为“多节点行为关系图预测”。

## 模型保留门槛

- 图路径必须在至少一个预先定义的重要范围内稳定优于纯时间路径。
- 事件残差修正必须改善事件窗口，同时不显著损害稳定窗口。
- 四格结果必须能按样本量加权还原全局指标。
