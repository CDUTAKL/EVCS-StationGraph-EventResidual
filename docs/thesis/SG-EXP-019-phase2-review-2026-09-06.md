训练充分性审计结果如下：

2. 实际停止轮次由验证集不再改善触发，而不是异常退出、显存不足或人工截断；同时区分

6. 每个模型的环境、数据SHA、代码SHA和配置契约一致。

本次审计确认36/36运行合同闭合、检查点完整、训练日志有限且四格还原通过；30个运行

## 2. phase2 数值的直接解释

以下相对变化均以 `mrg_full=0.0389` 为参照，仅描述用户汇总表中的新协议结果：

| 配置 | test MAE | 相对 mrg_full | 解释 |
|---|---:|---:|---|
| agcrn_full | 0.0374±0.0002 | −3.86% | 完整AGCRN在新协议下更低，但参数量更大 |
| mrg_equal_beta | 0.0386±0.0003 | −0.77% | 与完整模型基本持平，不能称“β贡献为零” |
| mrg_no_skip | 0.0390±0.0005 | +0.26% | 跨层拼接去除后变化很小，且小于汇总SD量级 |
| mrg_no_refine | 0.0393±0.0003 | +1.03% | 精炼模块有小幅支持，证据强度有限 |
| mrg_pattern | 0.0395±0.0003 | +1.54% | 三个单关系中最好，但仍劣于三关系融合 |
| mrg_fixed_gate | 0.0411±0.0015 | +5.66% | 固定门值使结果明显变差，支持门控组件重要 |
| mrg_load | 0.0431±0.0007 | +10.80% | 仅负荷关系明显弱于三关系 |
| mrg_event | 0.0456±0.0003 | +17.22% | 仅行为关系接近无图水平 |
| mrg_self_loop | 0.0461±0.0006 | +18.51% | 仅自环的图路径作用很弱 |
| tcn / tcn_wide | 0.0463 | +19.02% | MRG变体整体低于无图基线；两者应分开报告精确均值和SD |

由此，新协议最稳妥的结论是：

- MRG的门控机制有较清晰的功能证据；固定门值的退化大于去精炼和去跨层拼接。
- 三关系融合优于任一单关系，支持“关系互补性”这一较窄的结论；不能据此说每一类关系
  都有独立正增量。
- `mrg_equal_beta` 与 `mrg_full` 的差异只有0.0003，低于两者汇总标准差的合成量级；
  只能写“在新协议和所检配置下未观察到可辨识增益”，不能写“可学习β贡献为零”。
- `agcrn_full` 的数值最优不推翻旧主线，因为它回答的是 `SG-DATA-006-eventtime-v1`
  的行为可见输入问题；它也说明新协议下不能宣称 MRG 普遍优于完整AGCRN。

## 3. 公平性审阅

### 3.1 已经具备的公平比较

phase1/phase2按现有运行器设计共享7通道事件时刻输入、严格时间切分、三种子、优化器、
学习率、权重衰减、批量大小、最多轮数、patience、标准化L1和tuning选best。故它们在
**数据权限与训练预算**上具备同协议比较基础。

本地 `check` 给出的参数量为：

| 模型 | 可训练参数 |
|---|---:|
| mrg_full | 32,714 |
| tcn_wide | 32,674 |
| agcrn_full | 199,912 |

因此 `tcn_wide` 是当前最强的容量匹配无图对照，`agcrn_full` 是保留完整核心结构的
标准基线，但不是容量匹配基线。两者都应保留，图表中明确标注参数量差异。

### 3.2 真正仍缺的比较

若要把新协议写成完整的“公平基线”结果，还缺一个至少满足以下条件的行为输入基线：

- 与 MRG 使用同一7通道、同一96→4窗口和同一四段切分；
- 使用相同三种子和早停预算；
- 最好给出参数量匹配的GRU或MLP，并另给一个线性/均值下界；
- 输出全局、事件、稳定、逐步长和四格三种子均值±样本SD。

旧协议中的GRU、MLP和传统基线不能直接填入新协议表，因为旧协议输入权限和切分不同。
如果短期不再开机，论文应把新协议限定为“MRG内部消融+TCN/宽TCN/完整AGCRN对照”，
不要把它包装成所有基线均已在可见性修订协议中重跑。

本次不因`agcrn_full`的较低数值自行改变主线，也不为补齐上述缺口再次启动付费实例。
只有在导师明确要求“新协议下完整公平基线”时，才按同一合同补跑行为输入GRU/MLP、线性
或均值下界，以及容量匹配AGCRN；届时另立实验登记号和独立结果表，不覆盖本归档。

## 4. 与旧主实验的关系

旧 `SG-DATA-005` 主结果仍回答事后重构代理负荷上的离线比较，MRG-GCN为
`0.01376`；新 `SG-DATA-006-eventtime-v1` 的 MRG 为 `0.0389`。两者的绝对数值不应
直接比较，也不应计算跨协议“性能下降百分比”作为模型退化。

新结果更适合放在第五章的“协议敏感性与可见性边界”小节：它说明删除旧代理负荷输入后，
图结构和门控仍有一定相对价值，但完整AGCRN在该输入权限下取得更低MAE；这会让论文主线
更可信，而不是削弱旧主实验。旧主线仍负责主要模型结果，新协议负责可见性压力测试。
