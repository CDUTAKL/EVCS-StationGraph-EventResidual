## 多指标一致性（正文段落素材，2026-08-03 核验）

> 为检验结论对误差指标的依赖性，表 3-1 同时报告 MAE、RMSE 与 WAPE 三个指标。
> 三个指标下，本文 StaticGraph 均排名第一，且前三名（StaticGraph、EventResidual、
> AdaptiveGraph）完全一致，仅第 2/3 名次序在 RMSE 下发生微调（0.09920 vs 0.09925，
> 差异 0.05%）。该一致性表明：本文方法的相对优势不依赖于指标选择，主要结论稳健。
> 另说明不采用 MAPE 的原因：本数据测试集零负荷样本占比约 87%（负荷稀疏），MAPE 分母
> 趋零导致数值失真，故以 WAPE（总负荷加权）替代，兼顾百分比语义与数值稳定性。

¹ 训练时间估算：训练步 12.6 ms（A6000）× 每轮约 830 步 × 40-60 轮 ≈ 7-10 分钟/种子，
   供论文正文量级描述（"分钟级"），不作精确计时声明。

**效率论证（正文素材）**：MLP 参数量约为 StaticGraph 的 6.7 倍（215K vs 32K），
但全局 MAE 反而落后 34.8%（0.02112 vs 0.01376）——性能差距不能归因于容量，
而来自图结构对站内交互信息的利用；该论证支撑"图结构是收益来源而非参数红利"。

## 口径声明（表格下方注释，论文必备）

1. **实验来源统一口径**：SG-EXP-002/003/004/005 取自正式流水线（night_run/20260730-171821）三种子；SG-EXP-009/010 取自 outputs/experiments 目录三种子；传统基线取自 traditional_baselines_summary.json。
2. **SG-EXP-004 双 run 说明**：SG-EXP-004 存在两个已完成 run——正式流水线（全局 0.01396，本表采用）与独立复跑（outputs/experiments/20260731-102456，全局 0.01368，用于图 4-4/3-5/3-7 的训练过程与机制诊断素材）。两者差异约 1%（三种子标准差范围内）；本表统一采用流水线口径，正文凡引用全局数值均以本表为准。
3. **EventResidual（SG-EXP-005）边际改善说明**：相对 StaticGraph，其事件窗口 MAE 三种子均值变化 -0.02%（seed-2024 +0.47% / seed-2025 -0.54% / seed-2026 0.00%），不构成显著改善；其消融（SG-EXP-006 no_event_gate）显示"门控关闭→全样本修正"导致全局恶化 +90.5%（相对完整模型 SG-EXP-005 基线；若相对 StaticGraph 为 +92.4%），证明门控选择性激活必要。事件机制的详细讨论见第 5 章（探索性定位）与附录。
4. 事件窗口样本占比 1.43%（10,160/712,360），稳定窗口占比 98.57%；四格加权还原全局 MAE 容差 ≤1e-9（18/18 通过）。
