# 正文语言与结构递进审阅建议

## 审阅范围

本次完整阅读了 `docs/thesis/thesis-manuscript.md` 的中英文摘要、正文第1—5章、结论、图表题注及附录A。审阅聚焦表达凝练、段落功能、章节递进和术语一致；未查看其他审稿报告或评分记录，未核验原始数据、文献全文、Word/PDF版式，也未修改论文正文。

## 总体判断

论文已经具备清晰的证据意识，核心边界也写得较严谨。当前主要问题不是缺少限定，而是核心发现尚未始终占据叙事中心：方法介绍、历史回溯结果、诊断边界和负面探索结果有时获得相近篇幅，读者需要自己拼出“哪些组件有增量、完整模型在哪些样本上仍不占优、MDP具体改变什么判断”。全文还多次重复同一边界，造成防御性语气偏重。

建议按以下主线组织修订：

> **关系组件的受控增量 → 完整模型在不同目标组的表现 → MDP改变的研究判断 → 可靠性与应用边界。**

须同时保留两项并不矛盾的发现：JPL中负荷关系相对自环对照的非零组差异，是组件内、已查看测试期上的未校正事后分层；MRG-GCN完整模型的非零组MAE仍未优于TCN。前者不能改写成完整模型胜过TCN，后者也不能抹去该关系的条件增量证据。

## 优先修订建议

### 1. 把“发现是什么”前置到研究问题、贡献和结果组织中

**位置：**摘要第5—13行；第1.3—1.5节（第112—152行）；第3.7.2、3.8节（第885—1049行）。

摘要已经给出准确结果，但第1.4节的贡献仍主要按工作流程列项（数据、建模、诊断、可靠性），没有用一句话点明最重要的新知识。第3.7.2节也先回顾旧关系子集、稀疏度和随机失活，再进入SG-EXP-031的关系替换证据；读者要读到后段才遇到当前最强的组件结论。

**建议：**在第1.4节首段或末段增加一条“结果型贡献句”，随后再列研究工作；把第3.7.2节重排为“JPL关系替换主证据→非零组与完整模型对照→旧协议关系子集和敏感性补充”。不需要增加更强的创新宣称。

**可用表述示例：**

> 本文的主要经验发现是：在JPL所检协议和训练预算下，负荷耦合与轮廓相似关系相对自环替换获得条件性整体MAE增量，行为共现关系的增量仍不确定；与此同时，完整MRG-GCN在非零目标组尚未优于TCN。因此，关系组件是否有增量与整套模型是否适合活跃负荷预测，应分别判断。

这段可按篇幅压缩；不得删去“JPL所检”“相对自环”“条件性”及“完整模型对TCN”的比较边界。

### 3. 调整第3.7.2节证据的先后与标签

**位置：**第3.7.2节（第885—927行）。

该节先讲旧协议关系子集、top-k和随机失活，再讲等权β、旧协议时间块分析，之后才给出JPL三类关系替换重训练表3-11及其解释。不同实验的协议、对照和证据等级连续切换，容易把“旧协议删分支”与“JPL同参数自环替换”看成一组实验。

**建议：**用短引导语显式划成两组：

1. **关系组件主检验（JPL，事后自环替换重训）：**先报告表3-11，接着分别解释整体MAE、行为关系区间跨零、非零组事后差异，以及完整模型未胜TCN。
2. **历史配置与敏感性补充（Caltech）：**再报告表3-10、等权β、top-k及关系随机失活，并指出删除关系分支同时改变参数量和传播路径。

如果不增加小标题，也应在段首反复明确协议名和比较类型。避免在同一段中从“JPL”切换回“旧协议”而不显式提示。

### 4. 让第5章按“候选结构—区间可靠性—运行使用条件”形成递进

**建议：**

## 句级凝练示例

### 5. 把关键结果从长句拆成“结论—证据—边界”

- **第1.1.3节第57行：**该句同时定义事件、比较日历事件、说明可见性、批评全局指标并引出主线。建议拆成两到三句：先定义“事件窗口/评价标签”，再说明目标侧标签事后可见、规则触发含回溯字段，最后引出全局与分层评价。细节由第2章承接。
- **第2.1.2节第238行：**一句包含合法完成时刻规则、回退条件、守恒数值、平均差解释、032训练设置和效度限制。建议分为“替代重构规则与守恒”“逐片差异及其解释”“SG-EXP-032如何使用替代目标”三句，读者可先得到规则，再读结果，不改变数值含义。
- **第3.6.3节（约第710—725行）：**整体MAE、三个基线降幅、24块重采样、置信区间、种子相关限制及复算结果集中在连续段落。建议拆成“总体比较与区间”“预测键复算”“分层权衡”三个段落，并让各段首句先给结论。
- **第3.8.3节表3-14注（第1013—1025行）：**注释承担了输入编码、优化器、选模规则、全部轮次、031停止规则、032固定项、容量差异和复算限制。建议保留表格读者必须立即理解的定义；把解释性限制移到表后两段，并按“统一设置—协议差异—预算限制”排列。
- **第5.2.3节（第1338—1355行）：**名义阈值、无向节点对、ASYM定义、阈值比例、独立选滞后、完整检验族与校正结果在同一段/邻近段落密集出现。建议首句先说“多重校正后无候选保留”，其后将名义数量与方向不对称指标分段报告。
- **第5.2.5节（第1380—1387行）：**历史PCMCI+结果与当前环境重算结果混在一段且数字多。建议明确分段标题或转折句：“历史归档结果”“当前锁定环境复算”；每段以各自数据来源、可复核范围和结论收尾。
- **第5.3.7节（第1522—1524行）：**路由错位与校准失配两条解释链是重要结论，但两个大段包含多组分层数值与限制。建议每段首句分别给“事件大多未触发，因而未获得宽区间”和“测试残差尾部高于验证期，显示校准失配”；细数值留在表5-6及紧接解释中，末尾的多重边界可归并成一句。
- **第5.4.2节（第1547—1553行）：**运行核查、公式定义、物理约束、缺失输入、影子运行日志和停止条件一段写完。建议分成“余量公式及变量”和“本研究当前不能验证的内容”两段；边界不删，只降低单段信息负荷。

### 6. 控制重复限定语，保留决定证据等级的限定

正文多处重复“测试期已查看”“不能据此证明”“不表示因果”“不支持部署/现场收益”。这些限定是科学边界，不应机械删除；问题在于同一段落或相邻段落常对同一结果重复两次。

建议采用“首次定义＋结果处简述＋总结处归纳”的分层方式：

- 在2.1.1定义三套协议及其测试时期属性；
- 在每项事后补充分析的结果段保留一次“已查看测试期/事后分析”；表注只在脱离正文仍可能误读时保留；
- 在章节小结或总论集中说明外推范围，不在同一结果段末重复列举所有“不等于”的结论。

例如3.7.1节既在表3-9注说明Caltech共享门控seed-2024触及上限，正文又两次重申更长预算不确定；保留一个紧邻结果的限定即可。4.2.6.1和4.2.6.3重复说明分层敏感度不等于关系贡献/因果效应，可在方法定义处完整说明，解释边界处仅保留“因此不能据此设定节点优先级”的直接结论。4.5末段又逐项复述表4-6，可压为一句总括。

## 章节递进与篇幅主次

1. **第2章的启示与小结略重复。** 2.6已把四项数据特征转为建模要求，2.7又重述统计比例、事件口径、输入相关性。建议2.6保留“这些数据特征如何决定建模/评价”，2.7压缩为本章结论及转入第3章的一段，不重复列全量比例。
2. **第3章主结果与回溯补充篇幅接近。** 3.6.2—3.6.3是行为输入协议的主比较，3.6.4—3.6.6则包含大量旧模型、重采样、逐节点和成本细节。建议在不丢复算链的前提下，把历史基线与次要诊断压缩或移入附录，让3.6主次与3.6.1承诺一致。
3. **第4章的“方法—证据—判断”框架合理，但L1限定语密度最高。** 4.2.3已报告权重画像，4.2.4又重复权重排序再给干预结果；可让4.2.3只负责观察，4.2.4直接从干预结果起笔。4.2.5保留重参数化的关键解释，其他章节引用结论即可，不要重复推导。
4. **结论结构是清楚的，但工作总结、5.5与主要结论重复较多。** 结论应承担全篇综合判断，不需要再次复述第5章所有表格数字。可把“研究工作总结”聚焦于论文回答的问题和新增认识；把数值集中在四条主要结论中；“研究判断与使用条件”只写实际能支持的决策，“研究局限与后续工作”只列下一步验证。
