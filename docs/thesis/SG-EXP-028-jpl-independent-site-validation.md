# SG-EXP-028：JPL独立场站验证预登记

登记日期：2026-10-05。当前权限：获取数据、元数据质检、冻结数据协议和实验设计；不运行正式训练、不查看任何JPL模型测试成绩。用户之后手动开机并授权执行。

## 1. 问题与结论边界

检验MRG的站内关系建模与节点门控是否能在另一场站的固定协议下复现效果。主任务为JPL场站重新训练后的代理需求预测，不是Caltech模型直接迁移，不是已测真实功率预测，也不称为2021年以后新时期验证。JPL与Caltech不同场站、同属ACN来源、历史时期有重叠，数据家族和采集机制并不完全独立。

JPL实测功率字段和时序质量尚未通过门禁，本次不为得到更好成绩切换任务。最终电量只用于事后目标和成熟训练期图构建，绝不回灌为预测原点历史负荷输入。即时接入/断开上报只是事件时间假设；不存在实测入库时刻，不能验证真实事件延迟。

## 3. 数据与节点协议

唯一数据配置：`configs/data/SG-DATA-007-jpl-eventtime-v1.json`。

- 时间格：UTC连续15min；完整合法会话最早接入向下取整至最晚断开向上取整，不依据模型结果删时期。当地日历使用America/Los_Angeles，正确处理夏令时。
- 顺序划分：训练70%、调参7.5%、独立校准7.5%、测试15%；边界为`floor(0.70T)`、`floor(0.775T)`、`floor(0.85T)`。每个96步历史与4步目标完全在所属分段内；所有使用的标签在分段末前成熟。代理标签的最早成熟时刻保守取断开时刻与非空完成充电时刻的较晚者；实际字段发布延迟仍未知。训练scaler、跳变阈值和图只拟合连续成熟训练前缀。
- 节点：以车位`spaceID`为研究单元。同车位多个设备标识合并为一个节点，绝不重复计节点；一个`stationID`若映射多个车位则停止调查。只按训练边界前最终标签已成熟的会话筛选，至少200会话、6个活动月份，按成熟会话数降序取10节点，平局按字符串排序。若不够10节点则停止，不用测试活动或预测误差更换节点。
- 输入7通道：接入数、离站数、活跃数、当地时刻sin/cos、星期sin/cos。接入事件不因未来完成字段被屏蔽而删除，未结束会话的断开时刻和总电量不参与历史输入。
- 目标：会话总电量均匀分配到接入至断开覆盖的15min格，单位kWh/15min；零时长会话仍生成事件但不生成代理电量，数量和能量单列披露。
- 没有会话的时间格表示“无已记录会话贡献”，不认证设备在线和实际零需求；完整列出按月覆盖及缺口，不因疫情或结果不利删月份。

保留原SG-DATA-006规则与LRE图定义。阈值只由调参期正规则分数95%分位数产生；目标跳变阈值只由成熟训练标签正跳变90%分位数产生；原点规则向前延续2格并向4步广播。规则与目标事件标签的用途分开。

## 4. 比较对象与训练预算

唯一实验配置：`configs/experiments/SG-EXP-028-jpl-independent-site.json`。

|身份|模型|种子|次数|
|---|---|---|---:|
|主要比较|完整MRG、等容量TCN、完整AGCRN|2024、2025、2026|9|
|预登记组件对照|等参数节点共享门控MRG|相同三种子|3|

合计12次。AGCRN保留NAPL、DAGG、两层递归、Chebyshev阶数2和多步输出，不以旧简化变体代替。TCN宽度只按参数量匹配，搜索整数32—64，不按误差选宽。共享门控使用SG-EXP-027定义，参数不删除、不增加。

所有配置为既有固定设置：hidden32、TCN六层、历史96步、输出4步、batch256、AdamW、学习率0.001、weight_decay0.0001、最多60epoch、patience8、标准化L1、梯度裁剪5、float32确定性执行；各模型额外超参搜索预算均为0。仅调参集原单位MAE用于早停和best选择。此为同预算固定配置比较，不声称每种方法已经穷尽最优调参。

确定性策略沿用已完成SG-EXP-019/027的分段切片+matmul TCN实现，不恢复旧CUDA慢速膨胀卷积路径。`CLAUDE.md`历史禁令针对尚未修复的慢卷积状态；本预登记明确以当前已核验实现与用户既有确定性实验要求为准。后续GPU smoke仍须测速并核对算子实现，不因速度问题暗中关闭确定性或改变预算。

校准集不参与训练与模型选择。全部12个run的配置及best checkpoint封存后才允许导出测试；每种子测试一次，不依据测试增加轮数、改变节点/图、挑种子、换指标或后处理。若运行达到60轮上限，记录为预算内结果，不称渐近收敛。硬件或环境变更须新运行版本，失败证据保留。

## 5. 指标、统计与“赢”的判据

主要指标固定为共同原点×四步×十节点键上的整体MAE。必须同步报告RMSE、非零和零目标MAE、事件/平稳MAE、四格数量/MAE/绝对误差贡献、逐节点和逐步长MAE、参数量、实际训练epoch、best epoch及同硬件推理延迟。分层结果不得事后顶替主要指标。

三种子报告mean±样本std（`ddof=1`），全部种子保留。每个7日UTC原点时间块保留所有节点、步长及三种子配对差值，重采样10,000次，随机种子20261005。报告`baseline − MRG`的95%区间和三组主要配对的Bonferroni 98.333333%区间；1日块仅为敏感性。至少12个周块，不足则只作描述性统计。随机种子波动与时期波动分开解释，重叠滑窗不作为独立样本。

只有MRG整体三种子均值同时低于完整AGCRN、等容量TCN且相应校正配对区间排除0时，才在这个独立场站、固定预算范围主张整体优胜。否则明确实际最优模型；若仅对TCN、共享门控或某分层有优势，限定范围报告，不回避完整基线。参数少不能直接推导运行更快或省电。

## 6. 次要区间验证

预登记alpha=0.1，比较独立校准集的全局校准、冻结行为分层校准与14天成熟标签约束滚动校准。有限样本分位数为第`ceil((n+1)(1-alpha))`个次序统计量，超出n时为正无穷；不存在可用分层样本时如实保留不可用，不暗中选择更有利回退。滚动只使用每天截点前已成熟标签，不重训；固定规则不借未来目标事件路由。

必须同时报告整体/事件/平稳覆盖、平均区间宽度及区间分数；漂移条件下不预先承诺90%覆盖。次要区间结果不用于模型选择，不能根据测试覆盖改变窗口或alpha。

回收后核对来源与代码哈希、共同预测键/真值、best选择和所有种子，再做统计和区间评价。主论文、唯一DOCX、旧36次和门控6次结果本轮不修改。结果未核验前不得将JPL提升为已完成跨站证据。
