### P1-1：第五章统计口径有具体修订空间

**已确认事实：**

- 正文式（5-1）描述下一步TE：`H(Y[t+1]|Y[t]) - H(Y[t+1]|Y[t],X[t])`。
- `scripts/analyze_transfer_entropy.py:131` 的三元组为 `(X[t-lag],Y[t-lag],Y[t])`。因此lag=2、4时，实际计算是 `H(Y[t]|Y[t-lag]) - H(Y[t]|Y[t-lag],X[t-lag])`，与只写“下一步”的叙述不完全对应。
- 脚本在lag=1、2、4分别检验，然后取每个有向对的最小p值及对应TE/lag，见脚本第283—293行。正文目前只写多滞后估计和名义p<0.05，未明示最小p筛选。
- 存档TE摘要含90对的最小p矩阵和选中lag，`n_perm=100`；未保存每一对三个滞后的完整p值。每次置换检验p值的最小分辨率是1/101。
- 双方向TE可能来自不同的选中lag。因此式（5-2）的不对称度同时包含方向、滞后和选择差异；阈值0.3是描述性筛选，不能直接当方向差异显著性检验。
- PCMCI脚本第59—65行直接以完整矩阵中的p<0.05筛选，而摘要只保存通过阈值的80条边，没有保存完整p矩阵。仅对这80条边校正会遗漏原检验家族。

**具体行动：**

1. 先明确要保留的统计定义。沿用现有数据时，将式（5-1）写成lag特定定义，并说明这是粗粒度滞后预测信息筛查；若要分析“源滞后改变、目标条件保持上一片”的问题，则需改统计脚本并重新做统计分析。
2. 明示三滞后最小p筛选，预先确定节点对内滞后选择和节点对之间的多重比较处理方式。不能只对已经选中的76条边做校正，也不能将筛选后的最小p值当作未经选择的原始p值。
3. 对TE保留逐对、逐lag完整结果；对PCMCI保留完整p/统计量矩阵、节点顺序与滞后范围，再进行适合检验家族及依赖条件的校正。Tigramite提供可选p值校正接口，具体实现需核对本地安装版本：[官方文档](https://jakobrunge.github.io/tigramite/)。
4. 在同一lag下比较双方向，或者将当前结果明确称为“各自选中滞后下的数值不对称”。补做分箱、置换次数等统计敏感性时固定规则，完整报告不利结果。
5. 原始76/90、44/76保留为未校正探索记录；校正后候选若减少，照实更新正文及结果图，不以维持边数作为方法选择目标。

这项工作主要是正文口径修订和统计复核，不需要重新训练MRG-GCN。它可改善统计解释的可靠性，不能自动提高点预测优势或方向图创新性。以上是代码与正文的直接对照，不据当前源码单独认证历史运行使用了同一代码版本；执行复核前还应锁定存档脚本来源。

### P1-3：可复现性优先复用现有训练产物

JPL报告已核对182项文件哈希及12个best/last锁；问题不在于“JPL没有环境和检查点”，而在于主论文证据包依赖另一交接目录，后来核心审计没有重新核验全部远端环境/检查点合同。应先列出现有材料，复用既有锁及环境记录，不重复声称做了一项全新训练。

### P2-1：MDP的价值需要正面论证，而不是累积免责声明

表4-1已写研究问题、操作和边界；新增相同表不会增强贡献。应补的是它如何改变研究判断：L1阻止把β大小或冻结替换退化当独立贡献；等权重训练提供不同问题的对照；L2输出当前替代尝试的未决因素；L3定位稀有困难键，并推动第5章核验路由与覆盖失败。

### P2-2：训练预算公平不等于已排除优化差异

表3-9共享门控一个种子达到60轮上限，JPL共享门控seed-2024也达到上限。共同预算与选模规则是合理控制，但尚不能证明对照已充分优化。先核查已有验证曲线、best/last轮次、最佳点距上限、日志记录与检查点选择；展示全部种子而非挑一个有利示例。

已有材料足以强化“在既定预算条件下节点级门控有条件性增量”。若进一步主张优化充分后仍有结构优势，才需在预先固定的延长预算/控制方案中重新训练。行为GRU、容量匹配AGCRN和受控蒸馏同样属于新增实验选项，当前分析不将它们自动列为必做，也不因补跑后结果不利而删去。

### P2-3：第五章重组的收益是主线清楚，而非人为增加性能贡献

## 四、加分规划与执行顺序

按现有77.5/90作规划，达到至少88/100需要79.5/90（88.33/100）；79/90仅为87.78。因此需净增2个原始分。该算术不代表预定四项各加0.5，也不保证满分项校准后仍维持这一起点。

优先顺序建议：TE定义与选择口径复核 → 关键近邻原文与差异闭合 → 现有检查点与便携证据链 → 核心贡献/MDP判断流程与第五章结构统一 → 视资料和必要性决定一项有明确问题的补充验证 → 同量表新旧材料配对复评。

每项正式加分必须有完成工件、稳定正文定位及独立核验。不同要求可以共享证据，但不能将同一“写得更清楚”同时当成方法设计、结果充分和创新性三项新增能力。若仅完成表述修订，优先评价主线与规范；若结果经复核支持更窄的结论，也应保留，不用分数目标筛选结论。
