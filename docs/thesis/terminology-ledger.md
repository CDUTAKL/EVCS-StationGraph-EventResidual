# 术语台账（Terminology Ledger，2026-08-03 建立）

> 全篇强制统一，新增术语需登记。

## 模型与方法

| 规范形式 | 禁止/废弃变体 | 定义边界 |
|---------|--------------|---------|
| MRG-GCN（多关系门控图卷积网络） | Multi-Relation Gated GCN、多关系门控图卷积（首次出现可并列中文） | 本文核心方法全称；正文首次出现给全称+缩写 |
| LRE 三关系图 | 三类关系图、Load/Event/Pattern 图（正文可用 LRE 缩写） | load=绝对 Pearson 相关 / event=行为信号余弦相似 / pattern=96 步轮廓欧氏指数核 |

| EventResidual | 事件残差模型、残差修正模型 | SG-EXP-005；事件窗口边际改善≈0，正文按探索性定位表述 |

## 数据与口径

| 规范形式 | 禁止变体 | 定义边界 |
|---------|---------|---------|
| 节点代理负荷 | 代理负荷、重构负荷（首次出现并列） | 会话记录重构，非电表实测功率 |
| 标签事件窗口（`target_event`） | 真实事件标签、外部事件真值、异常窗口 | 由未来4个预测步中的接入、离站或负荷突变标签定义，仅用于事后评价与分层，不是人工核验的现实事件真值 |
| 规则触发（`rule_trigger`） | 事件预测标签、真实事件 | 由预测起点可见的冻结规则生成，用于四格诊断和规则路由 |
| 稳定窗口 | 正常窗口 | 非事件窗口样本 |
| 冻结规则 | 验证集阈值、95 分位阈值 | 验证集非零事件分数 95 分位冻结，测试集仅执行 |
| 因果前向窗口扩展 | 前向扩展、窗口扩展 | 触发点仅向未来扩展，不向过去 |
| 四格诊断 | 四格分析、误差四格 | 目标侧标签事件 × 可见规则触发，加权还原全局 MAE ≤1e-9 |
| 规则路由分层共形 | 分层共形、规则共形、可部署路径 | 在本文比较路径中可于预测时执行，但经验覆盖未达目标，不称可靠或已经可部署 |
| 标签事件事后参照（oracle） | oracle 上界、理想上界、可部署结果 | 使用预测时不可获得的目标侧标签事件进行分层，只作事后参照 |
| 分层参数干预敏感度 | CATE、参数干预因果、因果效应 | 参数干预功能敏感度，不涉因果 |

## 指标

| 规范形式 | 禁止变体 | 边界 |
