# 图5-3口径与输出核验

## 统计口径

- 每个散点代表一个无向节点对，横纵坐标为两个方向各自按最小置换$p$值选择滞后后的TE读数。
- 不对称度按$|F-B|/(F+B+\epsilon)$计算，阈值为0.30。按该定义，45对中20对超过阈值（44.4%）。
- 修订前绘图脚本使用$|F-B|/\max(F,B)$，得到29/45；该量与主文式（5-2）不一致。本次将图、脚本和正文统一为和分母，20/45是更新后的正确计数。
- 20/45是描述性比例，不是两个方向TE差异的显著性检验。TE全部270项“有向对×滞后”检验经Bonferroni校正后均未保留（最小调整后$p=1.00）。
