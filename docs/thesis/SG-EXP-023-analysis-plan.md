# SG-EXP-023 独立校准与创新增益补充分析

2026-10-03，在读取新增覆盖与配对统计结果前固定本方案。既有测试时期已查看，因此该方案为事后补充分析方案，不称首次测试前预注册。

目标：核对代理序列能量守恒和信息权限；定位新协议关系路径的误差改善来源；检验新协议独立校准段下区间的覆盖与宽度。冻结SG-EXP-019模型、预测、数据、规则与点预测排名。

配置：`configs/analysis/SG-EXP-023-independent-calibration.json`。本地CPU只读归档预测，无训练，无付费实例。模型仍用tuning选择；区间半宽只用calibration确定，target_event仅作事后评价。alpha=0.1，有限样本秩为ceil((n+1)(1-alpha))；逐节点标准路径及行为规则分层路径两种，不能依据测试覆盖选优或增宽。

同时报告覆盖、平均宽度和90%区间分数，后者为宽度加2/alpha倍超出区间的距离。按原点当地日期分七日非重叠块、2000次配对Bootstrap；保留全部节点、步长、种子，种子先平均，时间块重采样。区间描述本历史时期的不确定性，不构成交换性保证、多终点显著性或未来时期保证。

主要结构对照预先固定为mrg_full对tcn_wide、自环变体；其余关系/内部组件/完整AGCRN只作补充描述。逐节点、事件/稳定、零/非零、月份分层保持原掩码、时间键和真值。新旧协议结果不合并。

数据守恒核对仅证明总会话电量与分摊目标相符，不证明峰值、充电过程或实时功率真实性。训练对照仅根据既有4090/4090 D日志估计耗时，本轮不执行。

来源审计、逐种子指标、校准秩/样本数、逐键区间、配对统计、时间日志和manifest保存至独立输出目录；完成后进入正文3.7.5与5.3的限定性说明及一张小结果表。
