## 1. 对当前阶段 A/B 结果的准确理解

| 实验 | 当前最优配置 | 验证集 MAE | 阶段性含义 |
|---|---|---:|---|
| B1 TCN | `levels=6, hidden=32` | 0.05958 | 纯时间建模基线 |
| B2 StaticGraph | `top_k=3` | 0.01592 | 固定站内多关系图带来主要增益 |
| B3 AdaptiveGraph | `embed=12, fixed_weight=0.5` | 0.01509 | 在固定图基础上继续改善 |
| B4 EventResidual | TCN base | 0.05947 | 纯时间底座上的局部修正收益有限 |
| B5 调度对照 | ReduceLROnPlateau | 0.05958 | 学习率调度不是性能差异的主要来源 |
| B6 Static base + 修正器 | 阶段性配置 | 0.01581 | 全局改善很小，事件窗口 MAE 初步改善 4.6% |

当前可以形成四个**研究假设**，但尚不能直接形成最终结论：

1. **站内图结构可能是主要性能来源。**  
   固定图模型相对 TCN 的验证集误差差异达到量级变化，说明单节点独立时间外推没有充分利用站内节点之间的共同变化。

2. **自适应关系可能补充固定统计关系。**  
   自适应图在固定图基础上继续改善约 5.3%，说明训练集构建的负荷、事件和时间模式关系仍可能存在表达不足。

3. **事件残差修正必须建立在合适的图底座上。**  
   TCN 底座上的修正近乎无效；固定图底座上的修正对事件窗口出现初步收益。其机制原因必须由阶段 D、多底座对照和 SG-EXP-006 消融共同验证，不能先写成确定因果解释。

4. **局部修正是条件性增强，不是主模型替代。**  
   新路线的主要模型应是站内多关系图时空预测模型；事件残差修正是针对少量事件窗口的附加模块。

## 4. 研究问题树

### 总问题

如何从离散充电会话记录中构建可用于预测的站内节点代理负荷，并利用节点间多种统计关系，提高短期预测精度和事件窗口响应能力？

### 子问题

1. **数据问题**：不同起止时间的会话记录如何重构为统一的 15 min 节点时序张量？
2. **时间问题**：单节点历史负荷和可见行为特征能够提供怎样的默认预测能力？
3. **空间问题**：站内节点之间的负荷相关、事件共现和时间模式关系是否能改善预测？
4. **关系问题**：固定统计图是否足够，是否需要学习随任务变化的自适应关系？
5. **事件问题**：局部事件窗口中，能否在图底座预测上增加有界残差修正，同时保持稳定窗口性能？
6. **证据问题**：模型收益来自时间建模、图关系、自适应关系还是事件修正？能否通过消融、敏感性、四格诊断和多随机种子检验解释？

## 5. 预期贡献与证据状态

> **2026-07-30 修订**：基于调研反馈，从原来的 4 个贡献重构为 3 个。
> "会话重构"从创新点降格为第 3 章技术基础（同类论文均不将其列为创新）；
> "事件残差修正"与"事件加权损失"合并为统一的"事件感知机制"叙事；
> 核心创新聚焦到"多关系门控 GCN + 自适应图协同"。

### 贡献 1：站内多关系门控图卷积预测模型（核心）

- 构建三类固定统计关系图（负荷相关、事件共现、时间模式）；
- 设计两层门控多关系图卷积，每层独立学习关系融合权重；
- 采用图特征 MLP 精炼与跨层跳连融合；
- 通过关系消融实验逐类验证每种关系的增量价值。

**状态**：阶段 B 验证结果强支持（StaticGraph 相对 TCN 提升 3.74 倍）；最终贡献强度等待阶段 D 三随机种子 + AGCRN 公平对比。

**差异化**：调研 18 篇 GNN 时空预测硕士论文中，仅 5 篇涉及多图，且无一篇使用门控融合机制进行关系选择——这在硕士论文层面具有先发优势。

### 贡献 2：固定图与自适应图协同的关系学习

- 基于节点嵌入学习任务相关的第四类隐式关系（不依赖先验统计量）；
- 通过可学习权重 α 将自适应图与固定图混合，实现"补充而非替代"；
- 可视化自适应图与固定图的差异，证明学习关系捕获了固定关系未覆盖的节点依赖。

**状态**：阶段 B 初步支持约 5.3% 的验证集增益；等待三随机种子 + 自适应图可视化确认。

**差异化**：与 AGCRN（自适应图替代固定图）不同，本文的协同策略保留了可解释的固定统计关系，同时允许数据驱动的隐关系作为补充——这在充电站"有先验统计知识但可能不完整"的场景中更合理。

### 贡献 3：事件感知的层次化评价与训练策略

- 设计验证集冻结的因果前向事件窗口规则（仅向未来扩展，避免信息泄漏）；
- 构建"目标事件 × 规则触发"四格诊断框架，按样本量加权精确还原全局 MAE；
- 探索事件窗口稀疏分布（~0.1% 样本）下的梯度稀释问题，引入事件加权训练策略；
- 对比"架构修正"（EventResidual）与"优化修正"（WeightedL1Loss）两种事件感知路径。

**状态**：事件规则和四格诊断已完成（可作为确定性内容撰写）；事件加权损失代码就绪，待 SG-EXP-007 筛选实验确认效果。

**差异化**：调研中未发现将事件信息显式编码为损失权重的硕士论文；"冻结规则 + 因果窗口 + 四格诊断"的评价协议在硕士论文层面属前沿实践。

# 第 1 章 绪论

## 1.1 研究背景与意义

### 1.1.1 电动汽车充电负荷增长与节点级预测需求

- 说明充电设施规模增长及运行调度需求；
- 区分站级总负荷和站内节点级负荷；
- 指出站内节点受到车辆接入、离站和会话重叠影响，局部波动更强。

### 1.1.2 离散会话记录与节点代理负荷预测问题

- 原始数据是一条条具有不同起止时刻的会话记录；
- 需要重构为统一时间轴上的节点代理负荷；
- 明确代理负荷与真实在线功率的边界。

### 1.1.3 站内节点关系与事件窗口预测意义

- 节点变化并非完全独立；
- 单节点时间模型可能忽略同时或相似变化；
- 全局平均指标可能掩盖少量事件窗口的误差。

## 1.2 国内外研究现状

### 1.2.1 电动汽车充电负荷时间序列预测

- 统计模型、机器学习、循环网络、TCN、Transformer；
- 总结其时间依赖建模能力和单节点独立预测局限。

### 1.2.2 多节点负荷与时空图预测

- STGCN、Graph WaveNet、AGCRN 等代表思路；
- 讨论固定图、自适应图和多关系图；
- 强调本文研究的是站内统计关系图，不是配电网拓扑。

### 1.2.3 充电行为特征与事件窗口建模

- 讨论接入、离站、活跃会话和负荷突变；
- 指出现有研究多把行为特征作为一般输入，较少专门诊断局部事件窗口。

### 1.2.4 残差学习、条件修正与分层评价

- 介绍残差修正和条件性增强；
- 讨论全局、事件、稳定、节点和步长分层评价；
- 引出验证集冻结和测试集隔离的重要性。

## 1.3 现有研究不足

建议归纳为四点：

1. 离散会话记录与站内节点时序之间缺少可追溯重构；

3. 固定关系难以完全反映预测任务中的动态依赖；
4. 事件窗口局部修正与稳定窗口保护缺少统一、可复核的评价协议。

## 5.6 事件感知机制二：事件窗口加权训练（优化路径）

> **新增节（2026-07-30）**：阶段 B 实验揭示 EventResidual 在 TCN 底座上几乎无效（改善仅 0.2%）、
> 在 StaticGraph 底座上事件窗口仅改善 4.6%。根因分析指向事件样本占全部样本 ~0.1% 导致的
> **梯度稀释**：标准 L1Loss 下事件样本的总梯度贡献被 99.9% 的稳定样本主导。
> 本节从重要性采样视角引入事件加权训练策略。

### 5.6.1 梯度稀释问题形式化

- 全局 MAE 分解：MAE ≈ P(stable)·E[|e||stable] + P(event)·E[|e||event]
- 标准 L1 梯度贡献比例 ≈ P(stable) : P(event) ≈ 999:1
- 事件窗口预测偏差无法通过常规训练有效优化

### 5.6.2 二值事件加权损失（Binary Weighted L1）

- weight = 1.0 + λ × rule_trigger
- λ ∈ {2, 3, 5} 筛选
- 事件梯度贡献从 ~1% 提升到 13%（λ=2）~23%（λ=5）

### 5.6.3 连续事件强度加权（Intensity Weighted L1）

- weight = 1.0 + λ × event_score_norm
- 基于 visible_event_scores 的连续事件分数
- 高分事件（多特征同时激活）比低分事件获得更高权重

### 5.6.4 两种事件感知机制的互补性讨论

- 架构修正（5.5）：在推理时对底座预测做局部调整，不改变底座行为
- 优化修正（5.6）：在训练时重新分配梯度注意力，改变底座参数
- 两者正交互补：加权训练让底座在事件区域学得更好 → 残差修正的修正量需求减小

## 5.7 训练、冻结与推理流程

- 底座模型先训练（使用加权损失或标准损失）；
- 若启用 EventResidual：冻结底座后训练修正器 MLP；
- 事件阈值和窗口规则由验证集冻结；
- 测试阶段不重新估计规则和关系。
