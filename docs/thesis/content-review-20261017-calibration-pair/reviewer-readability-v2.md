## [76]近邻核验：重叠、区分与对论文定位的影响

包内 `evidence/NEAR76-primary.md` 给出出版社原文页核验：[Liang (2026), *World Electric Vehicle Journal* 17(7), 336](https://www.mdpi.com/2032-6653/17/7/336)，DOI `10.3390/wevj17070336`，出版社记录日期为2026-06-29，早于本稿。证据记录核实其提出 PARC 残差校正：以持续性预测保留当前水平，以预测时点安全的滞后、滚动统计、爬坡和周期特征学习修正项；主实验用加工后的配电负荷代理序列，EV 验证用公开 Boulder 充电交易数据重构的充电负荷序列；并报告直接预测／残差预测对照、滚动起点、日块重采样和配对检验。结果依指标而异：持续性／季节性混合在 sMAPE、正负荷 MAPE 较优，直接 HistGBR 在 MAE/WAPE 较优，PARC-ExtraTrees 在 RMSE/R² 较优。证据明确禁止把其主实验误写成实测 EV 功率，也不支持跨论文误差排名。

本文与[76]有实质重叠：两者都涉及由公开 EV 交易／会话记录构造的负荷代理预测；[76]也已涉及残差校正和多指标结果。因此，当前稿不能让读者把“EV 代理负荷预测”或一般残差修正理解成本文的首创。可辨识的边界仍然具体：据已核验范围，[76]没有报告本文式的单场站内部多节点统计关系图、节点级门控、关系邻接替换重训或 MDP 三层诊断；两个研究的节点粒度、目标构造、预测时距和验证协议也不同，不能横向排误差名次。

**判断：当前近邻综述不足以充分解释[76]与本文的重叠和区分。** §1.2.3 只把[75–76]合并概括为“基线预测—风险时段识别—选择性残差修正”一类路径，再笼统说事件定义、可见信息、阈值和修正路径有差异。它没有告诉读者[76]用了 Boulder 交易重构负荷、持续性锚点／残差学习、直接与残差模型同特征对照、或出现指标依赖的结果；也没有明确指出本文具体不覆盖什么。这个缺口在 baseline 与 current 都存在，因为两稿 §1.2.3 和表1-1未因新增原文核验而补写比较。

对定位的实际影响是：**不推翻**本文较窄的“单场站内部节点关系及其条件性增量／诊断”主张，但**收窄**“公开 EV 代理负荷预测与残差路径”作为一般新颖性的表述空间。当前摘要已具体聚焦站内关系、节点门控和 MDP，并没有声称一般代理负荷预测首创；仍建议在 §1.2.3 加一个短的正面对照，并在 §1.3/§1.4 或摘要用一句话明示贡献边界。对应分数变化体现在 BR-03 gap 与 BR-10 prior_difference，两版本同分；未把同一遗漏重复扣在 BR-12。

## 缺陷、已声明限制、后续拓展与未核实疑点

- **已证实的文本缺陷**：两稿 §1.2.3 没有用新增的[76]出版社原文事实展开直接近邻比较；“不同研究存在差异”的概括没有具体落实到目标、节点粒度、输入、残差方法和验证结果。影响 BR-03 gap 与 BR-10 prior_difference。建议加一段紧凑对照，并明确本文贡献集中于单场站内部节点关系及其条件增量／诊断。
- **已声明的范围限制（不是新缺陷）**：目标为会话电量均匀分摊代理、非实测连续功率；行为计数片末可见是建模假设且无上报时延核验；JPL与Caltech属同一 ACN 数据体系并且时期重叠；许多补充分析复用了已查看测试期；完整 AGCRN 容量更大，部分共享门控运行触及训练上限；区间事件覆盖不足；合成决策例不代表现场收益。正文、S31/S32、QUALITY、PASSPORT、DATA-AVAIL 证据对这些限制有对应说明。
- **后续拓展**：同步电表和输入到达时间戳、未查看时期／不同数据家族、替代目标下重建关系图、共享门控更长且一致预算、容量／输入／预算匹配的学生替代实验、真实站点影子运行。它们对应更强主张，不反向否定本文已限定的结果。
- **未核实疑点**：图像与实际排版无法从本包检视；原始训练源码／每一历史模型完整版本认证在部分记录中受限；现实上报延迟及代理标签到电表功率的效度仍缺证据。这些只列为检查／补证事项，不据此指控数据错误或自动判定图表有误。
