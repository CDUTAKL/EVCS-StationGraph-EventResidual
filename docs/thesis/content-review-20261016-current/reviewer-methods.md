# 侧重评阅二：方法、统计与替代解释

**版本：** 当前主稿SHA见packet-manifest.json。  
**独立性：** 这是同一评阅上下文中的方法侧重审阅，不是独立盲评或现实专家意见。

## 直接证据

SG-EXP-031的12个运行参数量均为32,714，同种子非图初始参数配对；三种子共享632,640个测试键。负荷和轮廓替换的全局MAE配对差多重校正区间下限高于0，行为替换区间跨0。审计标识其为固定JPL测试期上的事后诊断。SG-EXP-032的六个运行在708,560个共同键上通过审计；完成时刻截断目标下全局MAE排序保持，非零目标组MRG-GCN仍高于TCN。

## 方法判断

当前稿区分了自环替换重训练、冻结β干预、时序蒸馏和模型间比较，避免将它们混为“关系必要”或“β独立重要”。门控同参数比较仍有共享门控seed在60轮触顶；AGCRN容量不匹配，行为GRU缺失，L2学生的容量/输入/目标不匹配。若主张扩大到更长预算或图结构不可替代，这些对照必须补齐；当前正文已把主张缩窄，未将这些缺口当作已解决。

## 评分影响

关系非零分层来自同一已查看测试数据，三种子均同向，但未做分层校正；它提升论文对效应分布的描述，不构成新确认实验。因此不提高BR-08或BR-09。方法设计维持BR-05 8.5，证据充分性维持BR-08 8.5。


## 五轴评阅

- **整体判断：** 核心训练合同、共同键比较和结果审计支持限定性结论；这些证据不足以支持更广泛的架构必要性或未来泛化主张。
- **可能关心的读者：** 时序预测、图模型实验设计、机器学习结果审计和负荷评估研究者。
- **主要优点：** 031只替换指定邻接且同参数配对；032固定输入、关系图与预测键而改变标签规则；正文将两者定义为事后补充。
- **主要疑点：** 共享门控触顶、容量近似与否不等于功能等价、蒸馏条件不匹配、目标仍为代理。
- **技术问题：** 新增非零分层是同一已查看测试集上的未校正分析；不能按确认结果解读。实际功率映射和未见时期尚未验证。
- **五轴判断：** 原创性来自受控任务证据而非新算子；科学重要性在于指出整体MAE与活跃样本排序会不同；跨学科用途是评价协议设计；技术论据对当前范围成立；可读性因说明比较对象而改善。
- **建议姿态：** 适合在限定主张下继续导师审阅；若扩张门控优势或图结构不可替代结论，应补齐预算匹配或学生对照。
