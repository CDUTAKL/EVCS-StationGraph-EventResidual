# 基于站内多关系图与机制诊断的充电节点短期负荷预测研究

# 摘  要

场站内充电节点负荷呈强零膨胀，Caltech测试键中87.25%为零目标，整体MAE易被零值段主导，掩盖活跃片段与事件的差异。以公开会话记录重构的15 min节点代理电量为对象，在整体MAE之外构建受控比较与误差分解协议，回答三个问题：站内三类统计关系是否带来可归因的增量、整体误差由哪些样本构成、模型排序是否随标签口径变化。

方法上以负荷耦合、行为共现、轮廓相似三类关系构建关系图，用多关系门控图卷积网络（MRG-GCN）作关系编码的载体，以`load_lag1`为基准、由模型预测残差，并把软门控输出头（QMH）保留为输出头对照；对每条关系作同参数自环替换重训（JPL，12次配对运行），对节点门控作同参数共享门控配对，对JPL独立重拟合，并按“事件标签×规则触发”分解误差，对12种配置在两种标签下作冻结排序比较。每次比较只改变一个因素，使增量可归因。

（1）针对零膨胀节点负荷下整体MAE被零值键主导、且行为特征无法替代历史负荷的问题，本文提出残差化多关系门控图卷积模型：以`load_lag1`为基准、由模型只预测残差，并以负荷耦合、行为共现、轮廓相似三类关系图编码跨节点信息。在Caltech事件时刻协议上，三种子（2024–2026）均值下整体MAE为0.015704，为表3-2所列全部对照中最低；零值层MAE为0，非零层为0.0878，参数量33,902，较无图的残差TCN（0.030709）低48.9%、较persistence基线（0.015896）低1.2%。新旧对照显示，原七特征非残差配置的整体MAE为0.036326，补入`load_lag1`并改为残差预测后降低56.8%，故输入缺历史负荷是原模型的根本约束。容量与输出头对照表明该结果不来自参数扩充：同一骨干的hidden 32线性头为0.016682（高于主模型6.2%），残差QMH头为0.027243，均高于主模型；容量匹配AGCRN（残差）为0.017489，按三种子协议运行、现仅完成seed-2024。工程价值上，全站十个节点由单一模型一次前向覆盖，不依赖逐节点独立训练。两站120轮扩展预算下，节点门控相对共享门控的整体MAE分别低3.08%与2.89%，JPL容量匹配AGCRN的整体MAE为0.082111，高于MRG-GCN的0.081067。

（2）针对整体误差无法归因到关系类别与样本层级的问题，本文提出分层评价协议（MDP），把关系增量按评价层、标签口径与参数配置分别测量；三层证据分别回答配置依赖、特定替代尝试与误差构成，其中L1受消息尺度影响、L2在结构上不能回答图结构必要性。回溯协议中1.39%的预测键贡献28.10%的绝对误差，交叉分组分解经加权还原校验自洽；冻结预测上替换标签口径后全局排序相关为0.993，非零层仅0.420且区间跨零，故非零层排序不宜单独作为选型依据。

（3）针对关系图增益默认成立、缺少可归因测量的问题，本文提出关系增量的条件性测量方法，以同参数自环替换重训与同参数门控配对逐条关系剥离增量。负荷耦合与轮廓相似分别带来1.82%与1.52%的整体MAE增量，行为共现为0.15%且区间跨零而不计为增量；JPL整体MAE较三项预先设定基线低2.64%—3.36%，软门控QMH取得0.079685（五种子均值），较完整AGCRN低4.45%。同源第三场站ACN Office 1的小规模复核与上述方向一致，其中与容量匹配AGCRN的比较在三个种子中两个同向、一个反向。

适用条件为：目标是会话电量均摊重构的代理电量而非计量功率；证据来自ACN同一数据体系的三次重拟合，不含跨运营商与未来期验证；名义90%区间在测试期实测覆盖69.6%与79.55%，事件层仅1.9%—3.87%，尚不能直接用于运行核查。

关键词：充电节点短期负荷预测；代理电量；零膨胀；受控对照；误差分解；使用边界

# Abstract

Charging-node load is strongly zero-inflated: 87.25% of Caltech test keys are zero targets, so aggregate MAE can be dominated by the zero segment and can conceal differences on active intervals and events. Taking 15-min node proxy energy reconstructed from public session records as the object, and going beyond aggregate MAE, this thesis builds a controlled comparison and error-decomposition protocol to answer three questions: whether the three within-station statistical relations bring attributable predictive gains, which samples constitute the aggregate error, and whether model rankings change with the label definition.

The protocol builds relation graphs for load coupling, behavioral co-occurrence and profile similarity, uses a multi-relational gated graph convolutional network (MRG-GCN) as the relation encoder, takes the previous-step node load (`load_lag1`) as the base and predicts only the residual, and keeps a soft-gated output head (QMH) as an output-head control, compares each relation against a same-parameter self-loop replacement with retraining (JPL, 12 paired runs), sets node gating against a same-parameter shared gate, refits JPL independently, decomposes error by event label by rule trigger, and ranks 12 configurations on frozen predictions under two labels. Each comparison changes one factor so that the increment can be attributed.

(1) For the problem that aggregate MAE under zero-inflated node load is dominated by zero keys and that behavioural features cannot substitute for historical load, this thesis proposes a residualised multi-relational gated graph convolutional model: it takes the previous-step node load (`load_lag1`) as the base and predicts only the residual, and encodes cross-node information with the three relation graphs of load coupling, behavioural co-occurrence and profile similarity. On the Caltech event-timestamp protocol the three-seed (2024–2026) mean aggregate MAE is 0.015704, the lowest of all controls listed in Table 3-2; the zero-layer MAE is 0 and the nonzero-layer MAE is 0.0878, with 33,902 parameters, 48.9% below the graph-free residual TCN (0.030709) and 1.2% below the persistence baseline (0.015896). The new-versus-old contrast shows that the original seven-feature non-residual configuration reached 0.036326 aggregate MAE, so adding `load_lag1` and switching to residual prediction lowers it by 56.8%; the absence of historical load in the input is therefore the root constraint of the original model. Capacity and output-head controls show that this result does not come from extra parameters: the hidden-32 linear head of the same backbone reaches 0.016682 (6.2% above the main model) and the residual QMH head 0.027243, both above the main model, while the capacity-matched AGCRN (residual) reaches 0.017489 on the three-seed protocol with only seed-2024 completed so far. On engineering value, one model covers all ten nodes of the station in a single forward pass without per-node independent training. Under the 120-epoch extension budget the node gate lowers aggregate MAE by 3.08% and 2.89% on the two stations, and the JPL capacity-matched AGCRN reaches 0.082111, above the 0.081067 of MRG-GCN.

(2) For the problem that aggregate error cannot be attributed to relation type or sample layer, this thesis proposes a layered evaluation protocol (MDP) that measures relation increments separately by evaluation layer, label definition and parameter configuration; its three layers answer configuration dependence, a specific substitution attempt and error composition, where L1 is affected by message scale and L2 cannot answer the necessity of graph structure. In the retrospective protocol 1.39% of prediction keys contribute 28.10% of the absolute error, and the cross-cell decomposition is self-consistent under the weighted reconstruction check; after the label definition is replaced on frozen predictions the global rank correlation is 0.993, while the nonzero layer is only 0.420 with an interval crossing zero, so nonzero-layer rankings should not be used alone for model selection.

(3) For the problem that relation-graph gains are assumed rather than measured, this thesis proposes a conditional measurement of relation increments, stripping each relation by same-parameter self-loop retraining and node-gate pairing. Load coupling and profile similarity yield 1.82% and 1.52% aggregate-MAE gains, while behavioral co-occurrence yields 0.15% with an interval crossing zero and is not counted as a gain; JPL aggregate MAE is 2.64%–3.36% lower than the three preregistered baselines, and the soft-gated QMH reaches 0.079685 (five-seed mean), 4.45% lower than the full AGCRN. A small-scale recheck on the same-family third station, ACN Office 1, agrees in direction, although the comparison with the capacity-matched AGCRN reverses in one of three seeds.

The scope is deliberately a measurement one and does not propose a new graph operator: the target is proxy energy from session allocation, not metered power; evidence comes from three refits within the same ACN data family, without cross-operator or future-period validation; all comparisons are retrospective on a viewed test period. Nominal 90% prediction intervals attain empirical coverage of 69.6% and 79.55% on the retrospective and new-protocol test periods, and only 1.9%–3.87% on the event layer, so the intervals cannot yet be used directly for operational checks.

Keywords: short-term charging-node load forecasting; proxy energy; zero inflation; controlled comparison; error decomposition; scope of use

# 第1章  绪论

## 1.1 研究背景与意义

### 1.1.1 电动汽车充电负荷增长与节点级预测需求

我国电动汽车与充电设施持续增长。截至2024年底，全国公共充电桩达357.9万台[1]。到达时刻、停留时长和充电需求的不确定性，使负荷具有随机、间歇和空间不均衡特征[2-4]。现有研究多预测区域、站群或单站聚合负荷，可服务于站级规划，却难以说明站内各充电节点的负荷分配[2,3]。节点级预测更贴近多桩均衡、局部容量识别和有序充电等运维对象[5,6]。

充电运营的岗位分工体现了对站点级数据的需求。理想汽车等企业公开招聘的“充电量运营”岗位以站点为单位开展工作，职责涉及站点信息核对与录入、价格调整和运营数据复盘。若关注对象进一步细化到站内充电位置，整站汇总数据难以支撑这种判断。

聚合可平滑用户行为，单节点序列却常有大量零值、突变及显著异质性，单序列外推也难利用同站节点间的同步变化。本文据此研究：在明确代理目标口径的基础上，站内统计关系能否改善稀疏节点预测，以及这种改善适用于哪些样本层。

### 1.1.2 离散会话记录与节点代理负荷预测问题

运营平台通常记录会话节点、接入与离站时间及总电量，而非连续电表功率。本文将会话记录映射至15 min网格，构成“时间—节点”序列[7-9]。由总电量按时间规则分配得到的片段能量称为节点代理负荷；它不等于实测功率，二者对应关系需同步量测验证。数据稀疏且节点活跃度差异明显，故后续统一重构、筛选和评价口径，并避免使用易受小分母影响的百分比误差。

### 1.1.3 站内节点关系建模与事件窗口预测意义

同站节点共享运行环境，但可能呈现负荷同步、行为共现和日内轮廓相似等统计联系[10,11]。图神经网络可通过邻居传播补充单节点历史信息，已用于站群及多节点负荷预测[10,12,13]。本文的图边是训练数据中的统计关系，不表示电气拓扑；三类关系的作用通过重训练对照和冻结参数干预分别检验。关系权重与变换共同决定消息，权重大小本身不等于关系贡献。

充电接入、离站、活跃状态变化和负荷跳变构成本文所称的事件窗口，与可预先获知的节假日不同[14-17]。事件标签可事后构造，行为字段的预测时可见性仍需核验。由于稀有高误差样本可能被稳定样本稀释，本文除总体误差外，还分别检查事件、非零目标和稳定窗口表现。

## 1.2 国内外研究现状

### 1.2.1 电动汽车充电负荷时间序列预测

充电负荷预测已从统计模型、机器学习发展至深度时序、组合和概率方法[2-4,18,19]。ARIMA适于相对稳定的趋势周期，LightGBM与XGBoost可拟合人工特征的非线性关系[20,21]；LSTM、GRU、TCN和Transformer则用于提取长短期依赖[22-25]。既有研究还结合循环卷积、注意力、外部因素、分解重构、误差修正与区间预测，处理行为扰动、非平稳性和不确定性[5,7,11,26-36]。

近期工作进一步引入多尺度建模、半监督学习、场景聚类、在线辨识，以及出行、引导、排队、SOC和路网等行为变量[37-46]。这些方法丰富了区域或站群预测，但大多未以同一场站内充电节点为图节点；其行为信息也未必与本文的片末计数假设一致。相较之下，站内单节点序列更稀疏、异质性更强，需同时评价关系信息的增量和其对不同样本层的作用。

与本文的关系在于：上述研究多以整体误差作为模型取舍与精度报告的依据[2-4,18,19,24]，其共同假设是整体误差对各样本层同等代表，模型排序不随样本构成改变。本文不改变这一方法谱系，而把同一批测试键按零值、非零目标与事件标签分层核对，检验整体误差在零目标占多数时是否仍能区分模型差异。

### 1.2.2 多节点负荷与时空图预测

GCN[47]、GAT[48]和RGCN[49]分别提供邻居聚合、注意力和多关系传播基础；STGCN[50]、Graph WaveNet[51]、AGCRN[52]等进一步结合时间建模或节点自适应参数，已用于交通[53-55]、居民及区域负荷预测[56-63]。EV负荷研究也采用站群多图、区域建模和概率预测[6,8,64-70]。既有近邻研究可按图节点类型归为站间图、住宅用户图与会话重构三类；与本文任务最接近的会话代理残差方法另见1.2.3节。

站间图预测以充电站为图节点，节点关系多取地理、交通或数据驱动的关联。黄健等[13]以地域关系连接城市站点，用GCN-LSTM预测；本文仅核实摘要及页码索引，其切分和输入权限未核实，且属站间任务而非站内节点任务。张延宇等[12]构造充电站的时空与自适应关系，以多头注意力、自适应图、Chebyshev卷积和多尺度时间卷积预测；摘要报告两套数据与Palo Alto四类场景，节点/边字段、切分与输入可见性未核实。黄南天等[10]以Rapid-MIC和动态图连接多座公共充电站，用AST-GCN结合节点参数与GRU预测；本节前八项有来源核查记录，[10]仅据摘要与索引，其小时级、随机32天与消融口径未在本文复核。Xie等[70]以距离、交通网络和密度构造多图，用MGAT-MIC-LSTM融合多图与外部因素；索引报告西安10站、30 min、2021年7—9月，详细切分与变量到达权限未核实。Huang等[67]面向Palo Alto、Boulder和韩国站群，以因果感知与动态关系构建CAGLM、CRGLM及时间融合；作者稿报告27/40/14站、小时级、72 h输入、3/6/12 h预测、7:1:2切分和5次初始化，其“因果感知”不等于外部因果识别。

住宅用户图预测以个体或聚合用户为节点，用于刻画住宅侧的时空耦合。Feng等[71]以自适应邻居和时间相似图构建边，用节点自适应GCN、自适应图门控和BiGRU预测住宅个体与聚合负荷；报告三套数据和六个基线，切分与超参未核实，属方法先例而非EV同键比较。Wang等[72]以Pearson相关和传递熵建图，用多图GCN-LSTM预测住宅用户负荷；仅核实摘要，建图、切分、容量和消融未知，非站内充电任务。Zhang等[73]以时空融合图连接住宅用户，用门控图卷积与门控TCN构成STFGCN；同样仅核实摘要，建图、切分和参数共享未知，作方法先例。

会话重构研究以交易记录重建负荷序列，其任务对象与本文最接近。Liang[74]在Boulder交易重构EV负荷上比较直接预测与残差校正，其最优方法随指标改变，未报告本文式的关系自环替换和MDP；方法与指标依赖见1.2.3节。与上述三类研究相比，本文的差别在于以单场站内的充电节点为图节点、把三类统计关系逐一相对自环作同参数重训，并以MDP分离配置敏感度、学生替代性与误差构成；按已核实范围未见在同一任务、同一协议下给出这一比较。

与本文的关系在于：上述多图与多关系工作多以整体误差判定关系建模的收益[64-73]，其共同假设是该收益可归因于关系层本身，且与样本构成无关。本文沿用相近的建图对象与关系类型，但把整体误差拆到零值、非零目标与事件标签各层后再作判断，检验增量在层间是否同向（见1.2.5节）。

### 1.2.3 充电行为特征与事件建模

用户接入、离站、停留和充电需求是充电负荷波动的直接行为来源，现有研究通常将其与历史负荷、日期、气象和价格等变量一并送入时序模型[5,7,9,11,26,31]。针对可提前获知的特殊日期，已有研究通过节假日增长率修正、春节影响期划分、日期映射和特殊事件组合模型改善预测[14-17]。这类方法利用已知日历信息，其对象仍不同于运行中临时出现的接入、离站与负荷跳变。

在非日历事件方面，已有研究关注事件数据与极端误差[75]；Hwang与Suh[76]以锚点模型为基线、用语言模型修正EV充电需求的峰值残差，在Urban EV逐时数据（120个分区）与三个预测步长上与图、序列和树模型比较。[74]则在会话重构EV负荷上比较直接预测与持续性锚点残差修正。本节关注事件定义、信息可见时点和阈值确定：须避免测试期信息进入判定，并分别评价事件与常态样本。

Liang[74]以持续性预测为锚点，用预测时可见的滞后、滚动和周期特征修正残差；其最优方法随指标改变：Persistence/Seasonal在sMAPE和正负荷MAPE上最优，Direct-HistGBR在MAE和WAPE上最优，PARC-ExtraTrees在RMSE和R²上最优。该研究已覆盖会话代理负荷预测及指标依赖，本文沿用这一问题认识，将比较推进到单场站内部的关系增量：以同参数自环替换检验关系信息，以MDP区分参数配置敏感度、指定学生替代性和分层误差。两类关系的条件性增量及其与完整模型排名的区别构成本文新增的任务内知识；诊断指导改模的收益仍待验证。两文粒度、时距和协议不同，不作误差数值排名。

本文据此区分目标侧标签事件与冻结规则触发：前者用于事后分层评价，后者用于回溯规则路由和诊断。冻结阈值不等于输入实时可见，旧规则中的代理负荷差分仍依赖会话最终字段。事件窗口兼作评价与误差溯源单元；本文不预设事件机制必然改善点预测，而是检验双口径分层的差异及事件窗口的区间表现。

与本文的关系在于：上述工作或把行为变量作为附加输入，或把事件窗口作为残差来源，通常以含与不含该信息的整体误差比较其价值[14-17,75,76]，其共同假设是事件信息的价值可在整体误差上稳定读出，且各类事件窗口对误差的贡献相近。本文不作更强的行为建模，而把事件同时用作评价切分与诊断路由，以目标侧标签事件与冻结规则触发的交叉分组核对误差构成，检验上述假设在分层后是否仍成立。

### 1.2.4 模型可解释性与机制诊断

解释方法包括SHAP等外部归因，以及注意力、门控和隐状态等内部信号分析[62,77-80]。它们可提供线索，但权重大小不等于功能必要性，仍需受控干预核验。事件价值加权评分[81]按样本重要性对误差加权，用于区分高价值时段的“坏误差”与低价值时段的“好误差”；本文处理连续代理负荷，不引入运营代价权重，而以交叉分组（按目标侧事件标签与冻结规则触发交叉划分的四组样本）描述样本数与绝对误差构成，不将其解释为经济或运行价值。

本文以同参数重训练与MDP检验上述信号，结论限定于这些任务内证据。

与上述可解释性方法相邻的两类工具在本文中承担不同角色。传递熵[82]与PCMCI+[83,84]用于在训练段筛查节点间的方向性依赖，只作为关系候选与阴性证据，不进入预测模型；共形预测[85,86]及分布漂移下的自适应共形[87]用于给出区间覆盖的经验边界，其覆盖率在冻结规则下评估。把这两类工具与预测性能分开报告，是为了避免把“检出依赖”或“区间覆盖”误读为预测增益。

与本文的关系在于：上述工作的结论载体有三类——权重、注意力或外部归因[62,77-80]，加权后的标量评分[81]，以及方向性筛查与覆盖检验[82-87]；其共同假设是信号的强弱与标量的大小可直接代表机制必要性。本文不以更强的解释方法为目标，而以冻结替换、指定学生替代与交叉分组构成三层证据，检验该假设，并逐层标明可回答与不可回答的问题；方向性筛查与区间覆盖单列，不与预测增益合并。

### 1.2.5 研究空白与本文定位

上述四个方向的空白可收敛为三条，且均可在同一任务内检验。

空白一：多关系建模的增量尚未被条件化检验。现有工作报告含图配置的整体误差提升，不区分提升来自哪一层样本、哪一层参数。本文用同参数自环替换重训检验它，并核查增量落在哪一层。

空白二：强零膨胀下整体MAE作为选型判据的效度尚未被检验。整体误差对每个测试键等权，零值占多数时排序可能由零值段决定。本文用分层误差构成与冻结预测排序检验它。

空白三：关系解释与预测性能之间缺少分层的证据协议。现有工作或只报性能，或只做可视化解释，缺少共同的比较单位。本文用同参数配对、指定学生蒸馏与交叉分组的三层证据检验它。

三条空白对应三个可检验的研究问题：站内三类统计关系是否带来可归因的整体误差增量、该增量能否逐类归到具体统计关系、以及结论在何种代理目标与可靠性条件下成立。它们与相关研究方向的对应关系见图1-1。

## 1.3 研究目标、主要内容与创新点

1.2.5节的三条空白是同一测量问题的三个侧面：站内关系是否带来可归因的整体误差增量、该增量能否逐类归到具体统计关系、以及结论在何种代理目标与可靠性条件下成立。本节按研究目标、研究内容与创新点的顺序给出回答。

### 1.3.1 研究目标

本文的目标是在公开会话记录重构的站内节点代理负荷任务上，对站内三类统计关系的预测价值作一次可复核的测量。该目标分解为三项。

（1）表示与检验。说明负荷耦合、行为共现、轮廓相似三类关系如何编码为关系图，并在同一任务与口径下检验关系图是否带来可归因的整体误差增量。

（2）分层测量。把整体误差按评价层、标签口径与参数配置分别测量，使“哪个配置更好”的回答可归到具体样本与具体参数，而不依赖“模型整体更强”这一前提。

（3）边界界定。说明上述结论在何种代理目标、数据来源与区间可靠性条件下成立，并把可直接使用的做法与不可外推的部分分开。

三项子目标分别由第3章、第4章与第5章承担：第3章回答增量是否可归因，第4章回答误差由谁构成，第5章回答结论在什么条件下成立。

### 1.3.2 主要研究内容

研究内容对应四部分。

（1）数据与协议：解析会话字段与节点标识，重构15 min代理电量，界定输入可见时点、标签成熟条件和时间切分，分析序列稀疏性与节点异质性，并说明代理目标的构造偏差。

（2）关系增量：构建三类LRE关系图并由MRG-GCN编码；比较节点级与共享门控、JPL自环替换重训、完成时刻截断目标重训及两种代理标签下冻结预测的排序，并在同源第三场站作小规模复核，区分模型表现、组件增量与目标敏感性。

（3）误差诊断：以L1参数替换敏感度、L2受检学生替代性和L3交叉分组误差构成三层证据，区分联合配置依赖、特定替代尝试与误差构成；明确L1受消息尺度影响、L2在结构上不能回答图结构必要性。

（4）可靠性与使用条件：筛查方向性候选，评价独立及滚动区间校准，并以固定预测轨迹和合成约束例说明运行接口。结果限于代理目标、已查看时期和现有计量材料。

四项内容各有对应证据：关系编码与门控检验“站内关系是否带来条件性增量”（JPL自环替换12次配对与同参数门控配对）；交叉分组分解检验“整体误差由哪些样本构成”；代理标签与可靠性分析界定“结论在什么条件下成立”。三者分别回答表示、增量与边界三个问题，共同支撑一个测量结论，而不是一个“全面更强模型”的主张。

### 1.3.3 本文创新点

针对零膨胀节点负荷下整体MAE被零值键主导、且行为特征无法替代历史负荷的问题，本文提出残差化多关系门控图卷积模型：以`load_lag1`为基准、模型预测残差，并以三类关系图编码跨节点信息；在Caltech事件时刻协议上（三种子，2024–2026）整体MAE为0.015704，零值层误差为0.00559，较无图TCN低48.9%，较persistence基线低1.2%。

针对整体误差无法归因到关系类别与样本层级的问题，本文提出分层评价协议（MDP）：以L1参数替换敏感度、L2受检学生替代性与L3交叉分组误差构成三层证据，把关系增量按评价层、标签口径与参数配置分别测量；回溯协议中1.39%的预测键贡献28.10%的绝对误差，交叉分组加权还原差小于$10^{-9}$。

针对关系图增益默认成立、缺少可归因测量的问题，本文提出关系增量的条件性测量方法：以同参数自环替换重训与同参数门控配对逐条剥离关系增量，得到负荷耦合1.82%、轮廓相似1.52%的整体MAE增量，行为共现为0.15%且区间跨零，因而不计为增量。

三项创新点的共同点是把“模型是否更强”改写为“增量能否归因”：按1.2.2节近邻研究已核实的范围，未见在同一任务、同一协议下对站内三类统计关系作相对自环的受控剥离；本文在该任务中实施三类关系的同参数自环替换重训，并报告带校正区间的条件性增量。目标、内容与创新点的对应关系见1.4节图1-3，技术路线见图1-2。

# 第2章  充电行为数据与特征分析

本章回答两个问题：充电会话记录如何转化为可建模的节点序列，以及该序列的统计特征如何约束模型与评价。文中先说明数据来源与重构口径，再分析稀疏性、节点异质性与事件窗口，并据此确定建模与评价要求。

## 2.1 数据来源与重构口径

本文采用Caltech公开的ACN-Data单站公开数据（`siteID=2`），含31,424条会话、11个字段，记录接入、断开、充电完成时间和总电量[88]。接入时间范围为2018年4月25日至2021年9月14日，最晚断开时间为2021年9月14日3:05:10；接入、断开时间均可解析，完成时间可解析29,369条。该快照不含连续电流量测，但ACN接口另提供时序数据；完成时间缺失不影响式（2-1）的主目标重构。

原始数据只给出会话总交付电量，不包含可直接用于节点级短期预测的连续功率序列。本文以15 min为固定时间间隔，将每条会话的总交付电量均匀分配至该会话从接入时刻到断开时刻所覆盖的全部时间片。设第\(s\)条会话的总交付电量为\(E_s\)，所属节点为\(i_s\)，覆盖的15 min时间片集合为\(\mathcal{B}_s\)，则节点\(i\)在时间片\(t\)上的节点代理负荷定义为

\[
y_{t,i}=\sum_{s:i_s=i,\,t\in\mathcal{B}_s}\frac{E_s}{|\mathcal{B}_s|}.
\tag{2-1}
\]

式中，\(|\mathcal{B}_s|\)为会话覆盖片数；同一节点片内多条会话的分摊量求和。所得网格覆盖2018年4月25日11:00至2021年9月14日3:15，共118,818个连续15 min时间步。\(y_{t,i}\)称节点代理负荷，单位kWh/15 min；它是分摊电量，不是瞬时或电表实测功率。

10个主节点11,085条会话的代理总量与92,650.017 kWh交付总量守恒，逐节点差小于$10^{-8}$ kWh；这不证明时间分配真实。均匀分摊可能延伸至充电完成后的停留时段并平滑会话内变化，2.1.2节以完成时刻、电流样本和设备上报序列核查。

`siteID=2`场站含55个候选节点；`stationID`、`EVSEID`和`spaceID`各有55个唯一值，前两者逐行一致，并与`spaceID`一一对应。因此本文以`spaceID`（如CA-303）标记节点，不将`stationID`误作场站数或将节点解释为配电母线。图边表示统计联系，不表示电气拓扑。

如图2-1所示，原始会话记录依次转换为模型输入张量；回溯协议中占用率分母与负荷跳变阈值等统计量取自全时期。因此，不能把后续训练期标准化概括为全部预处理与测试时期隔离。

### 2.1.1 三套评估协议的任务边界

三套协议均以左端时间戳标记15 min片，使用96片历史预测随后4片。最后输入片结束时刻为发布时刻，四个目标片起点为发布时刻及其后15、30、45 min。行为计数按片末可见构造，但数据记录未包含实际上报时间，延迟和丢失率未知；标签也可能在会话结束后才成熟。

Caltech回溯协议用会话最终字段重构历史负荷，故早于发布时刻的时间戳不保证片值当时可见；其0.01376 MAE仅描述该事后回溯任务。事件时刻协议移除旧负荷及派生通道，目标仍是事后代理标签。两协议的输入、切分和测试键不同，不直接合并比较。

### 2.1.2 分摊支持范围与历史设备记录核查

10节点11,085条会话中，10,399条完成时刻位于接入与断开之间，420条缺失，266条顺序异常；合法记录完成至断开的停留时间中位数为62.67 min。6,967条会话在完成后仍含完整15 min片，均摊规则向其分配28,403.239 kWh，占总电量30.66%。

该比例只表示分摊延伸至记录完成时刻之后的范围；会话重叠使其不能说明节点片内无充电。

仅当`connectionTime <= doneChargingTime <= disconnectTime`时，才以充电完成时刻替代断开时刻作为分摊终点；完成时刻缺失或不满足该区间条件时，回退至`disconnectTime`。替代重构与原重构的总电量均为92,650.017 kWh，最大逐节点守恒差为$4.91\times10^{-10}$ kWh，但对应节点时间片的平均绝对差为0.0477816 kWh/15 min。该值只表示同一批会话在两种标签分配规则下的逐节点时间片平均绝对差，不是模型误差、真实负荷不确定度上限，也不与模型MAE作大小比较。

目标敏感性实验随后在Caltech事件时刻协议的固定测试键上使用这一替代目标重新训练预测模型；预测输入、原图、切分和起点键保持不变，仅依替代目标的新训练前缀重算目标标准化参数。该敏感性结果见3.8.4节。

完成时刻仍不是连续功率测量，替代标签不等于真实负荷。

ACN公开静态快照[88,89]另提供有限设备时序。主10节点各抽取一个2018年5月会话，8条电流记录通过质量校验，仅为已查看的便利样本。CA-303在2020年11月匹配到11次设备上报累计电量序列，共277个共同完整片；节点、月份选择前已查看一条先导会话，故属探索性历史核验而非未见期验证。累计量经线性插值至完整片边界后差分，与两种分摊代理比较；原始高频文件不入库。

### 2.1.4 代理目标的定义与偏差方向

本文的预测目标是按会话总电量在接入—断开区间内均匀分摊得到的15 min节点代理电量，不是电表计量功率。这一定义有三个直接后果。其一，完成充电后车辆仍可能占用车位，均摊会把电量记在完成之后（见2.1.2节）。其二，偏差方向可判：代理目标把本应集中的功率拉平，使高峰被压低、尾部被抬高；按完成时刻截断的对照在CA-303单节点11次会话、277个共同完整片上给出更低的MAE，但样本只覆盖一个节点和一台设备，计量算法与校准未核实，不能作为计量校准。该偏差（均摊与设备电量的MAE为0.3133 kWh/15 min，截断标签为0.0535）比本文讨论的模型间差异（0.0012—0.0076 kWh/15 min）大1—2个数量级；因此在代理目标上只能比较模型间的相对差异，不能据此判断真实功率下的可辨识性。其三，所有结论只在该构造下成立：第3—5章的模型比较、关系增量与误差分解都以代理电量为对象，换成计量功率需要重建标签并重新验证。

## 2.4 事件分数构成与事件窗口统计

为描述会话接入、离站、活跃状态突变和负荷突变共同形成的短时行为变化，本文构造节点级规则事件分数。设节点\(i\)在时间片\(t\)的新接入数、离站数、活跃会话数和节点代理负荷分别为\(a_{t,i}\)、\(d_{t,i}\)、\(c_{t,i}\)和\(y_{t,i}\)，相应分量的训练期标准差为\(\sigma_{a,i}\)、\(\sigma_{d,i}\)、\(\sigma_{\Delta c,i}\)和\(\sigma_{\Delta y,i}\)，则事件分数定义为

\[
q_{t,i}=\frac{a_{t,i}}{\max(\sigma_{a,i},\varepsilon)}+
\frac{d_{t,i}}{\max(\sigma_{d,i},\varepsilon)}+
\frac{|c_{t,i}-c_{t-1,i}|}{\max(\sigma_{\Delta c,i},\varepsilon)}+
\frac{|y_{t,i}-y_{t-1,i}|}{\max(\sigma_{\Delta y,i},\varepsilon)},
\tag{2-2}
\]

式中，\(\varepsilon\)为防止分母为零的极小常数。四个标准差均按节点在训练集上计算，使不同活跃度节点和不同量纲的行为分量能够在同一规则中比较。对于每个节点，在验证集非零事件分数上取95%分位数作为阈值；超过阈值的时间片记为规则触发点，并只向未来扩展2个时间片。阈值和扩展规则一经确定便保持不变，测试集不参与阈值估计，相邻或重叠的触发窗口合并为连续窗口。该规则属于含事后代理负荷差分的回溯诊断，不解释为发布时刻可用的在线触发。完整生成流程见图2-7。

![事件分数与事件窗口生成流程](../../outputs/figures/fig2_7_event_score_flow.png)

**图2-7 事件分数与冻结规则事件窗口生成流程**  接入、离站、活跃变化和负荷变化四个分量经逐节点标准差归一化后求和，采用验证集95%分位阈值触发，并仅向未来扩展2个时间片。标准差来自训练集，测试集不参与阈值估计。

规则在训练、验证和测试三个数据段内分别执行，因此每段最前面的两个预测起点不会继承上一数据段的触发状态。该处理避免跨划分传递信息，最多影响测试评价键中的80个位置，占712,360个测试预测键的约0.011%，属于保守的边界处理。

三套协议的输入可见性并不相同，各按自身协议提供历史输入，不表示共用同一通道（逐项汇总见附录表A-2）。回溯协议的节点代理负荷历史为纯历史片、不含目标片，事件时刻与JPL协议不使用该通道；当地日历为确定性构造；接入、离站与活跃计数按协议假设在片末可见，实际到达延迟未核（2.1.3节）。回溯协议的占用率分母含全时期活跃节点数，需求强度与负荷突变阈值取全时期90%分位，因而该协议的若干统计量跨越了测试期，仅用于历史配置复核，不用于事件时刻主比较；事件标签与规则触发为事后构造，仅用于评价，不作输入。

## 2.6 数据特征对建模的启示

稀疏与长尾要求并列报告总体、事件、稳定及非零误差；节点异质性为构图提供动机，但关系增量须由对照检验；标签事件与规则触发错位，需分别评价。JPL协议据此固定输入、训练期筛选与建图、调参选模和共同测试键（图2-11）：96片历史窗与4片目标窗完整留段，四种模型各跑三个种子，以调参集原单位MAE选冻结模型，锁定后每次运行只导出一次测试预测，整体MAE另按24个七日块作配对比较。

**图2-11 JPL固定协议重新拟合验证流程**  输入为接入、离站、活跃计数与当地日历编码，目标为会话电量在接入至断开区间均匀分摊的代理电量。各模型按时间分段训练与校准后冻结，各导出一次测试预测，在632,640个共同预测键上评价。行为计数假定片末可见，实际到达延迟未核实。

## 3.2 预测任务形式化定义

设主分析节点集合为$\mathcal{V}=\{v_1,\ldots,v_N\}$，其中$N=10$。令$s_k$为末个输入时间片的左端时间戳，时间片宽度$\Delta t=15$ min，发布时刻为$\tau_o=s_k+\Delta t$。预测输入为索引$k-95$至$k$的96片历史特征：

$$
\mathbf{X}_o\in\mathbb{R}^{H\times N\times F},\qquad H=96,\ F=7, \tag{3-1}
$$

预测目标为未来$P=4$个目标片的节点代理负荷：

$$
\widehat{\mathbf{Y}}_o=f_\theta(\mathbf{X}_o,\mathcal{A}),\qquad
\widehat{\mathbf{Y}}_o,\mathbf{Y}_o\in\mathbb{R}^{P\times N},\ P=4, \tag{3-2}
$$

其中，$\mathcal{A}$为训练集构建的关系矩阵集合，$f_\theta$为待学习模型。模型输出$P=4$个连续目标片$\widehat{\mathbf{Y}}_o=(\hat y_{k+1},\ldots,\hat y_{k+4})$，对应真实值$\mathbf{Y}_o=(y_{k+1},\ldots,y_{k+4})$，覆盖$[\tau_o,\tau_o+60\,\mathrm{min})$。输入为发布前完整24 h；四片起点相对发布时刻依次为0、15、30、45 min。评价键由协议、发布时刻、目标片和节点唯一确定，同协议模型按共同键比较。标准化参数仅由训练集估计；`target_event`和`rule_trigger`不作输入。

## 3.3 场景驱动的LRE三关系图构建

LRE从训练期数据中构建负荷耦合、行为共现和轮廓相似三类无向统计关系。测试数据不参与关系估计。构建与稀疏化流程见图3-4。

![LRE三关系构建流程](../../outputs/figures/fig3_4_lre_construction.png)

**图3-4 LRE三关系构建流程**  训练期负荷序列、行为信号和96片轮廓分别形成负荷耦合、行为共现和轮廓相似关系，随后经Top-k稀疏化、无向并集和对称归一化得到三类固定邻接矩阵。

### 3.3.1 负荷耦合关系图

设$\mathbf{l}_i\in\mathbb{R}^{T}$为节点$i$的训练期节点代理负荷序列。节点$i$与$j$的负荷耦合强度定义为绝对Pearson相关系数：

$$
A^{\mathrm{load}}_{ij}=\left|
\frac{(\mathbf{l}_i-\bar l_i)^{\mathsf T}(\mathbf{l}_j-\bar l_j)}
{\|\mathbf{l}_i-\bar l_i\|_2\,\|\mathbf{l}_j-\bar l_j\|_2}
\right|. \tag{3-3}
$$

绝对值表示耦合强度，不保留正负方向；任一序列方差为零时，对应权重置零。该关系描述节点负荷在训练期的同步程度，不解释为物理连线或因果联系。

### 3.3.2 行为共现关系图

对节点$i$构造行为序列
$\mathbf{b}_i=\mathbf{x}^{\mathrm{access}}_i+\mathbf{x}^{\mathrm{departure}}_i+|\Delta\mathbf{x}^{\mathrm{active}}_i|$，再以余弦相似度定义行为共现关系：

$$
A^{\mathrm{event}}_{ij}=
\frac{\mathbf{b}_i^{\mathsf T}\mathbf{b}_j}
{\|\mathbf{b}_i\|_2\,\|\mathbf{b}_j\|_2}. \tag{3-4}
$$

分母为零时权重置零。该关系侧重接入、离站与活跃变化在时间上的共同出现，对行为规模差异相对不敏感。

### 3.3.3 轮廓相似关系图

训练序列从数据起点按固定相位切分为96步窗口，对各窗口同一相位位置取均值，得到节点轮廓$\mathbf{p}_i\in\mathbb{R}^{96}$。数据首时刻为11:00，因此这是固定相位的96步窗口轮廓，不是自然日00:00起算的日曲线。记节点轮廓均值为$\bar p_i$，中心化轮廓为$\tilde p_{iq}=p_{iq}-\bar p_i$；以节点对中心化轮廓的均方根距离$d_{ij}$表征形状差异，取所有正距离的中位数$s$为尺度（若无正距离则取1），再以指数核转换为相似度：

$$
\begin{aligned}
\bar p_i&=\frac{1}{96}\sum_{q=1}^{96}p_{iq},\qquad
\tilde p_{iq}=p_{iq}-\bar p_i,\\
d_{ij}&=\sqrt{\frac{1}{96}\sum_{q=1}^{96}\left(\tilde p_{iq}-\tilde p_{jq}\right)^2},\\
A^{\mathrm{pattern}}_{ij}&=\exp\left[-\frac{d_{ij}}{\max(s,10^{-6})}\right],
\end{aligned} \tag{3-5}
$$

式中，$i,j$为节点索引，$u,v$为取中位数时的节点对索引；$q=1,\dots,96$为固定相位序号；$p_{iq}$为节点$i$在第$q$相位的轮廓负荷，上述$p_{iq}$、$\bar p_i$、$\tilde p_{iq}$、$d_{ij}$、$s$及分母下限$10^{-6}$的单位均为kWh/15 min；$A^{\mathrm{pattern}}_{ij}$为无量纲相似权重，取值$(0,1]$。

### 3.3.4 top-k稀疏化与对称归一化

各关系矩阵按行保留权重最大的$k$个非自身邻居，再取$\max(\mathbf A,\mathbf A^{\mathsf T})$形成无向并集。回溯协议冻结$k=3$，事件时刻协议冻结$k=5$；$k=5、7$的其他结果仅为另行登记的稀疏度敏感性，两套Caltech配置不直接比较。加入单位自环后作对称归一化：

$$
\widehat{\mathbf A}_r=\widetilde{\mathbf D}_r^{-1/2}
(\mathbf A_r+\mathbf I)\widetilde{\mathbf D}_r^{-1/2},
\qquad r\in\{\mathrm{load,event,pattern}\}. \tag{3-6}
$$

式中，$\widetilde{\mathbf D}_r$为$\mathbf A_r+\mathbf I$的度矩阵，对角元取该行权重之和。三类关系矩阵见图3-5。它们均为训练期统计关系。

![LRE三类站内关系矩阵](../../outputs/figures/fig3_5_lre_matrices.svg)

**图3-5 LRE三类站内关系矩阵**  三个面板依次表示负荷耦合、行为共现和轮廓相似关系，并采用统一色阶。矩阵由训练集一次性构建，不含跨种子误差棒。

## 3.4 时间基线：TCN

时间骨干采用TCN[24]。对每个节点独立处理96片历史输入，六层一维卷积的膨胀率依次为$1,2,4,8,16,32$，记卷积核宽度$K_c=3$、层数$L=6$。网络使用因果填充并裁去右侧多余输出，使时刻$t$的表示只依赖$t$及其历史。其感受野为

$$
R=1+(K-1)\sum_{l=0}^{L-1}2^l=1+2(1+2+4+8+16+32)=127, \tag{3-7}
$$

能够覆盖96片历史窗口。每层在通道维执行逐时间步LayerNorm，不跨时间汇总统计量；最终时刻的隐藏状态作为节点初始表示$\mathbf H^{(0)}\in\mathbb{R}^{B\times N\times D}$。主实验取隐藏维$D=32$、dropout为0.1。TCN既作为MRG-GCN的时间编码器，也作为无图基线。

## 3.5 双层多关系门控图卷积网络（MRG-GCN）

### 3.5.1 总体架构

MRG-GCN由时间编码、两层图传播、层间精炼与融合预测组成。TCN输出$\mathbf H^{(0)}$；第一层图卷积得到$\mathbf H^{(1)}$；中间残差MLP生成精炼表示$\mathbf H^{(1,\mathrm{ref})}$，并作为第二层图卷积的输入，得到$\mathbf H^{(2)}$。最后拼接$\mathbf H^{(0)}$、$\mathbf H^{(1)}$和$\mathbf H^{(2)}$，经融合映射预测未来4个目标片的负荷。该结构同时保留纯时序、一阶邻域和二阶传播信息。为统一两层记号，定义$\mathbf Z^{(1)}=\mathbf H^{(0)}$、$\mathbf Z^{(2)}=\mathbf H^{(1,\mathrm{ref})}$，即$\mathbf Z^{(l)}$表示第$l$层传播的实际输入。

### 3.5.2 单关系消息传递

对第$l$层输入$\mathbf Z^{(l)}$，关系$r$的消息为

$$
\mathbf M_r^{(l)}=\widehat{\mathbf A}_r\mathbf Z^{(l)}\mathbf W_r^{(l)}, \tag{3-8}
$$

其中，$\mathbf W_r^{(l)}\in\mathbb{R}^{D\times D}$为关系专属变换矩阵。邻接聚合沿节点维进行，不改变批次维和隐藏维。

### 3.5.3 关系级门控

每层设置独立的未归一化权重参数（logit）$\mathbf a^{(l)}$，经Softmax得到三类关系的全局融合权重：

$$
\beta_r^{(l)}=\frac{\exp(a_r^{(l)})}{\sum_{s=1}^{3}\exp(a_s^{(l)})},\qquad
\mathbf M^{(l)}=\sum_{r=1}^{3}\beta_r^{(l)}\mathbf M_r^{(l)}. \tag{3-9}
$$

$\boldsymbol\beta^{(l)}$在同一层内由全部节点共享，用于表示该层的关系混合偏好。两层参数相互独立，允许不同传播深度采用不同关系组合。

### 3.5.4 节点级门控

关系消息聚合后，模型按样本、节点和特征维计算门值：

$$
\begin{aligned}
\mathbf G^{(l)}&=\sigma\!\left([\mathbf Z^{(l)}\Vert\mathbf M^{(l)}]\mathbf W_g^{(l)}+\mathbf b_g^{(l)}\right),\\
\widetilde{\mathbf H}^{(l)}&=\mathbf G^{(l)}\odot\mathbf M^{(l)}+
(1-\mathbf G^{(l)})\odot\mathbf Z^{(l)}.
\end{aligned} \tag{3-10}
$$

$$
\mathbf H^{(l)}=\operatorname{LayerNorm}\left(\mathbf Z^{(l)}+\operatorname{Dropout}(\widetilde{\mathbf H}^{(l)})\right). \tag{3-11}
$$

关系级$\boldsymbol\beta$与各关系变换共同缩放聚合消息，节点级$\mathbf G$在自身表示和邻域消息间分配门值。$\beta$的数值随关系变换的尺度缩放，不作重要性或因果解释，详见4.2.5节。Caltech回溯协议没有$\mathbf G$的重训练消融；事件时刻协议采用节点级门控，其与同参数共享门控的配对结果见表3-6，回溯协议的五组组合消融见表3-8，其中门控关闭为复合变体，不能单独归因于门变量。

### 3.5.5 关系随机失活

关系随机失活（relation dropout）在训练时按关系类型采样掩码，并对保留关系的$\boldsymbol\beta$重新归一化；若三类关系均被屏蔽，则随机恢复其中一类，以保证消息传播路径非空。该机制只在$p>0$时启用，主模型配置$p=0$，因此不是主结果中的有效正则项；其$p=0.2$和$p=0.4$设置仅用于3.7.2节敏感性检验。

### 3.5.6 逐层关系选择与跨层融合

第一层输出$\mathbf H^{(1)}$经残差MLP精炼后输入第二层，但跨层融合使用原始$\mathbf H^{(1)}$，而非精炼后的$\mathbf H^{(1,\mathrm{ref})}$。最终表示为

$$
\mathbf H^{\mathrm{fuse}}=
\operatorname{Dropout}\!\left(
\operatorname{GELU}\!\left\{
\operatorname{LayerNorm}\!\left[
\mathbf W_f(\mathbf H^{(0)}\Vert\mathbf H^{(1)}\Vert\mathbf H^{(2)})
\right]\right\}\right). \tag{3-12}
$$

预测头将每个节点的融合表示映射为4个目标片。图3-1给出整体数据流，图3-2和图3-3分别展开关系传播单元与跨层融合路径。

### 3.5.7 目标函数与训练策略

训练目标采用标准化空间中的L1损失：

$$
\mathcal L(\theta)=\frac{1}{BPN}\sum_{b=1}^{B}\sum_{p=1}^{P}\sum_{i=1}^{N}
\left|\widehat Y_{bpi}-Y_{bpi}\right|. \tag{3-13}
$$

事件时刻协议及JPL重拟合实验使用标准化L1训练，以调参集原单位MAE选择冻结模型；连续8轮未改善时早停，最多训练60轮。该节实验按冻结时点设计为2024、2025和2026三个随机种子；第3.6节主结果已扩充至2024–2028五种子（见各表标注），口径以表注为准。校准集和测试集不参与选模。回溯协议的历史选模口径另见3.8.3节。

注：各协议均用10节点、96片历史预测4个连续15 min目标片，发布与目标起点见2.1.1节。种子是训练重复，预测键是误差单元，时间块描述固定期变化；三者均不是独立场站样本。回溯配置按7∶1.5∶1.5切分；两套行为输入协议另设独立调参、校准段。

完整的训练、预测与分层评价流程见图3-8。主指标为MAE，并辅以RMSE和WAPE：

$$
\operatorname{MAE}=\frac{1}{M}\sum_{m=1}^{M}|\hat y_m-y_m|,\quad
\operatorname{RMSE}=\sqrt{\frac{1}{M}\sum_{m=1}^{M}(\hat y_m-y_m)^2}, \tag{3-14}
$$

$$
\operatorname{WAPE}=\frac{\sum_{m=1}^{M}|\hat y_m-y_m|}{\sum_{m=1}^{M}|y_m|}. \tag{3-15}
$$

MAE和RMSE单位为kWh/15 min，WAPE无量纲。本文不使用MAPE：87.25%的测试键目标为零，MAPE的分母为零而无定义；WAPE以总量为分母，可在零膨胀数据上稳定解释。MAE为主要比较指标；零目标、非零目标及事件MAE用于检验收益分布，RMSE用于检查大误差权衡。事件标签为事后评价标记，分层结果不追认为新的预先设定主终点。

输出头的作用在残差化后反转。同一骨干与参数量下，残差QMH为0.027243、非零层0.1167，均高于线性头的0.015704与0.0878（分别高73.5%与32.9%）；QMH的分位网格与软门控以标准化零点为回落目标，而残差化后零值键的正确回落点是基准（残差0），两者不一致，故残差化后QMH引入系统性偏离。主模型因此采用线性输出头，QMH作为输出头对照保留（机制见3.6.7节与3.6.8节）。

容量方面，hidden 32的线性头为0.016682，高于主模型6.2%，窄容量不改变方向；容量匹配AGCRN（残差）当前仅完成seed-2024（0.017489），三种子均值待补，故本稿不据此对该基线作完整性结论。标签事件层不在表3-2中列出，事件时刻的误差构成分析见4.4节。

校准段零目标比例为94.5111%，测试段降至87.2479%，非零目标占比由5.49%升至12.75%。整体MAE随零值比例下降而上升，与非零及事件MAE不同口径。跨段比较须同时报告非零与事件层；JPL测试键零值为72.75%，与Caltech不可互换。

### 3.6.7 软门控输出头

第2章数据诊断指出，节点级负荷预测误差集中于非零（活跃）充电层，且事件时刻协议下活跃时段缺乏显式监督。软门控输出头（QMH）以显式门控分支判别活跃状态，单调分位网格刻画活跃条件下的电量分布，软组合器将二者耦合为最终点预测。

QMH 与两段式（hurdle）模型、零膨胀回归所代表的"显式活跃建模"传统同源[96-98]：经典 hurdle 模型以硬门限判别活跃，活跃概率低于 0.5 即输出硬零[96]；QMH 以连续软组合器替代硬门限，零键回落到标准化零点而非硬零。ZIP/ZINB 以泊松、负二项等参数化混合分布刻画零值过量[97]；QMH 以单调分位网格非参数地刻画活跃条件下的电量分布。MQ-CNN 类分位数输出头按固定分位水平给出全分布[98]；QMH 的查询分位由门控输出动态设定，随活跃概率单调上升（分段定义见下）。门控概率同时决定缩放强度与查询分位，是本方法与上述传统的主要区别。

设共享编码器输出节点嵌入 $h\in\mathbb{R}^d$。门控分支为轻量线性层 $p=\sigma(w_g\cdot h)\in(0,1)$，即该键为活跃事件的概率，仅引入一个向量参数。电量分支为 $K+1=9$ 个单调分位节点 $\hat{Q}=\{\hat{Q}_k\}_{k=0}^{K}$（$K=8$）：对累积 softplus 输出逐级累加并附加非负初值 $z_{\mathrm{init}}\ge 0$，即 $\hat{Q}_k=z_{\mathrm{init}}+\sum_{i\le k}\mathrm{softplus}(u_i)$，保证 $0\le\hat{Q}_0\le\hat{Q}_1\le\cdots\le\hat{Q}_K$ 恒成立；因 $z_{\mathrm{init}}\ge0$，标准化空间分位节点恒非负，该网格刻画的是活跃条件的正电量上侧，非完整分布下半支。两支由软组合器耦合：$g=\min(1,\,p/0.5)$，$\tau(p)=1-1/(2p)$，$\hat{y}=(1-g)\,z_0+g\,\hat{Q}(\tau(p))$，其中 $\hat{Q}(\tau)$ 在网格点间线性插值。组合器使 $p<0.5$ 时 $g=p/0.5$ 线性衰减，避免硬门控的零梯度区；$p\ge 0.5$ 后 $g$ 饱和于 1；查询分位水平取 $\tau(p)=1-1/(2p)$（$p\ge 0.5$），$p<0.5$ 时取 $\tau=0$，整体截断于 $[0,1/2]$；$K=8$ 的分位网格按 $\tau_k=k/(2K)$（$k=0,\dots,8$）在 0 至 1/2 均匀布置。需要指出，$\tau_0=0$ 是网格的下边界而非内点分位水平：该处的 pinball 项不具内点最优；训练中该项权重为 $1/9$，不主导梯度。该映射在 $p=0.5$ 处分段可微；其方向是：活跃置信度越高，查询分位越接近 $\tau=1/2$；越低则越靠近网格下端，与门控缩放 $g$ 一并把预测压向标准化零点。零值键整体回落到标准化原点 $z_0=(0-\mu_n)/\sigma_n$，不再占用回归容量。

目标序列按训练集逐节点均值与标准差作 z-score 标准化：$\tilde{y}=(y-\mu_n)/\sigma_n$，预测经反变换 $\hat y=\tilde{\hat y}\,\sigma_n+\mu_n$ 回原单位后报告。训练目标为$L=\beta\,\frac{1}{K+1}\sum_{k=0}^{K}m\,\ell_{\tau_k}(y,\hat{Q}_k)+c_g\,\mathrm{BCE}(p,z)+\lambda\,\mathrm{L1}(\hat{y},y)$，其中$\ell_{\tau}(y,q)=\max\{\tau(y-q),(\tau-1)(y-q)\}$为pinball损失，$m=\mathbb{1}\{y>0\}$为活跃掩码（分位项只在活跃键上归一化），$\tau_k=k/(2K)$，三项分别为分位损失、门控监督与保真项，其中保真项以L1惩罚点预测偏离、并因$\lambda=2$在最终配置中主导梯度。其中$\beta=0.5$、$\lambda=2$，$z=\mathbb{1}\{y>0\}$为活跃标签。门控由二元交叉熵显式监督。该监督的承重性依赖损失配置：仅靠回归损失塑形 $p$ 时，$p>0.5$ 后 $g$ 饱和、梯度为零，$p$ 无监督漂移，组合器失去校准。系数 $\beta$、门控系数、保真项权重 $\lambda$ 与 $K$ 由调参集选定：敏感性扫描同时记录调参集原单位 MAE 与测试期 MAE，最终配置按调参集 MAE 取最小。以保真项权重为例，$\lambda=0,2,5$ 的调参集 MAE 分别为 0.003518、0.003325、0.003369，$\lambda=2$ 在调参集上亦为最优；$\beta$ 在 {0.5, 2, 4} 上的调参集 MAE 分别为 0.003325、0.003676、0.003753，随 $\beta$ 增大单调上升，故取 0.5。因此最终配置的选择不依赖测试期读数，测试期仅作一次性报告；配对 p 值仍按五种子的验后比较报告，未对敏感性扫描的多重比较作校正。最终配置为 $\beta=0.5$、门控系数 1.0、$\lambda=2$、$K=8$。

可见输出头单独即贡献约 5.3 个百分点；分位项单独加入无增益，门控监督单独加入反而劣化，两者同时启用才取得完整的 6.14%。因此 6.14% 中约 5.3 个百分点来自输出头结构本身，其余约 0.87 个百分点来自两项损失成分的联合作用——头结构是主要来源。

机制在于 λ 决定损失的主导项。λ=0 时 pinball 与门控 BCE 主导优化，BCE 是模型得以成立的前提；λ=2 时 L1 保真项主导，两个辅助项退为边际修正：保真项直接把预测拉向观测值，即使门控或分位分支不精确，输出仍被约束在合理范围。

因此 λ=2 的绝对性能更优（0.0363 对 0.0370），但单组件的承重性下降。报告消融时须同时给出损失配置，否则"某组件是否承重"的结论会随 λ 改变。

### 3.7.4 交叉分组评价的加权还原检查

目标侧标签`target_event`与冻结规则`rule_trigger`按0/1交叉划分为四组，并验证

$$
\operatorname{MAE}_{\mathrm{global}}=
\frac{\sum_{a=0}^{1}\sum_{b=0}^{1}n_{ab}\operatorname{MAE}_{ab}}
{\sum_{a=0}^{1}\sum_{b=0}^{1}n_{ab}}. \tag{3-16}
$$

原正式MRG-GCN三个种子的交叉分组加权还原与全局MAE最大差低于$10^{-9}$，712,360个测试键均被分配。该检查验证算术闭合，不证明机制；误差解释见4.4节。

### 3.7.5 平凡收缩基线与预算对齐检验

为检验整体增益是否只是“更保守的预测”，补两个平凡对照。其一为零预测（所有键取0）；其二为单参数收缩基线：在调参集上拟合$\lambda$，把容量近似TCN的测试预测乘以$\lambda$。$\lambda$在2024、2025、2026三个种子上分别为0.254、0.273、0.273。三种子测试MAE依次为：零预测0.048275、容量近似TCN 0.046345、由调参集拟合$\lambda$的收缩TCN 0.043904、MRG-GCN 0.038901、完整AGCRN 0.037434 kWh/15 min（均为三种子测试集均值，$\lambda\cdot$TCN只增加一个标量参数，其余与容量近似TCN相同），原表见附录表A-6。

收缩使TCN的MAE降低5.3%，但MRG-GCN仍比收缩基线低11.4%，零预测比MRG-GCN差24.1%。因此整体增益不能由零膨胀或输出保守化单独解释；同容量AGCRN仍更低这一事实不变。

预算对齐方面，节点门控与共享门控在相同轮次下的调参MAE差距随轮次缩小（第10、20、30轮分别低43.4%、34.0%、21.6%），但方向不变。




## 3.8 证据综合与适用范围

本章主比较限定于三套协议及其各自的预测键；目标敏感性实验则在已查看的Caltech事件时刻测试键上固定输入、图和切分，单独检验另一代理目标构造下的模型比较。

### 3.8.1 方法组件与目标敏感性证据综合

方法组件的增量读数分散在表3-5、表3-6、表3-7、表3-9与表3-10，各分属回溯、事件时刻与JPL三套协议，不作跨协议合并排序（3.8.2节）；除QMH为五种子外均为三种子，关系行的基线为自环替换，汇总见附录表A-7。节点门控和两类关系的整体增量证据均限于所检协议、预算与基线；负荷关系的非零组差异仍属探索性结果。MDP三层诊断不产生预测增量，其数值见表4-1。基础图卷积、TCN和门控算子沿用已有方法。

### 3.8.2 三套协议的回答范围与比较边界

Caltech回溯、Caltech事件时刻和JPL重拟合分别使用712,360、708,560和632,640个测试预测键。前者比较事后重构序列上的历史配置，后两者比较行为输入条件下的预测；行为输入协议的模型设置见3.6.2—3.6.3节。JPL重新筛选节点、构图和训练，不代表零样本迁移或未来时期验证。

### 3.8.3 输入、容量与训练选模预算

主要比较、门控配对与关系替换训练共用同一输入窗口与训练预算，各协议只在输入权限、选模指标和预测键上不同；运行环境与训练配置见下段。

训练用RTX 4090 D与5090、PyTorch 2.8.0；96片历史→4片目标，训练、调参、校准与测试按时间留段；主比较（八特征残差化配置）用三种子（2024—2026）；旧七特征配置的主比较与QMH用五种子（2024—2028）；补充的门控配对、参数敏感性与承重消融按三种子（2024—2026）运行，各表已标注。优化器AdamW，学习率$1\times10^{-3}$，批大小256，上限60轮，早停耐心8，按调参集原单位MAE选模。

回溯配置的七通道输入含代理负荷、占用率、需求强度与跳变标志；两套行为输入协议只含接入、离站、活跃计数及当地日历编码。可训练参数见表3-2与表3-3，其中回溯AdaptiveGraph为35,005个；完整AGCRN的199,912个参数未与MRG-GCN容量匹配。自环替换的四种配置按种子的最佳轮次为22至42轮，停止轮次均未触及60轮上限；该实验未检验更长预算或不同收敛判据，不能单独证明优化已充分收敛。AdaptiveGraph的跨环境复核、选边差异及来源限制见3.6.4节。

**端到端时延预算**。单窗口推理2.5—36.0 ms，远小于15 min预测粒度；毫秒级推理不构成瓶颈，端到端时延主要由特征抽取与数据到达决定，本文未实测。

**部署形态**。主模型对10个节点联合建模，单模型单次前向覆盖全部节点，不按节点独立部署；节点数增加只改变关系图与输入矩阵的宽度，不增加单次推理次数。

**节点扩容与冷启动**。主分析覆盖55个候选节点中的10个，其余未建模；扩容需重建关系图并重训（2.2节15节点集未重训），冷启动兜底策略本文未验证。

两项敏感性实验只替换目标或邻接、沿用既有训练配置与运行环境。自环替换实验的代码版本未受版本库历史差异影响；目标敏感性实验缺少可验证的历史提交记录。

## 3.9 本章小结

在七特征非残差配置下，MRG-GCN相对容量近似TCN有16.4%的整体MAE优势，但完整AGCRN与容量匹配AGCRN更低（0.03746与0.03745对0.03870）；扩展软门控输出头并取λ=2后为0.036326（五种子），较完整AGCRN低3.02%。该配置的限制在于输入不含历史负荷：补入`load_lag1`并改为残差预测后，主模型（MRG-GCN+线性头，33,902参数）三种子（2024–2026）整体MAE为0.015704，零值层为0.00559、非零层为0.08494，较无图的残差TCN（0.030709）低48.9%、较persistence（0.015896）低1.2%，较旧配置低56.8%。容量对照hidden 32为0.016682，残差QMH为0.027243，容量匹配AGCRN仅完成seed-2024（0.017489）。节点门控及JPL负荷、轮廓关系有条件性增量证据，行为关系仍不确定；目标敏感性与MDP边界见3.8节和第4章。

本章给出的是一步点预测的能力边界：整体 MAE 可比较，事件层误差高度集中（见4.4节）且预测区间覆盖不足（见5.1节），故点预测可用于排序与筛查，区间输出尚不能支撑运行核查。

# 第4章  分层评价协议（MDP）与误差构成分析

## 4.1 引言：分层评价协议（MDP）的定义与边界

权重分布不能单独解释关系作用或误差来源[80]。本文将三层证据协议（mechanism diagnostic protocol，MDP）分为三层：L1冻结替换关系级$\boldsymbol\beta$，L2检验指定TCN学生能否逼近静态图教师，L3交叉标签事件与规则触发以描述误差构成（图4-1、表4-1）。此处MDP指本文的诊断协议，不指马尔可夫决策过程；三层均不识别现实因果机制。

![三层分层评价协议](../../outputs/figures/fig4_1_three_layer_framework.png)

**图4-1 三层证据协议**  L1为关系参数干预，L2为受检学生蒸馏，L3为预定义样本组误差分解。“溯源”仅指描述误差构成，不作因果归因；L2结论限于所检学生、蒸馏目标与权重。

**表4-1 MDP三层诊断的设计与结果**

|---|---|---|

| L2 学生替代 | 静态教师蒸馏至TCN | 未弥合：2.12—2.14倍 |
| L3 误差构成 | 事件×规则交叉分组 | 1.39%键占28.10%误差 |

## 4.2 L1参数替换敏感度（PS）：关系分配的功能依赖

### 4.2.1 观察操作

从Caltech回溯模型三个冻结模型提取两层Softmax关系权重$\boldsymbol\beta^{(1)}$、$\boldsymbol\beta^{(2)}$，分别混合负荷、行为和轮廓关系。权重层内共享，不表示逐节点贡献或物理因果强度。

### 4.2.2 干预操作

在相同测试键上保持其他参数不变，只替换两层$\boldsymbol\beta$并前向推理。七种替换包括单关系、等权、层间交换及单层固定，学习值为基线。该内部干预借鉴改变模型单元后观察输出的解释思路[92]，不识别数据生成因果效应。

### 4.2.3 观察证据

第一层三个种子均以行为权重最高；第二层均值最高的是负荷关系，但种子2025中行为权重略高（表4-2、图4-2）。

### 4.2.5 L1判定结论

七种替换均使MAE升高，表明模型对已学的联合配置敏感；$\beta$的独立增益另由3.7.2节的等权β重训检验。消息为$M=\sum_r\beta_rW_r(\widehat A_rH)$。关系变换无偏置、主配置不作关系随机失活，取$\beta'_r=1/3$与$W'_r=3\beta_rW_r$即可保持消息不变。$\beta_r$的幅度需与$W_r$的尺度一并读取。两层等权冻结的退化（143.8%）大于权重本身的相对变化，说明当前配置在训练最优点附近对消息尺度较敏感。该幅度反映功能依赖，不宜用作关系重要性的定量排序；机理分解需针对消息尺度的单独实验。

冻结干预只检验现有配置的依赖程度，因果解释超出L1层范围。

节点门控的增量见表3-6（当前预算下MAE低2.69%），该增量与冻结$\beta$的敏感度分属两类证据。

### 4.2.6 分层敏感度：关系分配干预的样本响应

#### 4.2.6.1 方法与指标

本节在相同冻结模型和七种替换下，补充事件、稳定及逐节点响应。相对变化为：

$$
\Delta\operatorname{MAE}^{(c)}
=\frac{\operatorname{MAE}^{(c)}_{\mathrm{intervention}}
-\operatorname{MAE}^{(c)}_{\mathrm{learned}}}
{\operatorname{MAE}^{(c)}_{\mathrm{learned}}}. \tag{4-1}
$$

其中$c$为总体、事件、稳定窗口或节点。该量描述参数替换敏感度，不等同关系贡献。

#### 4.2.6.2 分层敏感度结果

所有替换在总体、事件和稳定窗口的MAE均高于基线：总体退化95.9%—233.6%，稳定窗口132.1%—316.6%，高于事件窗口的5.5%—35.6%（逐配置数值见图4-3(b)，原表见附录表A-8）；该差异描述响应，不识别其成因。该组替换以学习值为基线、结果汇总三种子，L1与L2分别指第一、第二层，逐种子离散度未保留，故不报告误差棒。

逐节点最大相对退化为CA-327的171.3%至CA-303的409.2%；未对节点差异作独立检验，故不划分固定敏感等级；三个窗口（全局、标签事件、稳定）上的相对变化见图4-3(b)。


#### 4.2.6.3 解释边界

相对变化受基线、节点尺度、事件占比及连接共同影响，不能据此设节点优先级或删关系；重训结果见3.7.2节。

## 4.5 MDP诊断结果与适用边界

MDP收紧了三项判断：L1反映$\beta$与变换的联合配置敏感度；L2仅说明受检学生未逼近教师；L3要求并列报告困难格单键误差和常态格总误差贡献。相应取舍见表4-5。



这些诊断改变了关系解释、替代性判断和报告重点；诊断指导改模是否提升预测仍待受控验证。

## 4.6 JPL的L1/L3跨场站诊断与适用范围

### 4.6.1 诊断材料与计算口径

为检验诊断能否迁移到另一场站，在JPL重拟合的三个模型及其数据上追加L1/L3；分析为测试已查看后的事后诊断，不训练或改动输入、图、标签、阈值和选模。CPU上重算的结果与原导出的逐键最大差为2.08×10⁻⁶（容差5×10⁻⁶）；24组基线/替换、3组重参数化对照及交叉分组还原结果一致，最大还原差1.39×10⁻¹⁷ kWh/15 min。

JPL上的重复诊断表明，既有模型可支持L1配置敏感度与L3误差结构的检验，格间响应与Caltech不同。该分析未覆盖L2或诊断指导改模收益；它也不同于自环替换实验的邻接替换重训。


## 4.7 本章小结

本章把“机制诊断”限定为误差形成机制，给出三层证据，并明确每层能回答与不能回答的问题。

L3是本章可复用的核心。回溯协议712,360个预测键上，交叉分组加权还原差小于$10^{-9}$；1.39%的困难格贡献28.10%的绝对误差，69.3%来自常态格。该分解把“整体误差高”转成“误差集中在哪些键”，可为复验排序与告警阈值研究提供样本构成依据。

L1是参数替换敏感度，不是因果归因。七种冻结β替换使整体MAE升高95.9%—233.6%，但消息对β与关系变换的尺度联合变化不变（取$\beta'_r=1/3$、$W'_r=3\beta_rW_r$时逐键差约$1.55\times10^{-6}$），因此该退化只说明模型依赖训练所得的联合配置；

L2是受检学生替代性，不是图结构必要性检验。四档蒸馏权重下指定TCN学生的MAE为教师的2.12—2.14倍；学生无邻居输入、参数量16,996对32,714，结构上不能回答“图结构能否被时序模型替代”。

由此三条判定规则：门控增量仅在三种子同向时作一般性表述；关系取舍依据重训而非β幅度；交叉分组结论须并列困难格单键误差与常态格总贡献。本章的贡献因此是一套可复用的误差构成测量，而非对关系作用的因果解释。


# 第5章  模型结构与可靠性边界分析

## 5.1 引言

前三章分别建立预测对象、比较模型并分析误差来源。本章进一步考察这些预测关系在方向性检验和区间评价下能支持何种结论，以及将预测用于运行核查还缺少什么条件。本章定位为模型可靠性与应用边界验证，不构成第三项独立预测模型创新。

本章的区间结论在此集中陈述：名义90%区间实测覆盖为回溯协议69.6%（表5-2）、事件时刻协议79.55%（表5-1），事件层仅1.9%—3.87%；14天滚动校准把整体覆盖提至89.01%、事件层提至26.71%（行为分层路径；标准逐节点路径膨胀6.25倍）（表5-1），但区间宽度膨胀至4.47倍，实际可用性有限。故本章结论是：点预测可用，区间预测尚不能直接用于运行核查；“有区间”不等于“区间有用”。

**图5-1 TE候选生成与PCMCI+条件独立检验流程**  两法使用同一训练期10节点序列；44/32/6为两法均、仅TE、仅PCMCI+达到名义阈值的有向对数，未经多重校正。该对照不构成独立复现，TE候选经家族校正后无一保留。

### 5.2.1 问题与动机

第3章LRE图为无向统计关系，不含时滞。此处检验的假设是：站内节点历史可能包含指向其他节点后续负荷的方向性统计信息；方向只表示先后关系。

### 5.2.2 传递熵方向性检验

采用传递熵（transfer entropy，TE）[82]衡量给定目标历史后，源节点滞后取值对目标当前值提供的条件信息：

$$
\operatorname{TE}_{X\rightarrow Y}(\ell)
=H(Y_t\mid Y_{t-\ell})
-H(Y_t\mid Y_{t-\ell},X_{t-\ell})
=I(X_{t-\ell};Y_t\mid Y_{t-\ell}). \tag{5-1}
$$

对10节点90条有向对，在滞后$\ell\in\{1,2,4\}$下用8分位分箱估计，并对每个“有向对×滞后”作100次循环平移置换。该方法保留部分自相关，但不能排除共同驱动或滞后选择不确定性。检验程序先取三个滞后中的最小置换$p$值，再以$p<0.05$标记候选，检验族为270项；最小可达$p=1/101\approx0.00990$，故名义候选仅作探索。

### 5.2.3 传递熵名义候选与双向读数不对称

90条有向对中76条达到未校正名义阈值；45个无向对中31对双向、14对单向。对双向候选定义描述性读数不对称度

$$
\operatorname{ASYM}_{ij}=
\frac{|\operatorname{TE}_{i\rightarrow j}-\operatorname{TE}_{j\rightarrow i}|}
{\operatorname{TE}_{i\rightarrow j}+\operatorname{TE}_{j\rightarrow i}+\epsilon}, \tag{5-2}
$$

其中$\epsilon$防止分母为零。阈值$\operatorname{ASYM}>0.3$标出20对（44.4%），但两个方向分别选择滞后，故不是共享滞后效应检验。100次置换可分辨的最小$p$为$1/101\approx0.0099$，而270项Bonferroni阈值为$0.05/270\approx1.85\times10^{-4}$，两者相差约53倍，故100次置换下校正后最小$p$只能取1.00，这只是分辨率的算术后果。把置换次数提高到10,000次（$p$下限$1.0\times10^{-4}$，低于上述阈值）重跑后，有3条有向对通过Bonferroni校正（校正$p$均为0.027）：CA-303$\to$CA-311（$\mathrm{TE}=0.003292$，滞后2）、CA-303$\to$CA-317（$\mathrm{TE}=0.003098$，滞后1）、CA-305$\to$CA-307（$\mathrm{TE}=0.001448$，滞后1）；另有5对处于$p_{\mathrm{adj}}=0.054$的临界带。因此原100次置换下的空结果应归因于$p$值分辨率不足，而非方向性效应不存在；提高到阈值以下后候选重现，但数量仍少，图5-2(a)、图5-2(b)提示的方向结构只宜作候选清单而非效应确认。

## 5.3 事件感知的区间预测：分层共形预测

### 5.3.1 问题与动机

整体点误差不能代表区间可靠性。本节比较Caltech与JPL的独立、滚动和回溯校准，并按标签事件检查覆盖失配[85-87]。

### 5.3.2 分层共形方法

对冻结模型残差$r=|y-\hat y|$，取$\alpha=0.1$构造名义90%区间。独立校准用有限样本顺序统计量，回溯实现保留原经验分位数。标准路径逐节点估计半宽$q_n$；规则分层路径对触发键跨节点共用$q_{\mathrm{trig}}$，未触发键逐节点使用$q_{\mathrm{stable},n}$：

$$
[\hat y-q,\hat y+q],\qquad
q=\begin{cases}
q_{\mathrm{trig}}, & \text{rule\_trigger}=1,\\
q_{\mathrm{stable},n}, & \text{rule\_trigger}=0.
\end{cases} \tag{5-3}
$$

目标侧事件只作评价，标签路由oracle仅作事后参照。图5-5展示旧规则路由：规则含事后代理负荷差分、验证段参与选模，均属历史限制。事件时刻协议与JPL结果见5.3.3—5.3.5节。

![分层共形方法](../../outputs/figures/fig5_5_conformal_method.png)

**图5-5 冻结规则路由的分层共形方法**  验证期以冻结预测残差校准，触发层跨节点合并、未触发层逐节点估计90%经验分位数。测试期由旧规则选择半宽$q$并与$\hat y$组成区间。目标侧标签不参与路由，旧规则含事后负荷差分，经验分位数不保证测试覆盖。

## 5.4 节点负荷预测的决策接口与验证条件

充电运营的日常分析以站点为单位展开，要回答三个问题：站内不同位置的充电量如何变化，需求集中在哪些时段，某时段的高负荷属于常态波动还是异常片段。

第3、4章对应其中的需求分析环节，对象为会话重构的15 min节点代理负荷：第3章比较时序基线与多关系图模型；第4章进一步区分配置敏感度、受检学生替代性和误差构成。Caltech事件时刻协议下（三种子，2024–2026），残差化主模型（MRG-GCN+线性头，八特征含`load_lag1`）整体MAE为0.015704 kWh/15 min，零值层为0.00559、非零层为0.08494；较无图的残差TCN（0.030709）低48.9%，较persistence（0.015896）低1.2%。JPL重拟合中，MRG-GCN整体MAE为0.081067 kWh/15 min，较三项预先设定基线低2.64%—3.36%；JPL侧尚未提供残差化重跑的读数，两站结果不可直接比较。

### 5.4.1 预测量与运行量的对应

本节将10节点预测汇总为容量核查接口。发布时刻$t$对应随后60 min内4个15 min目标片，片起点为$t,t+15,t+30,t+45$ min；首片虽从发布时刻开始，预测量仍为完整片段能量。定义集合代理需求和预测值：

$$
D_{\tau}=\sum_{n\in\mathcal N}y_{\tau,n},\qquad
\widehat D^{(m,s)}_{t,h}=\sum_{n\in\mathcal N}\widehat y^{(m,s)}_{t,h,n}. \tag{5-4}
$$

其中$m、s$表示模型和种子；$D_{\tau}$及$\widehat D_{t,h}$为按接入—断开均分的kWh/15 min代理。除以$\Delta t=0.25$ h可得区间平均代理功率：

$$
\widehat P^{\mathrm{proxy}}_{t,h}=\frac{\widehat D_{t,h}}{\Delta t}=4\widehat D_{t,h}. \tag{5-5}
$$

该换算不恢复片内波动。预测仅覆盖10节点；与全站限额比较前，须经同步计量校准并补入其他节点和非充电负荷。

### 5.4.2 从预测曲线到运行核查

运行核查前须核对时间戳、节点映射、输入可见性和目标片；校准后可与其他负荷、限额及备用裕度合并计算余量：

$$
M_{t,h}=P_{\mathrm{lim}}-P_{\mathrm{other},t,h}-\widehat P^{\mathrm{cal}}_{\mathrm{EV},t,h}-R_{t,h}. \tag{5-6}
$$

各项单位为kW，依次为有功限额、非充电负荷、校准后的全站充电预测和规程裕度。15 min均值不能检验瞬时尖峰、三相不平衡或热约束，正余量不等于安全认证。当前缺少完整运行输入，式（5-6）仅定义接口。

### 5.4.5 有限时域充电分配与合成决策算例

本节以人工设定的情景演示预测结果如何进入有限时域充电分配，构造如下线性规划。令$p_{j,h}$为车辆$j$在时间片$h$的计划功率，$\pi_h$为单位电量记账价格，目标是在满足车辆请求的前提下降低计划成本：

$$
\min_{\{p_{j,h}\}}\ \sum_{h=1}^{K}\pi_h\Delta t\sum_j p_{j,h}. \tag{5-7}
$$

每辆车具有服务窗、剩余电量需求和功率上限，并满足能量请求及站点容量约束。容量式中的不可调充电基线须经计量校准；若全站预测已含可调车辆，再将同一车辆请求加入会重复计量。当前模块只输出供复核的计划；采用无损、连续功率假设，未建模V2G、三相约束、离散电流、效率和执行偏差。

合成算例设置一辆车在四片内请求1 kWh、功率上限3 kW；不可调充电与其他负荷各1 kW，站点限额6 kW、备用1 kW，价格为4、3、2、1。求解结果见表5-5。

### 5.4.6 证据边界与应用验证要求

同站证据只有两类：8条电流形态样本和CA-303的11条累计电量序列。后者未校准，也不评价2021测试期预测。设备型号、固件、计量算法、校准与完整导出程序均未确认。本地快照没有保存`userInputs`，源端覆盖范围与更新时间未知；本地缺失不能作为源端无记录的证明。EPFL的限额与功率无法映射到ACN十个节点。

上述比较仍限于代理目标，表5-5只核验合成求解。实测误差评价要求节点映射一致、时间同步、计量边界明确的kW或kWh；运行评价还需要当时可见的请求、限额、其他负荷与电价。现有证据不足以支持现场越限、服务改善或成本节约。

事件层是上述边界中最紧的一处，两条不同来源的证据指向同一结论。第4章的交叉分组分解显示，回溯协议中1.39%的预测键贡献28.10%的绝对误差（见4.4节）；本章的区间评价显示，事件层的实测覆盖远低于名义覆盖率，14天滚动校准后虽有提升仍不足以支撑核查（见5.1节、表5-1）。前者说明事件键的单键误差远高于常态键，后者说明这些键上的预测分布同样未被区间校准捕获，故事件层既难预测，也难给出可靠区间。

可据此确定的是研究设计：后续重复实验应优先检验负荷与轮廓关系；模型比较同时保留全局与活跃片段指标；目标核验优先取得完成时刻附近的独立计量。这些用于安排复验与采数，不是运行控制建议。

在本窗与当前预算下，可得到三点结论。其一，两种标签下，MRG-GCN与容量近似TCN的三种子排序方向一致；该结果只说明所检窗口与两种模型内的排序一致性。其二，误差的绝对水平依赖标签：整体MAE上升约22%，非零组条件MAE上升而事件组下降；两组只报告条件MAE差异。其三，第3章报告的MAE只对应代理目标，换用其他口径须重新标定。

边界有三条。该窗不是论文原测试期；功率为设备上报，没有独立计量校准，半计量的电压由能量匹配反推，只能复现会话总量；分析只涉及两个模型与三个种子，未做超参数搜索。

主实验与代理标签重训窗口的零值比例与整体增益差异（均为旧七特征配置：前者五种子、增益16.4%；后者2024–2026三种子、增益16.1%）源于种子数与窗口设置，不作直接比较。




同一对模型换窗口后优势显著收敛，说明主实验的16.1%不能直接读作方法在活跃片段上的增益，也说明按整体MAE选型会把零值段的贡献误记为关系建模的贡献。

### 5.4.8 使用条件、准入与价值边界

整体选型可参考全局排序相关0.993（区间[0.893, 1.000]），其依据限于表3-10所列12种配置与已查看测试期。活跃片段评估须并列报告非零与事件分层，0.420与0.559说明这两层排序只在原口径内成立。区间使用以事件覆盖26.71%（表5-1，汇总见5.1节）作事件层参考，该值不构成覆盖保证。运营成本需另由告警频率与现场工时记录评估。

上线准入须同时具备同步计量与到达时间记录、冻结的事件定义、与训练一致的标签口径，以及固定的预算和早停规则。门控增量在Caltech与JPL为2.69%与2.71%，均取自三种子配对，方向判定须逐种子核对。JPL共享门控已有一个种子触及60轮上限，复现时须注明该条件。式（5-6）余量接口、合成线性规划与固定轨迹回放均已具备，与真实运行约束的联合调试仍待开展。

由此形成的后续离线研究顺序包括关系复验、同协议选型与告警阈值校准。关系复验按1.82%与1.52%的增量先检验负荷耦合与轮廓相似，行为共现0.15%跨零，列为观察项。N=10 与 top-k=3/5 使关系图接近稠密，自环替换属强干预；本文的增量读数不宜外推到节点数更多、图更稀疏的场景。容量控制的准入取决于可映射到所评价的十个节点的限额与备用裕度，收益估算还需电价与服务成本记录。



## 5.5 本章小结

本章检验了预测结果用于方向性分析、区间表达和运行核查时的证据边界。TE筛查未留下经家族校正的候选；该结果受置换分辨率限制，不构成方向性效应不存在的证据；区间整体覆盖与事件覆盖差异明显；标签构造检验显示，功率积分标签下重训的排序与均摊标签一致，误差水平上升约22%（同一重建窗、两模型三种子）；固定轨迹和合成线性规划展示了预测接口，但没有验证实际调度效果。

本章其他证据进一步限制用途：Caltech事件覆盖不足，JPL整体区间覆盖接近90%但事件覆盖低于50%。本章证据支持的是关系复验顺序、按评价目标选模和代理目标采数优先级，不支持设备选型、容量控制或收益估算。

# 结  论

## 主要研究结论

本文提出残差化多关系门控图卷积模型（以`load_lag1`为基准、模型只预测残差）与分层评价协议（MDP）两项方法，并在公开会话记录重构的 15 min 节点代理负荷上，就站内三类统计关系的预测价值给出三条条件性结论。

（1）针对零膨胀节点负荷下整体MAE被零值键主导、且行为特征无法替代历史负荷的问题，本文提出残差化多关系门控图卷积模型：以`load_lag1`为基准、模型只预测残差。该模型在Caltech事件时刻协议上整体MAE为0.015704（三种子，2024–2026），零值层误差为0.00559，非零层为0.0878，参数量33,902；较无图TCN低48.9%，较persistence基线低1.2%。新旧对照显示，原七特征非残差配置的整体MAE为0.036326，补入历史负荷并改为残差预测后降低56.8%，故输入缺历史负荷是原模型的根本约束；图结构在残差化架构下贡献48.9%，高于旧配置下的16.4%。非零层仍是数据稀疏下的硬瓶颈，故整体MAE不宜单独作为分层能力的依据。

（2）针对整体误差无法归因到关系类别与样本层级的问题，本文提出分层评价协议（MDP），把关系增量按评价层、标签口径与参数配置分别测量。回溯协议中1.39%的预测键贡献28.10%的绝对误差，交叉分组分解经加权还原校验自洽；冻结预测上替换标签口径后全局排序保持一致，非零层排序只在原口径内成立，故非零层排序不宜单独作为选型依据。

（3）针对关系图增益默认成立、缺少可归因测量的问题，本文提出关系增量的条件性测量方法，以同参数自环替换重训与同参数门控配对逐条关系剥离增量。负荷耦合与轮廓相似分别使整体MAE降低1.82%与1.52%，行为共现的增量区间跨零而不计为增量；该增量限于相同已查看测试期与JPL单站预算，复验顺序据此确定。

统计口径与解释边界：主结果按三种子（2024–2026）均值报告，旧七特征配置的对照以五种子均值±样本标准差与三种子配对差值为基础，配对检验为单侧Wilcoxon，关系子集扫描另作Bonferroni校正；保真项权重按调参集原单位MAE选定，测试期只作一次性报告，上述检验未对敏感性扫描作多重比较校正；区间跨零处只报区间、不引用点估计作结论；JPL为重新筛选与重训而非零样本迁移，非零层改善的显著性受种子数限制。

在证据覆盖的范围内，可直接使用的做法有三项：按评价层分别选型而非只看全局MAE；对关系增量按条件复验而非默认成立；在更换标签口径时重新标定误差水平。其准入条件见5.4.8节。

由此，本文不把整体MAE当作唯一选型依据，不把三站结果外推为跨运营商或未来期泛化，也不把代理电量结论直接用于计量功率场景。

## 研究不足与展望

（1）证据限于ACN同源数据的已查看测试期：JPL与Office 1属同一数据家族，跨数据家族与未见时期的表现均未验证；关系增量的条件性结论还限于JPL单站与60轮预算。

（2）代理目标与设备计量功率的衔接仅完成先导核对，未达可校准级，设备算法与校准链未核实；标签口径由会话均匀分摊改为设备上报功率积分时，误差水平改变约22%（表5-6，重建窗非原测试期、两模型三种子）；非零层改善的显著性亦受种子数限制。

（3）预测区间的实测覆盖严重不足，事件层尚不可用。名义90%区间在回溯与事件时刻协议测试期的实测覆盖分别为69.6%与79.55%，事件层仅1.9%—3.87%；14天滚动校准把整体覆盖提至89.01%、事件层提至26.71%（行为分层路径；标准逐节点路径膨胀6.25倍），但区间宽度膨胀为冻结方案的4.47倍（表5-1），区间尚不能直接用于运行核查。

（4）后续可开展跨数据家族验证、事件层区间校准，并把活跃判定概率用于运行核查；三者均以取得与预测同步的独立计量与输入到达时间记录为前提。式（5-6）余量接口、合成线性规划与固定轨迹回放已完成，与真实运行约束的联合调试仍待开展。

## 数据与代码可用性

数据取自ACN公开会话数据（Caltech单站与JPL场站）及ACN-Data Static设备时序快照，字段定义、节点筛选与四段切分见2.1节；建模代码、训练配置与逐运行指标按固定版本保存，可在不涉及第三方数据许可的前提下按请求提供，原始记录与逐键预测不随论文附送。
