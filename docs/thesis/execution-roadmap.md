# 执行路线

## 阶段 1：数据可行性

1. 已完成节点别名、一一映射和时间稳定性审计。
2. 已按年月和数据划分统计每个节点的会话数、非零时间片率与能量覆盖。
3. 已在不使用测试集选择信息的前提下冻结 10 个主分析节点和 15 个敏感性节点。
4. 下一步生成无泄漏的训练、验证和测试张量及预测键清单。

**阶段状态**：数据门禁已通过。研究可使用“站内空间单元统计关系图”表述；
在物理设备语义得到额外证据前，不将节点直接称为独立充电桩。

## 阶段 2：时空基线

1. 训练 TCN 默认时间路径。
2. 训练固定站内图模型。
3. 在数据支持时训练 Graph WaveNet/AGCRN 风格自适应图模型。
4. 统一导出三种子预测长表和计算成本。

**退出条件**：证明跨节点图关系是否带来稳定增益。

## 阶段 3：事件残差修正

1. 仅用训练集和验证集建立事件规则、候选关系及残差边界。
2. 冻结规则后一次性应用于测试集。
3. 对事件窗口施加有界修正，稳定窗口保持默认预测。

**退出条件**：事件收益成立且稳定窗口无显著退化。

## 阶段 4：机制诊断与论文写回

1. 完成消融、敏感性、四格还原、节点和步长诊断。
2. 与 TCN、STGCN、AGCRN、Graph WaveNet 等统一比较。
3. 按证据边界决定最终主张：整体时空预测增益，或仅保留事件窗口条件性收益。
4. 再规划论文结构、图表和工程意义，不提前覆盖旧论文。
