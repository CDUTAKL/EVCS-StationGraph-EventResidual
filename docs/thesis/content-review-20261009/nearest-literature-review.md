# 近邻原文比较备忘录：EV站内多关系、节点门控与参数诊断

日期：2026-10-09  
范围：仅核对论文1.2节/表1-1涉及的[10]、[12]、[13]、[67]、[70]，并补充最接近“多关系门控 + 节点特定参数”的方法近邻。没有修改论文、引文或参考文献。

## 核心判断

- 直接EV充电负荷近邻中，[10]与本文“节点参数适配/组件消融”最接近：以13座公共充电站为图节点，建动态图并用NAPL生成节点特定GCN参数，去除DAGG、NAPL进行消融。其节点仍是不同公共充电站，不是同一场站内的充电桩/空间节点；所核全文未见本文这种多种语义关系分图、节点级关系消息门控、冻结关系参数替换。
- [70]明确使用距离、交通网络、交通密度等多图，并以多图注意力融合，说明“充电站群多图融合”已有直接先例；它的节点是城市站群中的充电站，不能支持站内桩节点任务的数值对照。
- 门控与节点特定图卷积参数的最贴近方法先例是住宅负荷预测STGNet（Feng等，建议作为补充方法比较）。它以住宅单元为节点，把DTW时间相似邻居与可学习自适应邻居的图表示经sigmoid门控逐元素融合，并以节点嵌入和共享参数池生成节点特定GCN参数；但不是EV充电研究，其组件消融不等同于冻结关系权重替换。
- 因而本文可谨慎定位为：在单一EV场站的充电节点/代理能量任务中，拆分负荷、行为、轮廓三种训练期统计关系，使用关系级权重和节点级门控，并对参数配置作冻结替换及其他诊断。不要声称动态图、多图、节点特定参数、门控或消融本身为首创；不要把所选文献间的性能作横向排名。

## 重要核验缺口

1. [12] 与[13]的官方记录提供摘要，但本次没有取得可解析的全文；不能仅凭模型名推断节点门控或节点参数共享。
2. [67] 当前可核实的正式机构摘要仅描述CAGLM/CRGLM及多城逐小时验证。“历史负荷因果图”这一输入来源、图学习细节、参数共享和消融范围待全文核验。
3. [70] ScienceDirect正式摘要可支持多图构造与多步验证；全文受限。详细切分与外生特征的预测时可用性不能据索引段确认。
4. [10]与STGNet的参数矩阵化/节点特定参数有强方法相似性，但各自都采用模块消融；不要将它们误写为已做冻结参数功能干预。
5. 被比较文献使用不同预测对象、采样粒度、数据集、输入权限和验证协议；本比较只定位研究问题和建模先例，不构成模型性能排行榜或创新性优先权结论。

## 可落入正文的中文句草案

> 黄南天等[10]以13座公共充电站为图节点，依据站间负荷数据学习自适应时空图，并通过节点嵌入与共享权重池生成站点特定的图卷积参数；其去除动态图生成和节点参数学习模块的消融表明，EV充电负荷预测中已出现站间动态图建模与节点参数适配。该研究的节点是不同公共充电站，不能直接等同于单一场站内的充电节点；其模块消融也不等同于本文冻结关系参数后的功能干预。

> 张延宇等[12]将多头注意力、自适应相关图、Chebyshev图卷积和多尺度时间卷积用于EV充电负荷预测，并在两个真实数据集上验证。其可访问摘要未交代节点定义、输入字段及预测时的信息权限，本文仅据此确认自适应图和时空卷积的应用，不进一步推断其节点级门控或参数共享方式。

> Xie等[70]构造距离、交通网络和交通密度多图，并以多图注意力融合预测城市充电站群负荷，说明充电站群层面的多图融合已有EV应用。本文所用的负荷耦合、行为共现和日内轮廓关系面向单场站内节点，关系语义和预测粒度均不同，故不据此作数值排名。

> 在一般多节点负荷预测中，Feng等提出的STGNet以住宅单元为节点，门控融合DTW时间相似图与自适应图，并以节点嵌入和共享权重池生成节点特定GCN参数；其模块消融检验了图分支和节点参数化的作用。该工作不是EV充电预测，本文与之相关的是多节点负荷建模中的门控和节点参数化方法，而EV单场站任务及冻结参数诊断仍须按各自证据边界表述。

> 因此，本文不主张自适应图、多图融合、节点门控或节点特定参数的一般形式为首创；其问题定位限于单场站充电节点代理能量预测，将负荷、行为和轮廓三类训练期统计关系分开建模，并在统一协议内考察节点级门控、冻结参数替换和误差构成。现有近邻的对象和协议不同，跨文献数值不可直接比较。
