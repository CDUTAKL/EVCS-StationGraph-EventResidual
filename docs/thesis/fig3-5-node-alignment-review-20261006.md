# 图3-5节点编号对齐复查

用户指出上轮图3-5的CA序列视觉上未对齐。检查确认：冻结训练数据与当前数据张量的SHA256一致，三幅矩阵的节点顺序相同；55°倾斜、右端锚定的横轴标签偏离列中心，造成编号与对应列的错配感。上轮只核对节点顺序，未充分检查标签位置。

本次将横轴完整CA编号改为90°竖排、居中定位；纵轴编号保持水平，并明确垂直居中。编号使用等宽字体DejaVu Sans Mono，保留真实标识中的ASCII连字符。三幅矩阵的布局、刻度和网格共用同一尺寸与坐标规则。

节点顺序均为：CA-303、CA-304、CA-305、CA-307、CA-311、CA-315、CA-317、CA-321、CA-327、CA-489。该顺序来自训练时的正式张量，不补入未入选节点，不为了排版重排矩阵。

复查分三个层次：

1. 对照训练运行的manifest和当前数据张量哈希，确认节点来源；三幅原矩阵及其300个数值保留。
2. 绘图时逐项检查30个横轴标签与列中心、30个纵轴标签与行中心，允许误差0.05像素；同时核对三面板的底边、宽高及矩阵值。
3. 重新打开最终PNG进行视觉复查，并独立解析导出SVG，核对三面板的行列标签顺序、均匀刻度间距及一致的文字定位；再同步正式Word，核对嵌入图与正式PNG哈希。
