# ACN v3 五项扩展分析：结果与复核说明

## 研究范围

分析对象为 ACN-Data-Static 中 Caltech California Garage 的 2018-05-01 至 2018-06-11 会话时序。该窗口处于论文主模型训练时期，只核验代理标签与设备上报序列的差异，不评价模型对真实功率的预测能力，也不是独立留出测试。

报告中的 A 指设备上报累计电量差分序列，B 指设备上报功率积分序列。两类字段来自同一数据导出，设备算法和独立校准资料尚未核实。

## 五项扩展结果

### 1. 积分与分箱参数敏感性

固定最大桥接缺口阈值由 15 s 调至 300 s 时，B 功率积分高覆盖样本数由 1,769 增至 1,806，52 节点宏平均 MAE 降幅为 48.47%—48.61%。这是对阈值与样本共同变化的敏感性检查，不能解释为同一固定样本上的纯参数效应。

覆盖率阈值 0.90、0.95、0.99 对应的 MAE 降幅为 48.52%、48.56%、48.04%，样本量分别为 1,826、1,794、1,694。代码显示这些数值以功率覆盖率筛样，但误差参考序列为 A 累计电量差分。

分箱相位偏移 0、5、10 min 时，A 参考序列下的降幅为 48.76%、48.96%、48.94%（各 1,794 条会话）。A 累计电量边界模式的两种实现逐位相同。因而可以说所检设置下方向一致；不能概括成“B 功率主结果对所有参数均不敏感”。

### 2. 高覆盖子集代表性

高覆盖组 1,794 条、低覆盖组 541 条。交付电量、接入时长和完成后占桩比的标准化均差分别为 0.008、−0.007 和 0.011；接入小时存在较小差异（SMD=0.132），月份分布也不同（Cramér's V=0.263）。高覆盖组相对低覆盖组的截断标签 TVD 较低（SMD=−0.214；原分析 Holm 校正 p=0.00475）。

因此，描述变量大体可比并不能消除覆盖筛选偏差。B 的具体误差只适用于对应的高覆盖样本；该子集的截断残余误差可能偏低，不能将其数值直接推广到全部会话。

### 3. 完成后占桩时段与标签差异

在 1,763 条有效完成时刻会话上，包含节点固定效应及电量、时长、接入时刻和长缺口控制项的回归显示，`idle_ratio` 线性项与均分 TVD 正相关（系数 +0.590，95% 区间 [0.541, 0.639]）；与截断 TVD 的条件关联较弱且为负（−0.112，[−0.188, −0.036]）。均分—截断 TVD 差的相应系数为 +0.702（[0.648, 0.755]）。模型还包含 `idle_ratio` 二次项，因此线性系数不能单独解释为全范围平均边际效应。

分层中，完成后占桩比由低到高时，均分 TVD 中位数从 0.155 增至 0.760；截断 TVD 中位数保持在 0.135—0.162。结果与“均分标签的偏差与完成后的空置时段相关、截断减少了这一特定偏差源”一致。它是观察性分解，不能单独证明因果。

### 4. 时间粒度与聚合尺度

`multiscale_metrics.csv` 的多尺度误差以 A 累计电量差分为参考，样本由 B 功率覆盖率筛选；其 52 节点宏平均 MAE 降幅在 15、30、60 min 分别为 48.76%、44.17%、38.32%（每尺度 1,794 条会话）。全站 52 节点聚合相应降幅为 46.32%、45.05%、44.73%。因此“约一半”只适用于这里的 15 min 节点级口径，时间粒度变粗后节点宏平均降幅收窄。

校正后的 10 节点 15 min 结果在该多尺度表中也是 A 参考值：0.141710→0.075910 kWh/片，降幅 46.43%，n=548。它与 v4 的 B 功率参考值 0.142595→0.076790 kWh/片（46.15%，n=548）对应不同测量参考序列，不应混称或互相替代。

### 5. 统计不确定性

报告的百分位 bootstrap 区间包括：会话 TVD 中位数差 0.222（[0.201, 0.246]，按会话重抽样）；52 节点 MAE 差在 A 下为 0.0394（[0.0320, 0.0472]）、在 B 下为 0.0402（[0.0329, 0.0480]，均按节点重抽样）；10 节点 B 参考 MAE 差 0.0658（[0.0489, 0.0838]，仅 10 个节点）；全站聚合日块 bootstrap 差 0.738 kWh/片（[0.632, 0.851]）。这些区间依赖各自的重抽样单位，不能视为对所有时间相关和空间相关都稳健的统一区间；10 节点区间尤其受集群数较少限制。

CSV 中 `p_boot=0.0` 是有限重抽样的经验尾部频率为零，不是总体概率精确等于零。原报告中“方向性结论不受节点聚类与时间自相关影响”的总括句缺少相应检验支持，本复核不保留该结论。使用时以各自重抽样方案和区间为主，不沿用 `p=0.0` 或 Holm `p=0.0` 的表述。

## 与 v4 的关系

v3 扩展结果与 v4 标签核验并非同一实现。v3 固定使用 60 s 缺口阈值，其核心扩展表还包含按覆盖率筛选后采用不同参考序列的结果；v4 使用 `max(60 s, 3×会话中位采样间隔)`、更严格的时间边界处理，并更新了节点和样本口径。两者方向一致，但样本数、基准和统计定义不同。若论文要引用五项扩展数字，应先把对应分析按 v4 代码和样本口径重算或在正文明确标为 v3 探索性补充，不能把数字拼接成一组“最终结果”。

## 可以支持的判断

这五项分析加强了一个范围明确的结论：在已检窗口内，接入—断开均分会把一部分代理电量分到完成后的占桩空窗；在相同窗口的设备上报序列对照中，采用有效完成时刻截断后，标签形态和节点误差指标总体改善。它为代理标签构造提供设备侧佐证。

它们不证明全期误差降幅、独立校准真值、真实功率预测能力或运行收益。当前论文可将其作为训练期内标签口径核验的扩展证据，后续再决定是否按 v4 主口径统一重算。
