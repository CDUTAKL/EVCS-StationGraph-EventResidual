# 最小新增训练设计：关系条件增量与后续证据

日期：2026-10-15。状态：设计完成、代码待实现、未启动训练。设计标识 `PLAN-RELATION-20261015`；不复用已撤回的 SG-EXP-030 建议编号。正式实施时另注册实验编号并冻结设计哈希。

## 1. 优先回答的问题

在相同容量、输入、训练预算和选模规则下，保留另外两类关系，将某一类跨节点关系替换为自环后，整体 MAE 是否提高？这直接补充表3-12和BR-10的条件增量证据。AdaptiveGraph 三检查点复算已经通过，本轮不再训练该旧模型。

最先做 JPL：有同款4090 D历史耗时、冻结数据和完整模型对照，且训练样本较少。默认仅安排第一阶段12次训练。Caltech复核、延长门控预算、MDP引导改进为独立后续阶段，不自动叠加。

## 2. 第一阶段：JPL，4配置×3种子

| 配置 | 三个关系槽位 | 作用 |
|---|---|---|
| full | load / event / pattern | 同期完整模型对照 |
| load_to_self | I / event / pattern | 检验负荷关系跨节点信息的条件价值 |
| event_to_self | load / I / pattern | 检验事件关系跨节点信息的条件价值 |
| pattern_to_self | load / event / I | 检验模式关系跨节点信息的条件价值 |

此处正文 LRE 命名与代码槽位须在实现时逐项核对，不能按字母猜测顺序。I为10×10自环，经同一邻接处理路径使用。

保留三组关系变换、两层β、节点门控、精炼、跨层融合和预测头；每组变换都参与前向及梯度计算。预期每配置32714个可训练参数，正式启动前必须实测相等。直接删分支会改变参数量；保留无效参数但切断计算也不能作为容量公平证据。

这项对照测量“跨节点关系相对自环替代的条件价值”，不等同于关系严格不可替代，也不证明三种关系携带互不重叠的信息。若关系有效但仍需检验其特异结构，可另预登记置乱图对照；本轮不新增此组。

三个种子固定2024/2025/2026。从头训练，四配置同种子的非邻接初始参数逐张量一致、同一epoch的样本顺序一致。不得从已训练full热启动消融模型。历史full只作背景和一致性参照，主比较使用本轮同期full，避免代码或机器差异混入。

## 3. 冻结训练合同

- 数据：沿用 SG-DATA-007-JPL 事件时刻协议，数据SHA-256 `1bfc42fab6f127b2ec1735b3821bb272a444185f1861bfe95f489d15e78738af`；复用冻结 train/tuning/calibration/test 原点，不重划分。
- 输入：7项因果可用行为/日历特征、10节点、96历史片，预测后续4目标片。事件真实标签仅用于事后评价，不作输入、训练加权或选模条件。
- 关系图、标准化参数、规则阈值均复用既有训练来源及其manifest；不要在全部数据上重算。
- 架构：hidden32、TCN6层、dropout0.1、关系随机失活0；其余沿用冻结MRG配置。
- 优化：AdamW，lr0.001，weight_decay0.0001，batch256，梯度裁剪5，标准化L1。
- 预算：每配置最高60轮，耐心8；每轮完整tuning原单位MAE选best。相同上限及规则，不要求实际停止轮次相同。
- 精度：FP32、确定性算法、关闭TF32，沿用原环境 PyTorch2.8.0+cu128/NumPy2.3.2。前轮AdaptiveGraph的2.4.1复算环境只用于旧检查点，不作为本轮新训练环境。
- 数据范围：train/eval_limit均为null。calibration/test不参与训练、早停、配置选择或种子选择。

## 4. 时间预算：基于真实历史日志

历史JPL同款4090 D，full三个种子的停止轮次35/33/32，训练加tuning耗时5.59/5.28/5.12分钟，每轮中位耗时约9.5秒。历史Caltech在5090上约17.6秒/轮，不能直接作为4090性能承诺。

| 范围 | 运行数 | 按JPL历史每轮9.5秒计算 |
|---|---:|---:|
| 第一阶段，平均35轮 | 12 | 约66.5分钟训练+tuning |
| 第一阶段，全部60轮 | 12 | 约114分钟训练+tuning |

计划为第一阶段预留2–3小时，包含数据准备、预测导出、核验、网络回收。此为预算估计；实际逐轮耗时可能变化，首次4配置seed2024完成后更新估算。估算更新不改变正式60/8合同。

缩时主要依靠缩小实验矩阵、复用冻结数据和现有实现，而非削减证据。12次运行按固定队列顺序执行；不因先看到的test好坏删种子。小模型不保证多进程并发更快，首版单进程顺序训练，避免CPU数据加载和CUDA争抢。

先用一小批train做纯前向计时与参数/梯度路径静态检查，正式训练开始后记录前5轮中位耗时；计时不接触test。可缓存标准化数组和图，保留原样本及shuffle顺序。更改DataLoader、批大小、AMP或torch.compile均不是本轮默认提速方案；需另做等价性核验并让所有配置同步采用，不能边跑边改。

运行到第30轮时允许人工暂停全部队列以检查耗时和收集断点，不以30轮结果替代正式合同。以last.pt保存优化器、CPU/CUDA RNG和样本epoch，恢复必须通过原contract检查。超出预留时间时记为暂停/未完成，不人为截断某个劣势配置并宣称正式结果。

## 5. 评价、统计与阴性结果

主指标：共同测试键的原单位整体MAE。三项主比较分别为replacement减full，正值表示full更好。报告每个种子结果、均值、绝对差和相对差，不将重复预测键或三个种子视为大量独立样本。

配对统计以完整连续7日块为重采样单位，三个种子先逐键平均误差，再计算块内差异；采用10000次配对块bootstrap、固定统计种子20261015，三项主比较用Bonferroni同时区间（每项98.333%区间）。先核验时间覆盖和有效块数，不足则不报可靠区间；参考既有JPL块构造并保存块键清单。七日块只近似处理时间相关，不宣称完全独立。

次指标：RMSE、事件/非事件MAE、非零目标MAE、逐节点和逐目标片MAE，以及L3四格加权还原。默认描述性分析；不能用某个次指标替换未改善的主指标。零改善、方向反转、个别种子失败均保留。

若三项校正区间均支持正差，可写“所检JPL协议与预算下，三类关系的跨节点连接相对自环替代分别有条件增量”。若仅部分成立，只报告对应关系；若全部不成立，缩窄完整三关系配置的贡献陈述。既有test已查看，本设计属于在已知数据上的补充实验，不能包装为全新盲测或预登记独立确认。
