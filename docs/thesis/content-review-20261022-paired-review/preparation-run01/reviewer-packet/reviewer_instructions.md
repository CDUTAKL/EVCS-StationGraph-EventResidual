# 隔离评阅者说明（可进入盲评材料包）

量表`EVCS-THESIS-CONTENT-1.0`；执行协议`EVCS-THESIS-REVIEW-2.0`。这是专业硕士论文内容模拟评审，不是期刊选稿；不预测学校等级。数值12项/90分，每项0.5分步长，合计后换算百分制。不要按自身侧重点修改权重。

只读分配的旧稿、当前稿、相同证据材料、rubric.json、criterion-anchors-v2.json和本说明；不读项目评分README、history、publication-status或旧评阅。完整读两稿，独立评12项；技术、原创性、可读性只影响关注顺序，不增加要求或改变评分尺度。

先按组件判断已满足与未满足条件，再相加。每项给出正文位置、已读证据、理由、缺口。对两稿同一事实采用相同锚点；只因旧问题被这次发现，不得只降低当前稿。评价依据未变，该项旧新分应相同；真正变分须指认文字、证据或主张变化。

每个担忧区分已证实缺陷、已声明范围限制、后续拓展和未核实疑点。潜在问题在未核实时只建议检查。一个根因原则上一个主要指标，跨项需给不同受影响要求及独立证据。

贡献可以是算法、经验知识、评估方法或工程问题解决；不统一要求新算子、所有指标领先或现场部署。阴性结果也可充分回答问题。理论分检查概念/公式/假设；工作量分看实际难度和问题解决，不因缺外部新数据或现场部署重复扣分。证据分对照作者实际限定的主张评价，不能临时以更强目标替换它。

保存原始报告和reviewer-record-template.json；按12个数值由代码计算总和，不凭心算。记录唯一上下文ID，明确历史分数是否暴露（未知不能填写false）。不要在评阅中读取另外两份意见。

主评随后核实发现和裁定分歧。你提供的意见不等于最终分数，也不是学校官方结论。未检查的材料或图像必须明示，不能自动记为通过。
