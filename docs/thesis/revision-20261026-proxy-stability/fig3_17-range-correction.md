# 图3-17范围线解析纠正（FIG-3-17-RANGE）

在后续代码核查中发现，旧parse_range用带可选正负号的findall抽取两个数字，会把区间分隔符解释为第二个端点的负号。例如0.972-0.979被读为(0.972, −0.979)，−0.112-0.098被读为(−0.112, −0.098)。因此图3-17 A面板的逐种子范围线错误；CSV、逐种子结果、正文和表3-16的统计数值不受该绘图解析错误影响。

修复显式匹配“端点、分隔符、端点”，再检查Spearman范围及端点顺序。回归检查将六行CSV的解析结果与results.json中三个种子的实际最小/最大相关系数逐项比较，并检查正负端点、不同连字符、倒序及非法输入。

该项说明此前图件验收漏检了数据到图元的映射，不应把原PDF的图3-17继续记为正确。图件美化任务完成后，合并本解析修复并统一重绘、更新图清单，再集中导出正式Word/PDF和全页验收。当前隔离分支只修复脚本及检查，不覆盖正在进行的样式改动。
