## 核验结果

JPL三个正式MRG-GCN检查点、冻结数据与原预测通过来源核验。每运行632,640个键，原点、节点、目标时间、真值及目标/规则掩码逐数组一致。基线CPU前向相对原CUDA导出最大差2.08337×10⁻⁶，低于既定5×10⁻⁶容差。

完成三种子×（基线＋七种β替换＋函数保持重参数化），共27组完整测试前向。另一个不依赖torch的脚本从保存预测独立求和，24组基线/替换指标差为0，三组重参数化差均在容差内；四格闭合最大差1.38778×10⁻¹⁷。全部源配置、日志、检查点及原预测计算前后SHA-256保持。
