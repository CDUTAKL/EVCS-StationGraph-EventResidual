## 5. 图 3-1 MRG-GCN 整体架构图（第 3 章 3.5.1 节）⭐ 核心

- **内容**（横向数据流）：输入 [B,T,N,F]（96 步/7 特征/10 节点）→ TCN 编码
  （L=6、RF=127、逐时间步 LayerNorm）→ h₀ → GCN₁（三关系消息 ÂᵣH Wᵣ →
  β₁ softmax 融合 → G 门控 → LayerNorm）→ h₁ → GraphMLPRefine（h₁′=h₁+MLP(h₁)）
  → h₁′ → GCN₂（同构，β₂ 独立）→ h₂ → Skip Fusion（h₀‖h₁‖h₂ → GELU/LN/Linear）
  → 预测头 → [B,H=4,N]
- **要点**：三关系输入用三种颜色小卡片（load/event/pattern）；每模块下方标张量维度；
  底部可加 1-2 行设计要点（因果无泄漏/两层独立 β）
- **尺寸建议**：横幅 16:10，GCN₁ 块最大（内部展开），GCN₂ 块同构缩小
