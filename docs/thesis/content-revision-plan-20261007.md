## 四、文字简洁与规范规则

### 1. 段落与句式

- 每段回答一个主要问题，首句给出判断或段落任务；随后给证据与必要解释。
- 一个句子尽量承担一项主要判断。三套协议、多个分母或多项限制同时出现时拆句或转表。
- 结果段报告观察，讨论段解释意义和替代解释；避免结果段反复引入新的背景。
- 句子超过约70个汉字、含三项以上并列信息时优先检查是否过载。此为检查提示，不是机械字数上限。
- 删除空泛程度词和套话，如“充分证明”“全面揭示”“显著提升工程价值”“为……奠定坚实基础”。用具体对象、指标及条件替代。
- 公式符号、单位、引用和必要条件随句保留，压缩时不得割裂。

### 2. 按证据强度选词

| 使用情形 | 推荐措辞 | 应收紧的表述 |
|---|---|---|
| 固定协议性能比较 | “在所检协议下，整体MAE降低……” | “全面优于现有方法” |
| 时间块区间 | “固定测试期的配对时间块区间高于零” | “证明对任意场站稳定有效” |
| 冻结参数替换 | “所检替换使误差升高，表明联合配置的功能依赖” | “证明该参数具有独立贡献” |
| 所检学生蒸馏 | “当前学生设置未弥合师生差距” | “图知识不可蒸馏” |
| 四格还原 | “验证分组与误差汇总的一致性” | “验证现实因果机制” |
| 滚动校准 | “经验覆盖改善，伴随区间增宽” | “实现90%可靠覆盖保证” |
| JPL | “另一ACN场站的固定协议重新拟合” | “零样本迁移”“未来时期验证” |
| 合成决策 | “给定合成输入下满足所设约束” | “实现电费节约或现场调度收益” |

“显著”用于有明确比较对象、统计方法与适用范围的统计陈述；其余地方优先使用“较低”“增加”“方向一致”等可核对措辞。

### 3. 术语与限制集中管理

统一使用“节点代理负荷”，首次说明其为15 min时间片代理能量，单位kWh/15 min。功率换算仅在对应算例中定义。统一“关系级β权重”“节点级门控”“目标侧标签事件”“规则触发”等名称，避免将其混称注意力或因果贡献。

将限制分成三级：对象与数据条件放第2章；影响局部结果的条件紧随结果；全论文推广与应用范围放讨论和结论。允许简短回指，避免逐段复述。原单位、种子离散度、时间块区间、样本占比和百分比降幅的分母应随相应表图注明。

### 4. 建议表达示例

**预测贡献：** “在所检事件时刻输入协议下，关系路径相对近似参数匹配TCN降低整体MAE。同参数配对结果进一步显示，保留节点差异的门控在Caltech和JPL分别获得约2.69%和2.71%的MAE增量。”

**MDP贡献：** “三层诊断分别检查联合参数依赖、受检学生替代能力和样本误差来源。分析表明，冻结β替换的退化不能识别β独立增益，而全局改善与困难事件可靠性需要分开评价。”

**区间边界：** “成熟标签14天回放将行为分层整体覆盖提高至89.01%，平均宽度增至冻结方案的4.47倍；事件覆盖仍为26.71%。结果支持所检时期的失配缓解，尚不足以支撑困难事件防护。”

示例用于确定表述强度。实际入稿时应保留对应来源、比较基准及相邻上下文。
