## 2. 实验合同

新协议为`SG-DATA-006-eventtime-v1`：预测原点只使用接入、离站、活跃计数和当地日历
七通道，目标仍是事后会话能量代理。所有配置按同一96→4窗口、同一时间切分、三种子、
AdamW、最多60轮、patience=8和tuning原单位MAE选best。phase1包含`mrg_full`、
`tcn`、`tcn_wide`、`mrg_self_loop`、`agcrn_full`；phase2包含等权β、固定门、去精炼、
去跨层拼接和三种单关系等变体。

审计确认best/last检查点、实际停止轮次与早停原因、selected/best epoch、有限训练日志、
calibration/test未参与选模、逐键预测、四格还原、数据哈希和代码哈希均符合合同。36个
运行中有30个由patience=8触发早停，6个达到60轮预算上限；达到预算上限的运行仍是
固定预算下的正式比较，不宣称渐近收敛。

## 4. 以mrg_full为参照的描述性差异

下面的百分比只用于描述同一新协议下的相对差异，不是显著性检验，也不使用跨协议
旧结果。以`(MAE_variant / 0.0389 - 1)×100%`计算：

| 配置 | 相对mrg_full |
|---|---:|
| `agcrn_full` | −3.86% |
| `mrg_equal_beta` | −0.77% |
| `mrg_no_skip` | +0.26% |
| `mrg_no_refine` | +1.03% |
| `mrg_pattern` | +1.54% |
| `mrg_fixed_gate` | +5.66% |
| `mrg_load` | +10.80% |
| `mrg_event` | +17.22% |
| `mrg_self_loop` | +18.51% |
| `tcn` / `tcn_wide` | +19.02%（按0.0463点估计） |

由于只有三个随机种子且共享测试时间段，不能把上述差异写成统计显著，也不能把
`mrg_equal_beta`比`mrg_full`低0.77%写成β学习“没有贡献”或“有稳定收益”。正确表述是：
在当前新协议和所检配置下，未观察到可辨识的可学习β增益。

## 5. 可以保留的结论

1. 固定门值的退化最大，说明门控路径具有较清晰的功能依赖证据；该结论在三种子逐运行
   结果中保持，但不升级为统计显著性结论。
2. 三关系融合优于`load`、`event`和`pattern`三个单关系变体，支持“关系信息具有
   互补性”这一窄结论；不能据此声称每一关系都有独立正增益。
3. 去除跨层拼接和精炼的全局差异很小，不能把它们包装成与门控同等强度的关键创新。
4. `agcrn_full`在新协议下数值最低，因此新协议不能支持“MRG普遍优于完整AGCRN”。
   这不推翻旧主线，因为旧主结果和新协议回答的是不同的信息可见性问题。

## 6. 公平比较的真实缺口

当前已经有` tcn_wide`作为近似参数匹配的无图基线：本地合同检查为`mrg_full=32,714`
和`tcn_wide=32,674`个可训练参数，差异约0.12%。完整`agcrn_full=199,912`个参数，
约为`mrg_full`的6.1倍，应在表中标为“能力基线”而不是“容量匹配基线”。

仍缺两类严格意义上的补充：

- 新协议七通道下、同窗口/切分/种子/预算的GRU或MLP（并给出线性或均值下界），以排除
  TCN实现差异对“图收益”的影响；
- 在相近参数量下的AGCRN或明确的容量受限AGCRN，以分离结构差异和容量差异。

若不重新开机，正文只能把新协议定位为“MRG内部消融、容量匹配TCN和完整AGCRN的
压力测试”，不能写成新协议下所有基线均已公平重跑。旧协议GRU/MLP数值不能直接搬入
新表。

执行边界：本次不因`agcrn_full`的较低数值自行改变论文主线，也不为补齐缺口再次启动
付费实例；只有在导师明确要求“新协议下完整公平基线”时，才按同一合同补跑行为输入
GRU/MLP、线性或均值下界及容量匹配AGCRN，并以新登记号独立报告。

## 7. 与旧主实验的关系

旧SG-DATA-005/SG-EXP-003的`mrg_full=0.01376`是在事后重构代理负荷输入上的旧主结果；
新SG-DATA-006的`mrg_full=0.0389`使用更严格的行为可见输入。两者不应计算百分比下降，
也不应把新数值称为模型退化。新实验适合放在“协议敏感性与可见性边界”位置：它说明
在删除旧代理负荷输入后，MRG的关系和门控仍保留部分相对价值，但其优势不是对完整
AGCRN的普遍胜出。
