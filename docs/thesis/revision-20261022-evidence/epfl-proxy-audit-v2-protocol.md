## 连接键与分组规则（不使用Energy）

1. 会话侧键为`(CCS, Arrival, Departure)`：`CCS`去除空白并大写；`Arrival`、`Departure`取工作簿中的无时区naive值，按分钟对齐（秒和微秒必须为0；非零即排除，不做四舍五入或时区换算）。
2. 测量侧先在测量文件内部按`(CCS, Session)`形成组。`Session`只用于组内归并，绝不作为跨表连接键；`Energy`绝不进入连接键。
3. 测量组的`Arrival`、`Departure`按以下顺序确定：
   - 若测量表同时存在会话级`Arrival`、`Departure`列，且组内取值唯一，则直接使用这两个源字段；
   - 否则使用组内最早与最晚测量时间戳作为观测到的组边界；
   - 两种来源都必须满足`Arrival < Departure`，且与组内实测时间范围一致；不一致的组排除。
4. 只有`(CCS, Arrival, Departure)`在会话侧和测量组侧均唯一时才建立一一连接。任一侧键重复、仅单侧存在或不能唯一匹配的会话/组全部排除并计数。

## 纳排检查（计算前固定）

逐会话依次检查，任一不满足即排除，并记录原因计数：

1. `CCS`属于`{CCS1, CCS2}`，`Arrival`、`Departure`非空、为分钟对齐naive时间且`Arrival < Departure`。
2. 会话侧`(CCS, Arrival, Departure)`唯一；测量组侧同键唯一；两侧一一匹配。
3. 测量组时间戳严格递增、无重复，相邻间隔均为60 s。
4. 测量时间戳恰好覆盖从`Arrival`开始、以1 min为步长的连续序列，且末个时间戳必须等于`Departure`；末个时间戳为`Departure − 1 min`时，最后1 min的梯形积分区间未被测量，按覆盖不完整排除。该规则不吸收离站分钟约定，也不改变连接键。
5. 每个`P`值为有限数且`P >= 0`；任何非有限值或负值使该会话排除。
6. 会话时长`Departure − Arrival >= 15 min`。
7. 会话表`Energy > 0`，且由`P`梯形积分得到的总电量`> 0`。
8. 会话表`Energy`可解析；缺失或非有限值排除。

排除在汇总形态之前完成；输出按原因给出计数，不按结果大小增删门槛。

## 能量/幅值诊断（与形态分开）

对每个纳入会话分别计算：

- `P_integral`：以`P (W)`在相邻分钟时间戳间作梯形积分，单位换算为Wh；
- `Energy_delta`：测量表累计`Energy (Wh)`的首末差，仅在组内单调且字段可用时计算；
- `Session_Energy`：会话表`Energy (Wh)`。

报告三个聚合量：`P_integral / Session_Energy`、`Energy_delta / Session_Energy`的会话等权中位数、四分位距和均值，以及缺失`Energy_delta`的会话数。该诊断只描述幅值/电量闭合，不作为形态纳排的容差门槛，也不把任何比值解释为计量校准。

## 15 min分片、积分与形态距离

1. 每个会话以其`Arrival`为锚点建立会话内15 min分片：第`b`片覆盖相对时间`[15b, 15(b+1))`分钟；最后一片可为不足15 min的尾片。
2. 每条相邻测量区间`[t_i, t_{i+1})`按`(P_i + P_{i+1}) / 2 × Δt`积分，电量记入区间起点所在的片。由于纳排保证`Δt = 60 s`，区间不跨片边界。
3. 会话表`Energy`按`Arrival`至`Departure`的分钟重叠比例均匀分配到各片；每片份额为`Energy × 该片与[Arrival, Departure]的重叠分钟数 / 总时长分钟数`。
4. 将实测片能量向量与均匀分配向量各自除以自身总和，得到单位总量的片级分布`p_measured`与`p_uniform`。
5. 形态距离为总变差距离`TV = 0.5 × Σ_b |p_measured,b − p_uniform,b|`，取值`[0, 1]`。
6. 主汇总为会话等权：有效会话数、TV中位数、四分位距（线性插值定义的Q1、Q3）、TV均值。另可报告按会话`Energy`加权的TV均值，但只作次要描述，不替代等权结果。
7. 分CCS只报告会话数、TV中位数和均值；样本过少时不给区间。
