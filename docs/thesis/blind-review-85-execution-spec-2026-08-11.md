# 85分盲审目标执行规范（2026-08-11）

## 1. 目标与边界

本规范服务于专业硕士盲审的“良好偏上”目标，依据现有正式实验、主稿和术语台账增强论证与送审完整性。它不新增训练、不补造数据、不扩大单站代理负荷结论，也不把第5章探索结果升级为部署能力或物理因果结论。

执行后的判断目标是：论文的工程问题、方法贡献、诊断贡献、适用范围和正式材料之间不存在断裂；外部有效性不足被明确承认并转化为可验证的后续工作，而非被模糊化。

## 2. 五项执行项

## 3. 顺序与变更控制

1. 先执行B2、B1和B3，保证贡献、工程含义和边界的逻辑顺序一致；
2. 再执行B4，将第5章明确置于主线之后；
3. 执行B5时仅重建既有正式DOCX，不创建递增后缀版本；
4. 每次内容修改后扫描“可部署、因果、显著优于、真实功率、待写”等高风险词，并对照术语台账；
5. 致谢、在读成果和附录的作者特定材料不由协作者代写。送审前必须由作者提供内容，或按学院要求从送审稿中处理。

## 4. 本轮完成判据

- 正文能够用一段话回答“工程上可作什么、当前不能作什么”；
- MDP被清楚说明为三类不同问题的协议化证据链，而不是三项并列分析；
- 第5章每项结果可追溯到“探索性”的限定；
- 正式DOCX与主稿同步，结构审计无新增阻塞项；
- Word中的目录、页码和交叉引用域仍须在最终提交环境人工更新并复核。
