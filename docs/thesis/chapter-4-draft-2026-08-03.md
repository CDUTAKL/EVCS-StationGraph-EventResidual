## 4.1 引言：MDP 协议的定义与设计原则

第 3 章以全局与分层指标确认了多关系门控图卷积网络（MRG-GCN）的预测有效性，但"模型内部如何分工、误差从何而来"仍是开放问题。常见的可解释性手段（SHAP 归因、注意力权重可视化）本质上是**事后观察**：它们给出"哪些输入重要"的静态读数，却不回答"若权重被强制改变，模型行为是否退化""图结构知识能否被其他参数形态吸收""全局误差由哪类样本贡献"这类需要实验设计才能回答的问题。为此，本章提出一个命名的诊断方法——**三层机制诊断协议**（Mechanism Diagnosis Protocol，MDP），以"干预—验证—溯源"的可执行协议替代事后解释。

MDP 由三层递进结构组成（图 4-1 ⏳ 三层框架图待补绘），每层对应一个独立的研究问题与证据来源：

- **L1 干预归因层**（IA）：模型到底用了哪类关系？——提取逐层关系级 β 门控权重并执行参数干预；
- **L2 蒸馏验证层**（DV）：图结构能被纯时序模型替代吗？——以知识蒸馏检验结构知识的可替代性；
- **L3 四格溯源层**（FET）：全局误差来自哪里？——以"标签事件 × 可见规则触发"四格定位误差来源；

三层从模型内部机制（L1）逐级外扩至模型能力边界（L2）与误差与数据口径（L3），证据类型分别为参数干预、知识传递与标签-规则交叉，形成递进封闭的链条。

**协议三要素。** 与散点式分析不同，MDP 的每一层统一由三个要素构成固定结构：①**方法定义**——可复现的操作流程，输入为已训练 checkpoint，输出为量化证据；②**诊断实验**——具体的实验设计（干预组合、蒸馏扫描、四格交叉）与运行口径；③**判定准则**——显式的"通过/不通过"判据，防止结论依赖主观解读。三要素保证每层结论可复核、可反驳。

**与现有可解释性工作的区别。** SHAP 与注意力可视化回答"模型关注什么"（观察），MDP 回答"模型依赖什么、结构能否替代、误差在哪"（实验）——每一层都包含实验设计而非事后解释。文献定位：近三年期刊工作中 EDformer、WEITS 等模型已设置独立可解释性章节，但以"协议化三层诊断"组织机制分析并贯通至下游增强（第 5 章）的形式，在充电负荷预测领域尚属空白，这是本文区别于四篇对标论文的差异化核心。

## 4.2 L1 干预归因层（IA）：模型到底用了哪类关系？

**协议定义。** 本层回答第一个研究问题：三类关系（负荷耦合 load / 行为共现 event / 轮廓相似 pattern）中，模型实际依赖哪些关系、如何依赖。操作流程为：输入已训练的 StaticGraph checkpoint → ①**观察**：提取两层关系级 β 门控权重（可学习关系选择权重，Softmax 归一化，见 3.5.3 节）；②**干预**：将 β 强制固定为多种组合，仅执行前向推理，测测试集 MAE 变化——本操作属于**参数干预敏感度分析**（术语台账口径），不涉及因果效应断言；③**判定准则**：若全部干预组合均退化且分层分工跨种子可复现，则判定门控机制必要、分工是模型自学的结果。

**观察证据。** 由三种子 checkpoint 代码提取的 β 均值（2026-08-03 核验）显示清晰的分层分工：GCN1 以行为共现（event）关系为主导（β ≈ 0.402，跨种子区间 0.398–0.405），GCN2 以负荷耦合（load）关系为主导（β ≈ 0.352），轮廓相似（pattern）次之（β ≈ 0.326）¹。三种子权重高度一致，说明分工结构不是随机初始化的偶然产物，而是稳定收敛的模型特征；该结果印证 3.5.6 节"两层独立关系权重"的设计动机——一阶传播依赖行为共现的直接邻居信息，二阶传播转向负荷耦合的全局结构。

¹ GCN2 pattern 的三种子均值为 0.326（seed-2024 为 0.344），与前期素材的 0.343 差异源于种子口径，以代码提取值为准。

**干预证据。** 对学习值执行 7 种干预组合（两层全 load / 全 event / 全 pattern / 等权 1/3 / 两层交换 / 单层固定×2，共 7 组合 × 3 种子，仅前向推理）后，全部组合的全局 MAE 均大幅退化，相对学习值基线（0.01376）变化 +95.9% 至 +233.6%（图 4-2）：最小退化出现在"GCN1 保持学习值、GCN2 固定为 pattern"（+95.9%），最大退化出现在"两层全 load"（+233.6%），等权融合退化 +143.8%，交换两层学习值退化 +148.4%。任一单一关系或等权配置均无法接近学习值性能。

**判定结论（通过）。** 观察与干预证据相互印证，本层判定通过：①学习到的关系权重携带真实任务信息，门控机制（而非先验等权）是性能的必要组件；②分层分工不可交换且跨种子可复现，"GCN1 event / GCN2 load+pattern"的分工是模型自学的有效结构；③全 load 干预退化最大，负荷耦合关系的分配对性能最敏感——该敏感性为第 5 章分层参数干预敏感度（5.5 节）提供了全局层面的归因起点。口径注：本层证据为参数干预功能敏感度，不构成数据层面的因果识别。

## 4.3 L2 蒸馏验证层（DV）：图结构能被纯时序模型替代吗？

**协议定义。** 第 3 章消融（3.7.1）显示移除图结构后模型恶化 113%，但该证据来自"剥夺输入"的端到端对比。本层采用更强的检验方式——知识蒸馏：教师模型（StaticGraph）将其完整预测信号作为软标签传递给纯时序学生模型（TCN），若学生即使拿到教师全部输出信息仍无法逼近教师精度，则说明增益中有一部分无法用纯时序参数表达，即图结构承载不可蒸馏的结构知识。操作流程：教师输出经蒸馏目标传递，软标签权重 α 扫描；判定准则：KD 后 TCN 逼近教师精度 → 图结构可被参数替代；无法逼近 → 图结构承载不可蒸馏的结构知识。

**诊断实验（已完成，判定已定稿）。** 实验 SG-EXP-013 以 α 扫描 4 组（α∈{0.1,0.5,1.0,2.0}）× 3 种子共 12 次训练全部完成（2026-08-03 核验）：教师为 StaticGraph（固定），学生为纯时序 TCN（无任何图输入）。KD 收敛曲线见图 4-3。

**判定准则（两分支）。** 若 KD 后学生逼近教师：图结构的收益可被时序参数与容量吸收，L1 的"门控必要"结论应附加"当前容量下"的限定；若未逼近：图结构携带不可蒸馏的结构知识，与 L1 干预证据共同构成"结构不可替代"的双层证据。无论落入哪支，结论均限定表述于本蒸馏配置范围——**单组学生架构（TCN）、单蒸馏目标（教师预测信号）、α 扫描范围**——不作"图结构整体可替代/不可替代"的全称表述。

**判定结论（通过，未弥合分支）。** 实测落入"未逼近"分支：即使 α=2.0 强蒸馏（学生获得教师完整预测信号），KD 学生仍停留在 0.029 量级（与教师 0.01376 差距约 2.1 倍；各 α 与纯 TCN 0.02952 相比改善约 0.1%~1.1%，α=2.0 时最大仅 1.06%）。判定：**图结构承载不可蒸馏的结构知识**——图模块的增益无法用纯时序参数与蒸馏目标表达，与 L1 干预证据（门控权重携带任务信息）共同构成"结构不可替代"的双层证据。结论限定于本蒸馏配置范围（单学生架构、单蒸馏目标、α∈{0.1,0.5,1,2}），不作全称表述。

**与 L1 的关系。** L1 从"参数扰动"角度证明门控权重携带信息，L2 从"知识传递"角度检验同一信息的可表达性：前者证明模型依赖关系分配，后者检验该依赖能否被容量替代。两层证据互补——若 KD 成功，说明关系信息可压缩进时序参数，L1 结论需附加容量限定；若失败，则结构知识具有不可约性，图建模的贡献获得"不可用纯时序复现"的独立确认。

## 4.4 L3 四格溯源层（FET）：全局误差来自哪里？

**协议定义。** 本层将全局误差按两个维度交叉定位：target_event（真实事件标签，事后已知）与 rule_trigger（可见规则触发，验证集冻结规则产生的可部署信号，事前可知）。两者交叉构成四格：事件触发且真实事件、事件漏触发、非事件触发、稳定样本。**硬性约束**：样本量加权还原——Σ(格 MAE × 格样本量) / 总样本量 必须与全局 MAE 一致，容差 ≤ 1e-9；判定准则：还原通过则分层口径成立、误差来源可精确归属，否则四格分解无效。

**构念注（审查 H-04）。** target_event 与 rule_trigger 定义不同——前者为事件四分量任一 > 0 的事后标签，后者为验证集非零事件分数 95 分位冻结阈值 + 因果前向扩展 2 步的可见代理。因此四格是"标签事件 × 可见规则触发"的组合，不采用 precision/recall/误报/漏报等分类语义解读；"事件漏触发""非事件触发"仅为四格命名的描述性标签。

**诊断实验（seed-2024，图 4-4）。** 测试集 712,360 个样本的分解：事件触发且真实事件 n=235（MAE 0.2157）、事件漏触发 n=9,925（MAE 0.2767）、非事件触发 n=2,825（MAE 0.0689）、稳定 n=699,375（MAE 0.0096）；样本量加权还原全局 MAE 的容差 ≤1e-9，18/18 项核验全部通过。误差结构概括为三点：①事件相关样本（真实事件标签，格1+格2，占比 1.43%）的加权 MAE 约为稳定格的 28 倍——事件窗口误差被稳定样本稀释，全局指标不能代表事件窗口性能，分层评价必要；②事件样本中规则触发的仅 235/10,160 ≈ 2.3%（事件漏触发占事件样本 97.7%），可见规则与真实事件重合度低，指向可见代理信号的预测边界（衔接 5.3 节分层共形分析）；③非事件触发格（n=2,825）MAE 0.0689 约为稳定格 7 倍，规则误触发样本本身伴随误差上升。

**补充误差结构证据。** 图 4-5 显示 TCN、StaticGraph、MLP 三模型的事件窗口残差分布均比全局更宽且右偏（量级约为全局 20 倍）——事件窗口的误差结构差异对模型类型不敏感，是数据与任务层面的共性特征；图 4-6 显示平均绝对误差随可见事件分数总体上升（无事件约 0.013 → 强事件约 0.059，弱/中档差异较小），将事件窗口误差进一步分解为随事件强度总体恶化的结构性来源。

**判定结论（通过）。** 还原校验通过，四格口径成立：误差来源可精确归属——事件窗口误差主体在"事件发生但规则未触发"的漏触发样本，全局指标高估事件窗口性能，分层评价必要。该结论已用于第 3 章分层指标（表 3-2）与第 5 章分层共形（5.3 节）的设计依据。本层为单种子机制诊断（图 4-4 图注口径），不作三种子泛化结论。

## 4.6 协议总结：MDP 机制画像与可复用性

**机制画像。** 将三层诊断结果汇总为表 4-1：每层一行，固定呈现协议操作、诊断实验、判定准则与判定结论，形成本文模型（MRG-GCN）的完整机制画像。画像整体呈现一致性：L1 与 L3 均指向事件相关处理的特殊地位（关系分配中行为共现主导一阶传播、误差结构中事件样本主导误差方差），L2 从能力边界方向检验这一地位的稳健性——三个问题共同回答"模型在做什么、能做到什么、误差在哪"。

**表 4-1** MDP 三层机制画像（本文模型，2026-08-03）

| 层 | 研究问题 | 协议操作 | 诊断实验 | 判定准则 | 判定结论 |
|----|---------|---------|---------|---------|---------|
| L1 IA | 模型用了哪类关系？ | 提取逐层 β 门控 + 强制固定组合 | 7 干预组合 × 3 种子，仅前向推理 | 全部干预退化且分层分工可复现 | ✅ 通过：门控必要；GCN1 event / GCN2 load+pattern 分工为模型自学 |

**框架定位与可复用性。** 三层操作定义（参数干预 / 知识蒸馏 / 标签-规则交叉）与具体模型解耦，具备协议化迁移条件；但框架的有效性目前仅在本文模型上完成验证，跨模型复现属于未来工作，不提前宣称"任何图预测模型均可直接复用"。L2 蒸馏验证（SG-EXP-013）判定已定稿（未弥合：结构知识不可蒸馏）。

**三层闭环收束。** MDP 的输出直接驱动第 5 章结构分析与预测支持探索，构成"诊断 → 增强"闭环：L1 的分层分工证据支撑第 5 章 5.4 节分层参数干预敏感度（干预分析从"是否有效"升级为"对谁有效、在什么条件下有效"）；L3 的误差归属证据支撑 5.3 节分层共形区间（事件窗口误差稀释的直接应对）。机制增强候选（节点差异化参数 NAPL 与门控专业化 Gate-MI）的筛选过程与结论见附录。机制画像同时为结论章提供统一的证据骨架。

**限制披露。** 与第 2、3 章一致，本章结论受限于单站 10 节点代理负荷场景与固定关系图；验证集双重用途（事件阈值拟合与早停选择）已在 3.6.1 节披露，本章诊断均基于测试集冻结规则执行，不引入新的调参自由度；L2 结论限定于其蒸馏配置范围（单学生架构、单蒸馏目标、α∈{0.1,0.5,1,2}）。
