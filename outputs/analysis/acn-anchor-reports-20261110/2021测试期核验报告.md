## 核验②结果：低电量会话电压推断稳定性 —— 通过，且比预期更强

### 1. 标签总量标定精确

半计量标签构造（每会话 v_eff = kWhDelivered×3.6e6/∫I dt）使 `int_kwh_eff` 与 `kWhDelivered` 的偏差 **max 0.85%**，仅 3 条 >0.1%，无一条 >1%。逐会话总量是恒等归一的，不存在标定漂移。

### 2. “82 条低压会话”身份确证 = CA-321 的 120V 回路会话

- CA-321（spaceID 78-365）104 条会话呈双峰：**82 条 implied_v ≤195V（中位 157.9V，IQR [143.6, 168.8]），22 条 ~208V**。82 这个数字与论文 5.4 节的“82 条低压会话”精确吻合——它们是同一批会话。
- 对 82 条做 implied_v ~ 1/n_bins 线性外推：**n_bins→∞ 时渐近电压 = 122.4V**（拟合 R² 含义：implied_v = 122.4 + 623.5/n_bins）。即真实回路电压就是 ~120V 等级，这批会话是物理真实的 120V 电路会话，不是推断错误。
- 逐月 median 在 142.8–165.9V 间波动、与时间相关性 r=0.056 → 无长期漂移，推断机制稳定。
- 注意：implied_v 随会话变短而系统性偏高（短会话 120V 类可虚高至 280–315V），原因是电流零偏在短会话 ∫I 中占比大。这是**逐会话标签内部形状**的失真来源，但不影响总量，且已被 5.4.7 的节点级重评估覆盖（这批会话仅 183.1 kWh，占 8,362 kWh 总量的 2.2%）。

### 3. 208V 节点推断高度稳定

- 9 个 208V 节点合计 1,096 条会话：implied_v **中位 224.1V，IQR [222.0, 226.2]**。
- 与节点中位偏差对 1/√n_samples 的相关 **r = −0.017** → 推断精度不随采样量恶化，不是噪声主导。
- 真异常（偏差 >25V）仅 **4 条（0.36%）**：CA-327 一条 554.6V，CA-311 一条 280.0V，CA-303 两条 279.7V / 352.3V。其中三条集中在 **2021-03-15 同一天**，疑似当日遥测事件，建议在论文中作为单日异常处理而非系统问题。

### 4. 低电量（<2 kWh）会话：263 条，占能量 3.5%

- 除 CA-321 外 254 条中 **253 条（99.6%）implied_v ∈ [210, 240]** —— 低电量会话的电压推断完全稳定，不存在“低电量 → 电压推断失效”的问题。

### 5. 固定 208V 假设的偏差（为何必须逐会话推断电压）

- 208V 节点固定电压积分偏差 **中位 −7.2%**（各节点 −6.2%~−7.5%，与 README 的 −7.1% 一致）；CA-321 则 +28.4%（p90 +52%）。
- 即：不做逐会话电压推断，208V 节点会整体低估约 7%，CA-321 高估 28%+。5.4.7 采用 v_eff 的做法在数据上得到强支撑。

## 核验①结果：完成后电量占比 —— 闭环（bins.csv 已从 PR 分支取回，SHA-256 与锁文件一致）

口径：完成时刻严格有效（接入 < 完成 ≤ 断开）的 1,185 条会话；每个 15 min 箱按时间重叠比例把电量分配到完成后时段。

### 总量对比

| 标签 | 完成后电量 | 占比（电量加权） |
|---|---|---|
| 接入—断开均分 | 3,224.6 / 8,665 kWh | **37.2%**（会话均值 45.2%，中位 50.1%） |
| 半计量 eeff | 121.2 / 8,347 kWh | **1.45%**（会话均值 3.6%，中位 0.78%） |

均分标签的中位 50.1% 与仅用元数据算出的完成后时间占比（中位 50.1%）精确一致——管道自洽性再次确认。

### 分层结论

- **208V 九节点**（1,103 会话）：半计量完成后占比**中位 0.73%、均值 2.0%**；完成后残余电流中位约 **0.2A**（IQR [0.05, 2.79]）——主要为传感器零偏/涓流级别，134 条（12%）>5%。
- **CA-321 120V 类**（82 会话）：中位 **25.2%**，且 82 条会话的完成后电流全部恒定在 **0.90–0.94A**——这种跨会话恒定幅值是设备级真实持续耗电或通道固定偏置的特征，不是随机噪声；该节点仅占总电量 2.2%。
- 全部 121.2 kWh 完成后电量中 CA-321 贡献 45.2 kWh（37%）。
- 严格箱起点规则（bin_start ≥ 完成）下中位占比为 0.0%——完成后电量几乎全落在完成时刻所在的边界箱内，属边界分配而非长拖尾。

### 与 2018 训练期窗口的对照

2018 功率积分基准完成后占比 0.023%（unbridged）；2021 半计量 208V 节点中位 0.73%。口径不同（真实功率 vs 电流×推断电压），不可直接比数值，但两者相对各自均分标签（2018：25.3%；2021：37.2%）都把完成后伪电量压到了 1–2 个数量级以下，方向一致。

2. “82 条低压会话”有设备级解释：CA-321 为 120V 回路（外推渐近电压 122.4V），不是标签错误；建议论文中明写该站电压等级差异。
