# 答辩问答准备：创新、代理数据与排序稳定性

## Q1. 你的创新点是什么？

**答：** 本文的贡献是三类可复核证据：第一，在统一预测键上给出站内关系与节点门控的条件性增量，并区分整体、非零和事件样本；第二，提出并验证 MDP 三层诊断协议，说明 β 权重、学生替代和四格误差各自能支持什么判断；第三，量化两套代理标签的差异与排序敏感性，说明在本任务所检范围内三种子平均全局排序基本保持、非零/事件排序更敏感。MRG-GCN 是验证载体，其组合本身不作为主要创新。

## Q2. 组合已有组件，为什么算贡献？

**答：** 专业硕士论文的贡献可以是组合创新、受控经验发现或诊断方法，不要求新算子或全面领先。本文把“站内关系/门控是否有效”拆成整体—非零—事件—预算四层证据，并报告负结果：完整 AGCRN 在 Caltech 整体更低，MRG-GCN 在非零/事件组不如 TCN，行为关系不确定，β 没有独立增益。这些结论能约束后续研究和采数决策，属于可复核的经验贡献，而不是“又一个模型”。

## Q3. 为什么没有实测功率？代理标签怎么验证？

**答：** 本文使用的 ACN 会话归档不含连续电表功率；公开接口和静态镜像另有时序电流字段，但本文未取得覆盖测试期的同步实测功率。本地 Caltech 快照（31,424 条，2018-04-25 至 2021-09-14）与 2026-10-05 的 JPL 全量普查（33,638 条，2018-09-05 至 2021-09-14，带分页响应哈希）显示可用公开快照止于 2021-09-14；2026-10-25 的认证接口查询在指定站点/格式下失败，不能据此推断所有源端数据状态。本文用四类证据量化代理边界：总量守恒（逐节点差 < 1e-8 kWh）、完成时刻截断（30.66% 电量分配到完成充电后；逐节点时间片平均绝对差 0.0477816 kWh/15 min）、8 条电流形态（TV 0.0645–0.5957；最大片份额 1.10–4.38 倍）、EPFL 外部参照（1,620 条；TV 中位数 0.0736）。这些证据说明代理保留总量但会改变时间形态；它们不等于实测功率验证。两套代理标签差异与 5.3 节区间宽度的比较是描述性的，统计集合不同（非零/事件键 vs 全体键），不能据此推断逐键覆盖率或实测覆盖；本文未针对同步实测值校准或评价区间。下一步需要同步电表、到达时间戳、站级限额和计量映射，按“离线回放→影子运行→现场”分阶段验证。

## Q4. 全局排序基本保持、非零排序更敏感，说明什么？

**答：** 在 708,560 个测试键上，先对每个配置的三个种子取平均 MAE，再对 12 个配置排序，得到均匀标签与完成时刻截断标签之间的全局 Spearman 0.993；逐种子相关为 0.972/0.972/0.979，二者不是同一个统计量。Top-3 完全一致，最大排名变化 1 位；零目标和稳定窗口分别为 0.951 和 0.993。该结论只适用于本任务所检 12 个配置、两套标签和已查看 Caltech 测试期，不能外推为“所有模型筛选都稳健”。非零目标（评价标签）三种子平均只有 0.420，逐种子为 −0.112/0.098/0.014；标签事件 0.559（逐种子 0.007–0.608）；固定均匀非零子集 0.671（0.629–0.727）。在固定子集上完整 AGCRN 从第 1 降到第 6，`mrg_event` 从第 6 升到第 1。因此，全局优势不能外推为活跃片段优势；按活跃片段选模必须用实测标签，或至少并列报告两种非零子集定义和逐种子读数。

## Q5. 为什么节点门控优势从 2.69% 变成 1.65%？

**答：** 2.69% 是均匀标签下三种子平均的结果，1.65% 是同一批门控预测在完成时刻截断标签下的三种子平均结果。幅度变弱说明该增量对标签定义敏感；但截断标签下 seed-2024 由 +1.73% 变为 −0.91%，发生反转，所以不能写“方向不变”或“各次一致”。原结论本来就限定在当前 60 轮预算与选模规则下（共享门控有一个种子触顶），1.65% 是更保守的边界，但不是替代目标下重新训练门控的比较。

## Q6. 非零组 MRG-GCN 不如 TCN，为什么还说关系有增量？

**答：** 这是两个不同层次的问题。关系自环替换比较的是“同一架构内，保留该关系 vs 换成自环”，JPL 上负荷耦合和轮廓相似关系的整体 MAE 增量分别为 1.82% 和 1.52%（Bonferroni 区间下限为正）；它说明关系组件在当前架构内有条件价值。负荷关系相对自环的非零组差异为 0.004893 kWh/15 min，三个种子方向均为正，但这是已查看测试期上的未校正事后分层，属于探索性证据。完整 MRG-GCN 与 TCN 的比较是“不同架构/容量/归纳偏置”的模型排名，非零组 TCN 更低。两者可以同时成立：关系有组件内增量，不等于完整模型在活跃片段胜过 TCN；新增的标签排序分析补强了标签敏感性认识，不替代也不抹掉这一探索性证据。论文第 3.7.2 节和结论都明确写了这一点。

## Q7. 为什么没有 2021 年以后的新时期数据？

**答：** 需要区分页面访问、表单提交和 API 认证三类证据。GET `/register` 和 GET `/login` 页面返回 HTTP 200，只说明页面可访问；POST `/register` 提交曾返回 nginx 502，后续返回 HTTP 500（有截图）；POST `/login` 返回的是“用户名或密码无效”的提示（用户观察），不是 HTTP 500。2026-10-25 对 caltech/jpl/office001 的 API 只读测试中，无 `Authorization` 的 GET 返回 401；带 Basic 认证（包括故意无效 token）的 GET 在指定站点/格式下返回 500 或超时，不能据此推断所有 token 失效。2022–2026 年度下载记录为 0 行，但缺少已核验的状态码、查询范围和响应计数，不能单独作为源端零记录的证据；未认证查询也不等同于零条。更可靠的是：2026-10-05 的 JPL 全量普查成功返回 33,638 条，覆盖 2018-09-05 至 2021-09-14，并有分页响应哈希与 acquisition manifest；本地 Caltech 快照 31,424 条覆盖 2018-04-25 至 2021-09-14。因此，本文可用的公开快照止于 2021-09-14；不能据此推断所有源端数据均无更新。本文据此把所有测试期标为已查看，结论限定为固定历史时期，不声称未见时期泛化。

## Q8. MDP 是因果分析吗？

**答：** 不是。L1 是冻结参数替换的功能敏感度，L2 是受检学生能否逼近教师，L3 是事件×规则四格误差构成；三层都只描述模型内部依赖和样本误差，不识别现实负荷的因果机制。L1 还做了重参数化检查：β′ᵣ = 1/3、W′ᵣ = 3βᵣWᵣ 可以保持消息不变，所以 β 大小不能单独解释为关系重要性。MDP 的价值是修正过度解释和报告口径，不是给出因果结论。

## Q9. 工作量和工程价值在哪里？

**答：** 数据侧完成 31,424 条 Caltech 会话审计、55 节点筛选、9 项质量门禁、118,818 步张量重构；模型侧完成三套协议、12 种配置×3 种子、JPL 重拟合、同参数门控对照、关系自环替换、完成时刻目标敏感性；诊断侧完成 L1/L2/L3 和 JPL L1/L3 复核；可靠性侧完成独立共形、14/28 天滚动回放、TE/PCMCI+ 方向筛查。工程价值是给出可复用的证据链、MDP 协议卡和采数优先级，而不是现场调度收益。

## Q10. 如果继续做，最优先补什么？

**答：** 按性价比排序：①Caltech 事件时刻协议的关系自环替换（9 次训练），补上 JPL 已有的跨站关系证据；②容量匹配 AGCRN 或行为 GRU，排除“增益只是容量/架构”的解释；③若静态镜像中确有足够带 Power/Voltage 的会话，可扩到 50–100 条做均匀分摊校准；目前只验证了少量样本，尚未证明这一数量可用，不能写成已就绪路线；④若还有时间，做 proxy-aware 共形区间，把标签不确定性纳入区间宽度，但须明确仍是代理对代理的敏感性评价；⑤最终才考虑新场站/新数据。前三项都不需要新数据采集，但需要新的训练/分析任务授权。

## 一句话收尾

> 本文的贡献不是“又一个更强的模型”，而是把站内关系/门控的证据边界、诊断协议和代理标签有效性做成可复核的链条；它支持模型筛选和采数决策，不支持实测功率精度或现场收益。
