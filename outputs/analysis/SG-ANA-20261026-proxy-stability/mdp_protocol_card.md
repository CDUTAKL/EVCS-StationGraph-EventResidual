# MDP 诊断协议卡（可复用版）

## 目的

把第 4 章的三层诊断从“三个实验”整理为一个可复用的协议：给定一个冻结模型和预测键，按 L1/L2/L3 三步分别回答“参数配置是否敏感”“指定学生能否替代”“误差由哪些样本构成”，并明确每步能支持与不能支持的判断。

## 协议输入

- 冻结模型及检查点；同一批预测键（原点、目标片、节点）。
- 关系矩阵、关系级权重 β、节点级门值 G（若模型有）。
- 目标标签、目标侧事件标签 `target_event`、冻结规则触发 `rule_trigger`。
- 训练/调参/校准/测试分段；训练预算、早停规则、种子列表。
- 模型容量、输入权限、选择指标；是否触顶。

## L1 参数干预

**操作**

1. 观察两层 β 的三个种子取值，报告均值和离散度；不把权重直接解释为关系重要性。
2. 冻结其他参数，仅替换 β 为 7 种组合：两层单一关系、两层等权、两层交换、单层固定另一层学习。
3. 做函数保持检查：令 β′ᵣ = 1/3、W′ᵣ = 3βᵣWᵣ，冻结其余参数前向；若输出保持不变，说明 β 不能脱离 W 的尺度单独解释。
4. 若要做参数化选择，另做等权重训；区分“冻结替换”和“从头重训”。

**判据**

| 观察 | 可支持 | 不支持 |
|---|---|---|
| 7 种替换均退化 | 已训练联合配置对 β 敏感 | β 有独立正增益、权重大小等于关系贡献 |
| 重参数化输出保持 | β 与 W 共同决定消息 | 等权重训一定等效；优化轨迹相同 |
| 等权重训接近或更好 | 该参数化在当前预算下可达相近误差 | β 对所有数据/预算普遍无用 |

## L2 学生替代

**操作**

1. 固定教师，训练纯时序学生；记录教师/学生容量、输入、损失、蒸馏权重、预算。
2. 若学生未逼近教师，先检查容量、输入路径、损失尺度和早停；再做容量匹配或输入匹配的补充。
3. 只有在容量、输入、目标和预算匹配后，才讨论“图信息是否可替代”。

**判据**

| 观察 | 可支持 | 不支持 |
|---|---|---|
| 学生未弥合差距，且容量/输入不匹配 | 所检学生设置未替代教师 | 图结构普遍不可替代 |
| 容量/输入匹配后仍未弥合 | 该学生架构/目标下替代失败 | 所有时序模型都无法吸收图信息 |
| 匹配后接近教师 | 图信息在该设置下可被吸收 | 图结构无预测价值（需再做消融） |

## L3 四格误差分解

**操作**

1. 按 `target_event` × `rule_trigger` 交叉，得到四格：事件/触发、事件/未触发、非事件/触发、非事件/未触发。
2. 报告每格样本量、占比、MAE、绝对误差份额。
3. 用样本量加权恒等式还原全局 MAE，检查算术闭合。
4. 分别报告“稀有困难格单键误差”和“常态格总误差贡献”；不要用一个指标替代另一个。

**判据**

| 观察 | 可支持 | 不支持 |
|---|---|---|
| 稀有格单键误差高、样本少 | 评价需并列报告分层 | 改善稀有格一定降低运行风险 |
| 常态格贡献多数总误差 | 模型筛选需看总量与分层的权衡 | 全局 MAE 足以代表所有样本 |
| 四格加权还原闭合 | 分组与算术一致 | 因果归因或事件检测性能 |

## 输出模板

| 层次 | 问题 | 操作 | 支持 | 不支持 | 失败模式 |
|---|---|---|---|---|---|
| L1 | 当前配置对关系分配是否敏感？ | β 替换 + 重参数化 + 等权重训 | 联合配置敏感度 | β 独立增益/因果重要性 | β 与 W 混淆、预算不同 |
| L2 | 指定学生能否替代教师？ | 蒸馏 + 容量/输入匹配 | 所检学生替代表现 | 图结构普遍必要性 | 容量/输入/损失不匹配 |
| L3 | 全局误差由哪些样本构成？ | 四格分解 + 加权还原 | 分层评价重点 | 因果机制/运行风险 | 标签与规则错位、样本稀疏 |

## 失败模式清单

- 把 β 权重当关系重要性：先做重参数化检查。
- 把冻结替换退化当独立增益：β 与 W 共同缩放消息。
- 把学生失败当图不可替代：先匹配容量、输入、损失和预算。
- 把四格误差份额当风险：份额是描述性构成，不是经济或运行价值。
- 把共享门控触顶当收敛：预算受限时只报告“当前预算下的观测差”。
- 把已查看测试期当确认性证据：所有事后分层都要标注。

## 应用步骤

1. 固定模型、预测键和标签；记录哈希。
2. 先做 L1 观察，再做替换和重参数化；不要先定结论。
3. 再做 L2；先检查容量/输入是否匹配，再解释差距。
4. 最后做 L3；先检查四格加权还原，再报告份额。
5. 把三层判断写成“支持/不支持”表；不要合并成一个总分或单一因果结论。
