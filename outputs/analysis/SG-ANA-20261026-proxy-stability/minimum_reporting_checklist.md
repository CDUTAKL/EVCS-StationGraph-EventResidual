# 代理负荷预测的最小报告清单

## 目的

本文的核心教训之一是：全局 MAE 会掩盖活跃片段和事件样本的差异，代理标签会改变绝对误差，甚至会改变非零/事件子集的排序。为了让同类研究可比较、可复核，建议在论文或附录给出一张最小报告清单。它不是新的评分标准，而是对“代理负荷预测”这一类任务的报告要求。

## 清单

| 类别 | 项目 | 要求 | 理由 |
|---|---|---|---|
| 数据 | 数据源、场站、节点、时间范围 | 必报 | 判断任务边界与可复现性 |
| 数据 | 会话记录还是连续电表 | 必报 | 决定标签是代理还是实测 |
| 数据 | 分配规则（均匀、完成时刻截断、其他） | 必报 | 直接改变标签与零值率 |
| 数据 | 零值率、非零样本数、事件样本数 | 必报 | 解释全局指标的分母与主导样本 |
| 数据 | 标签成熟时刻、缺失/异常处理 | 必报 | 防止未来信息进入输入 |
| 输入 | 预测时可见字段、片末可见假设 | 必报 | 区分离线回溯与可部署输入 |
| 输入 | 到达时间戳/通信延迟是否核验 | 建议 | 判断计数特征是否真的在线可见 |
| 划分 | 时间顺序、完整窗口留段、校准/测试分离 | 必报 | 防止跨段泄漏 |
| 划分 | 测试期是否已查看 | 必报 | 区分确认性与事后分析 |
| 模型 | 参数量、容量匹配情况 | 必报 | 防止把容量差异当组件增量 |
| 模型 | 基线选择与输入权限 | 必报 | 判断比较是否同条件 |
| 训练 | 预算、早停、选模指标、种子数 | 必报 | 判断是否触顶与可复现 |
| 训练 | 触顶/未收敛配置 | 必报 | 防止把预算限制当稳定结论 |
| 指标 | 全局 MAE/RMSE/WAPE | 必报 | 主指标与量级 |
| 指标 | 零目标、非零目标、事件、稳定窗口 MAE | 必报 | 揭示全局掩盖的分层差异 |
| 指标 | 非零子集定义（评价标签 vs 固定子集） | 建议 | 本文显示两种定义会改变排序 |
| 统计 | 种子离散度、时间块区间、多重校正 | 必报 | 区分描述性与确认性 |
| 统计 | 事后分层/事后选择 | 必报 | 防止把探索性结果写成确认性 |
| 标签 | 两套代理标签差异/形态证据 | 建议 | 量化代理标签之间的差异与形态证据；无实测真值时不称“误差” |
| 标签 | 排序稳定性（全局 vs 非零/事件） | 建议 | 本文新增；判断结论对标签定义的敏感性 |
| 复现 | 配置、预测键、检查点、哈希、环境 | 必报 | 逐键复核与复现 |
| 主张 | 代理 vs 实测、固定期 vs 未见期、离线 vs 现场 | 必报 | 防止外推 |
